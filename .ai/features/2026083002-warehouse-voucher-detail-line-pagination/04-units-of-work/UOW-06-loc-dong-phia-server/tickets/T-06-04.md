# T-06-04 — Gỡ `GET /:id/lines`

## Context

Đến đây hai dialog đã đọc endpoint mới. Consumer còn lại **được biết đến** là panel chi
tiết cuộn vô hạn ở `GoodsIssuePage.tsx:879`. "Được biết đến" không phải "duy nhất" — grep
toàn repo trước khi xoá, gồm cả `apps/pos-web` và `packages/`.

## Implementation notes

- Chuyển panel cuộn vô hạn sang `POST .../lines/search` với body rỗng. Nó chỉ phân trang,
  không lọc, nên chỉ đổi đường gọi và cách đọc envelope: `{ items, hasMore }` →
  `{ data, total, page, limit }`. `hasMore` không còn — suy từ `page * limit < total`.
- Xoá route `@Get(':id/lines')` ở **cả hai** controller và `getLines` ở **cả hai** service,
  cùng các kiểu `GoodsIssueLinesPage` / `GoodsReceiptLinesPage` nếu không còn ai dùng.
- Xoá luôn các test đang gọi thẳng `getLines`, hoặc chuyển chúng sang handler mới — đừng
  để lại test chết.
- Chạy API rồi `pnpm openapi:generate`; commit `openapi.snapshot.json` và
  `packages/api-client/src/generated/schema.ts`. **Không** sửa tay file sinh ra.
- Bẫy đã dính một lần trên repo này: `:4000` có thể đang chạy từ một bản `dist/` cũ hoặc
  từ worktree khác. Xác nhận API đang phục vụ đúng mã của nhánh này **trước** khi tin kết
  quả `openapi:generate` hay kết luận endpoint mới 404 (`.ai/verify-stack.sh`).
