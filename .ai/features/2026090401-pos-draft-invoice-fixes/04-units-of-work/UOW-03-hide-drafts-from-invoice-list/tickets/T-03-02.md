# T-03-02 — Rào an toàn cho endpoint tìm nháp

## Context
Rủi ro duy nhất của UOW-03 là lọc lây: nếu ai đó "dọn dẹp" bằng cách đẩy điều kiện lên chỗ
dùng chung, dialog "HĐ lưu tạm" sẽ rỗng và thu ngân mất sạch phiếu treo — hỏng nặng hơn lỗi
đang sửa.

## Implementation notes
- Test cho `SearchDraftInvoicesV2Handler`: cùng dataset của T-03-01 → endpoint nháp trả đúng
  3 phiếu.
- Nếu suite e2e đã có setup hoá đơn dùng lại được thì bám vào đó; nếu không, viết ở tầng unit
  với repository giả như các `*.handler.spec.ts` sẵn có.
- E2E của repo chạy `maxWorkers: 1` và `forceExit: true`; teardown kafkajs treo có thể làm
  suite báo đỏ dù test xanh — đọc output thật, đừng tin exit code.
