# T-02-02 — Sinh lại `api-client` và openapi snapshot

## Context

T-02-01 đổi hợp đồng công khai ở hai chỗ: thêm tham số truy vấn `isTracked` và thêm trường
`isTracked` vào response DTO. `CLAUDE.md` quy định: sau khi đổi endpoint thì chạy API rồi
`pnpm openapi:generate`, commit cả `packages/api-client/openapi.snapshot.json` lẫn
`packages/api-client/src/generated/schema.ts`, và **không sửa tay** file sinh ra.

Tách thành ticket riêng vì nó là bước máy móc có tiền điều kiện riêng (API phải đang chạy ở :4000)
và vì quên nó là cách kinh điển để diff trông xanh mà client lại lệch hợp đồng.

## Implementation notes

- Khởi động API: `make dev-api` (hoặc `pnpm build` + `node dist/main.js`), chờ `:4000` sẵn sàng.
- Chạy `pnpm openapi:generate`.
- Diff phải chỉ chứa hai thay đổi trên. Nếu nó kéo theo thay đổi lạ ở endpoint khác, **dừng lại**:
  nghĩa là snapshot đang lệch sẵn từ trước, và đó là việc riêng chứ không phải việc của ticket này.
- Không sửa tay `schema.ts`.
