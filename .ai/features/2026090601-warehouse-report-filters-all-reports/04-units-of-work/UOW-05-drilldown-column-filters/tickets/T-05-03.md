### Test tầng engine **không đủ** — đột biến chứng minh điều đó

Sau khi viết xong 22 test tầng engine, thử gỡ đúng dòng bàn giao ở
`transfer-difference-detail.report.ts` — tức dựng lại nguyên bug ban đầu:

```
MUTANT → 166/166, failed 0     ← KHÔNG test nào bắt được
```

Engine vẫn đúng ở mọi test, vì engine **không phải** chỗ hỏng. Chỗ hỏng là lớp report giữ filter
lại cho riêng mình. Không có test tầng report thì bug tái phát im lặng y như lần đầu.

Thêm 8 test bàn giao rồi lặp lại đột biến trên **cả ba** lớp report:

```
MUTANT   → 166/174, failed 8
  caught: difference-detail passes them on buildData
  caught: difference-detail passes them on countRows too
  caught: document-detail passes them on buildData
  caught: document-detail passes them on countRows too
  caught: sends an empty map when the grid filtered nothing
  caught: passes them on buildData                (L1)
  caught: passes them on countRows too            (L1)
  caught: does not translate the column key through the totals key map
RESTORED → 174/174
```

`countRows` được khoá riêng vì nó nuôi hạn mức xuất khẩu: đếm không lọc thì file bị chặn — hoặc
được cho qua — theo một con số sai.
