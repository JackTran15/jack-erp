# T-02-02 — Mở route cho `setActiveStatus`

## Context
Nghiệp vụ đã xong ở T-02-01; ticket này chỉ dựng cửa HTTP. Đặt trên
`InventoryLocationController` (`@Controller('inventory')`), cạnh `PATCH /inventory/items/:id`
— **không** đặt trên `InventoryItemV2Controller`, vì controller kia là CQRS `QueryBus` thuần
đọc còn đây là mutation dùng service trực tiếp (đúng phân công trong CLAUDE.md).

## Implementation notes
- DTO mới `SetItemActiveStatusDto`: `ids: string[]` (`@IsArray() @ArrayNotEmpty()
  @IsUUID('4', { each: true })`) và `isActive: boolean` (`@IsBoolean()`). Có `@ApiProperty`.
  `ValidationPipe` toàn cục bật `forbidNonWhitelisted` nên DTO phải khai đủ mọi trường nhận.
  Export qua `dto/index.ts` cho khớp lệ.
- `@RequirePermission('inventory.write')` (AC-17). Guard đã ở mức class.
- ⚠️ **Thứ tự route:** khai `@Post('items/set-active-status')` **trước** mọi route
  `items/:id` trong cùng controller, nếu không `:id` sẽ nuốt path tĩnh này.
- Là mutation ⇒ tự động chịu `IdempotencyInterceptor` toàn cục. **Không tự cài lại** (AC-19).
- Trả thẳng `{ updated, skipped }` từ service.
- Sau khi API chạy: `pnpm openapi:generate`, commit cả `openapi.snapshot.json` lẫn
  `packages/api-client/src/generated/schema.ts`; không sửa tay file sinh ra.
