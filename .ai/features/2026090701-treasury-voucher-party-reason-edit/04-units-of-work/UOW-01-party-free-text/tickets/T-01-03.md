# T-01-03 — Regenerate openapi + api-client cho partnerName

## Context

FE gọi API qua `@erp/api-client` sinh từ OpenAPI. Bốn DTO vừa thêm trường mới ở T-01-01 và
T-01-02 nên phải sinh lại trước khi T-01-04 dùng được.

## Implementation notes

- Chạy API ở :4000 rồi `pnpm openapi:generate`
- **Không** sửa tay `schema.ts` — đó là file sinh tự động
- Bẫy đã biết: đừng chạy `pnpm --filter @erp/api build` khi `pnpm dev` (nest --watch) đang chạy,
  hai tiến trình ghi đè `dist/` gây lỗi "Cannot find module"
- Bẫy đã biết: xác nhận API :4000 đang chạy từ ĐÚNG checkout này trước khi tin kết quả — một
  tiến trình cũ ở cổng đó sẽ sinh snapshot của bản khác

## Done when

- [x] `partnerName` xuất hiện trong `schema.ts` ở cả 8 DTO (4 loại × create/update)
- [x] `openapi.snapshot.json` và `schema.ts` đều được commit
- [x] `pnpm --filter @erp/api-client build` xanh

## Sửa lúc thi công

- Cổng :4000 đã có tiến trình chạy sẵn. Theo đúng bẫy đã ghi, KHÔNG tin ngay mà kiểm hai bước:
  `lsof` xác nhận cwd là chính checkout này, rồi `curl /docs-json` xác nhận schema sống đã có
  `partnerName` ở cả 4 DTO (và chưa có `revision`, đúng vì đó là việc của T-03-04). Đó là tiến
  trình watch, đã tự nạp thay đổi — nên không cần bật thêm và cũng không chạy `build` song song.
- Kết quả: 8/8 DTO (4 create + 4 update) mang `partnerName` trong snapshot.
