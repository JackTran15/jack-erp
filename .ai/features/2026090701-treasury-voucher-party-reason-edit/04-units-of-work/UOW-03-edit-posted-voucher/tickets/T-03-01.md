# T-03-01 — Migration thêm cột revision cho 4 bảng phiếu

## Context

`revision` là khoá chống ghi đè đồng thời của ADR-06 và là số phân biệt lần sửa trong ghi chú
bút toán điều chỉnh. Bên kho đã dùng đúng cột này cho cùng mục đích.

## Implementation notes

- `revision int NOT NULL DEFAULT 0` trên `cash_receipts`, `cash_payments`, `bank_receipts`,
  `bank_payments`
- **Viết tay migration**, đừng chạy `migration:generate` — nó sinh drift khổng lồ trên repo này
- Không cần `mode: 'each'`: đây là `ADD COLUMN` thuần, không phải `ALTER TYPE ... ADD VALUE`
- `down()` drop cả 4 cột
- Thêm `@Column({ type: 'int', default: 0 }) revision: number;` vào 4 entity. Cẩn thận với bẫy
  TypeORM: entity con không override được cột kế thừa từ base — khai tường minh trên từng entity
