# T-01-01 — Mapper cột đọc width backend, fallback 160/112 theo dataType

## Context
`mapHeadersToTableConfig` (`invoice-report.api.ts`) là điểm vào duy nhất cho cột từ API
của cả 4 nguồn (A-04). Nó gán cứng `DEFAULT_REPORT_COLUMN_WIDTH` = 112 và bỏ qua
`h.width`. Backend kho đã điền width; 3 nhóm còn lại nhận width cột định danh từ T-01-04
(A-03), phần còn lại (cột số) cần fallback theo `dataType` (A-01).

## Implementation notes
- `lib/table/report-table.ts`: thêm `DEFAULT_REPORT_TEXT_COLUMN_WIDTH = 160` và
  `defaultReportColumnWidth(dataType)` — text → 160, còn lại → 112. `lib/table/index.ts`
  đã `export *`.
- `mapHeadersToTableConfig`: tính `dataType = feDataType(h.type)` một lần, dùng cho cả
  `dataType` và `width: h.width ?? defaultReportColumnWidth(dataType)`.
- Không đụng registry FE, không thêm field vào `ReportColumnTableConfig`. Phần backend ở T-01-04.
