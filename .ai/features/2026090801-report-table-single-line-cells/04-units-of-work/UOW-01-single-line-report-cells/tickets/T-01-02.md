# T-01-02 — Ô tbody/tfoot một dòng

## Context
`<td>` trong `ReportPageTableView` chỉ có `h-8 px-2 py-0 align-middle`; bảng
`width: max-content` + layout auto nên `truncate` một mình không cắt được (A-08). Header
giữ nguyên theo A-02. Drill-down dialog render cùng component nên tự nhận thay đổi.

## Implementation notes
- tbody `<td>`: style thêm `maxWidth: width`; class thêm `truncate`;
  `title` = `display` khi `!isReportNumberColumn(col)` và `display` là chuỗi khác rỗng.
- tfoot `<td>`: `const width = column.getSize()`; style `{ maxWidth: width, ...withStickyBottom(...) }`;
  class thêm `truncate`.
- Không đụng `SortableHeaderCell`, `FilterHeaderCell`, group header.
- `<a>` drill-down và `<span>` indent là inline nên ellipsis áp ở `<td>` là đủ.
