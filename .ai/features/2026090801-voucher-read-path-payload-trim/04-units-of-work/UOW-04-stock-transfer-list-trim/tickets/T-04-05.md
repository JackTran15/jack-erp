# T-04-05 — `StockTransferPage` đọc dòng từ endpoint phân trang

## Context
Trang này **chưa từng** fetch khi đổi hàng đang chọn — comment ở `:322-324` nói thẳng: "DetailPanel
đọc `lines` sẵn có trong row". Sau T-04-02 mảng đó không còn, nên phải đổi ba chỗ:

| Chỗ | Dòng | Hiện tại |
| --- | --- | --- |
| Panel "Chi tiết" | `:645`, `:665` | `transfer.lines.length`, `transfer.lines.map(...)` |
| Dialog Sửa/Xem seed form | `:831`, `:833`, `:1069` | `initial.lines` |
| Cột Tổng tiền | `:181-184` | đã ưu tiên `t.totalAmount` — **không cần sửa** (A-10) |

## Implementation notes
- Panel: `useInfiniteQuery` + sentinel + `IntersectionObserver`, khuôn `PurchaseOrdersPage.tsx:968-1010`.
- Dialog Sửa/Xem: `await fetchTransferWithLines(id)` **xong mới** `setDialogMode` (ADR-02). Mở
  dialog Sửa với `lines` rỗng rồi bấm Lưu là ghi đè phiếu bằng mảng rỗng — mất dữ liệu, chỉ lộ ra
  sau khi lưu.
- Kiểm mọi effect trong dialog bám vào `initial.lines` (`:1265`, `:1317` giải kệ ưu tiên / đoán
  kho nguồn): chúng phải chạy **sau** khi dòng về, hoặc bị chặn ở chế độ xem.
- `transferTotal` giữ nguyên. Nếu cột Tổng tiền lệch sau khi sửa thì lỗi ở T-04-02, không ở đây.
