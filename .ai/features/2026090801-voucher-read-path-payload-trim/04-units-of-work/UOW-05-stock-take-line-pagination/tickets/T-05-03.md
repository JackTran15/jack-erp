# T-05-03 — `CqrsModule` + controller v2 + `includeLines` cho Kiểm kê

## Context
Module này chưa có CQRS và chưa có controller v2 — khác `goods-receipt`, `goods-issue`,
`transfer-order`, `transfer`. Khuôn controller: `goods-receipt-v2.controller.ts`.

## Implementation notes
- `@Controller('inventory/stock-takes')` dưới prefix `v2`, khớp cách bốn controller v2 kia đặt tên.
- Quyền `inventory.read` + `@RequireBranchScope()`, khớp `GET /inventory/stock-takes/:id`
  (`stock-take.controller.ts:367-375`).
- Thêm `VoucherDetailQueryDto` vào `GET /:id`. **Chỉ cắt `lines`; `members` vẫn đi kèm** (ADR-09)
  — panel cần members và members không tỉ lệ với kích thước phiếu.
- Cả `lines` lẫn `members` đều `eager: true` (`stock-take.entity.ts:89-97`), nên cắt phải làm ở
  tầng truy vấn: `loadEagerRelations: false` rồi nạp lại **chỉ** `members`, hoặc QueryBuilder.
- Import `CqrsModule` và đăng ký handler vào providers.
- `pnpm openapi:generate` + commit. Nối đuôi UOW-03/UOW-04 ở bước này.
