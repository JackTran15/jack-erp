# T-06-02 — Hook badge đổi nguồn + gate quyền

## Context
```ts
const { data } = await apiClient.get<unknown[]>("/inventory/transfer-orders/importable");
return data.length;
```
Hook tải cả danh sách rồi đếm, và **không kiểm quyền** — trong khi route đòi
`inventory.transfer.read` (`transfer-order.controller.ts:383-385`). Tài khoản thiếu quyền ăn 403
trên mọi trang.

Lưu ý: tab được gate bằng `inventory.transfer.import` (`inventoryNavigation.ts:32`), **khác** quyền
của route. Gate hook theo quyền của **route** (A-11) — gate theo quyền của tab sẽ vẫn 403 với ai
có `import` mà thiếu `read`.

## Implementation notes
- Đổi sang `/inventory/transfer-orders/importable/count`, trả `data.count`.
- Thêm vào `enabled`: `hasPermission("inventory.transfer.read")` — dùng `usePermissionCheck` /
  `hasPermission` như phần còn lại của repo, không tự đọc localStorage.
- Giữ nguyên `queryKey` (kèm `activeBranchId`) và `staleTime: 30_000`; ba nơi mount vẫn gộp một request.
- `GoodsReceiptFormDialog.tsx:1385` invalidate theo key này — giữ key không đổi để lượt invalidate
  đó còn tác dụng.
