# T-07-04 — e2e: thu hồi phiên và đổi vai trò vẫn tức thì

## Context
Đây là ticket **chứng minh** của UOW-07. Unit spec đã kiểm từng mảnh; e2e kiểm cái duy nhất mà
mảnh rời không kiểm được: cache và thu hồi cùng tồn tại mà không cái nào che cái nào.

## Implementation notes
- Kịch bản 1: đăng nhập → `/auth/session` (cache nóng) → đăng xuất → `/auth/session` bằng access
  token cũ → **401**.
- Kịch bản 2: `/auth/session` → đổi vai trò qua service → `/auth/session` → thấy vai trò mới,
  **không** chờ TTL.
- Kịch bản 3: `/branches/me` → bỏ gán một chi nhánh → `/branches/me` → chi nhánh biến mất ngay.
- Kịch bản 4: `/branches/me` → ngưng hoạt động một chi nhánh → chi nhánh biến mất ngay.
- Kịch bản 5: `refresh` sau khi đổi vai trò → JWT mới mang vai trò **mới** (chứng minh đường đúc
  token không đọc cache).
- Bẫy e2e của repo, đọc trước khi kết luận đỏ: boot suite ~215 s nên hook 60 s đỏ sẵn kể cả với
  spec cũ; `switch-branch` thu hồi phiên hiện tại; teardown kafkajs treo làm suite thoát khác 0 dù
  test pass — **đọc output thật, đừng tin exit code**.
