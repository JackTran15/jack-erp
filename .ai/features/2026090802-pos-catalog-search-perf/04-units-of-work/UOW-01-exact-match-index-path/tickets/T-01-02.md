# T-01-02 — lookupByCode chuyển sang UNION

## Context

trong `lookupByCode` bằng `WITH matched AS (<buildExactMatchCte>) SELECT … FROM matched m
JOIN items i ON i.id = m.id LEFT JOIN stock_balances sb …`.
