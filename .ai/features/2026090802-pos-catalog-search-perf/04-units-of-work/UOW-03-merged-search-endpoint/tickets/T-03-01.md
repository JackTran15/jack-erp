# T-03-01 — DTO cho endpoint gộp

## Context
`ValidationPipe` toàn cục dùng `whitelist: true, forbidNonWhitelisted: true`, nên DTO
phải khai **mọi** trường được chấp nhận, nếu không request mang trường lạ sẽ 400.

## Implementation notes
`PosCatalogSearchQueryDto`:
- `q: string` — `@Transform(trim)` rồi `@IsNotEmpty()`
- `mode?: 'exact' | 'full'` — `@IsEnum`, mặc định `full`
- `view?: 'full' | 'suggest'` — `@IsEnum`, mặc định `full`
- `limit?: number` — `@Type(() => Number) @IsInt() @Min(1)`, **không** `@Max`:
  trần 100 là kẹp im lặng ở handler, không phải lỗi 400 (AC-06, ADR-02)
- `includeUntracked?: boolean` — cùng khuôn với `PosCatalogQueryDto` hiện có

`PosCatalogSearchResponseDto`:
- `exact: PosCatalogLineDto | null`
- `suggestions: PosCatalogLineDto[]` khi `view=full`, `PosCatalogSuggestionDto[]` khi `view=suggest`

`PosCatalogSuggestionDto` = `itemId`, `productId`, `code`, `name`, `unit`,
`sellingPrice`, `sellableQuantity`, `defaultLocationId`.
**Không** có `locations`, **không** có `quantityOnHand` (ADR-03).
`sellableQuantity` bắt buộc giữ — nó là cơ sở cảnh báo bán vượt tồn
([[project_pos_stock_warning_temp_warehouse]]).

- Mọi trường có `@ApiProperty` với `type` tường minh — nếu không, `/docs-json` sinh
  schema rỗng và `api-client` ra `unknown`.
- Comment tiếng Anh.

## Done when
- [x] `q` rỗng hoặc chỉ khoảng trắng → 400
- [x] `mode=bogus` → 400
- [x] Trường lạ trong query → 400 (`forbidNonWhitelisted`)
- [x] `limit=5000` → **không** 400 (kẹp ở handler)
- [x] Cả ba DTO xuất từ `dto/index.ts`

## Bằng chứng (2026-09-08)

`pos-catalog-search.query.dto.spec.ts` — 9 ca xanh, chạy DTO qua **đúng** cấu hình
`ValidationPipe` toàn cục (`whitelist`, `transform`, `forbidNonWhitelisted` — `main.ts:33`),
nên cái gì qua được ở đây là cái qua được trên production:

- `q` rỗng / chỉ khoảng trắng / thiếu → reject
- `q` được trim trước khi kiểm rỗng
- `limit` ép kiểu từ chuỗi query-string; `abc` và `0` → reject
- `limit=5000` → **qua được** (kẹp trần ở handler, không phải 400) — AC-06
- `mode`/`view` ngoài enum → reject
- `includeUntracked` đọc được `true` / `1` / `false`
- Tham số lạ (`direction`) → reject nhờ `forbidNonWhitelisted`

`tsc --noEmit` sạch.
