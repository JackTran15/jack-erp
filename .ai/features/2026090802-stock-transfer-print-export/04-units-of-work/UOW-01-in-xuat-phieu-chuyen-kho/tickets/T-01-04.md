# T-01-04 — Bật nút In / Xuất khẩu trên dialog phiếu chuyển kho

## Context
`TransferFormDialog` trong `StockTransferPage.tsx` có hai mục toolbar `print`/`export` bị
`disabled: true`. Chép `handlePrint`/`handleExport` từ `TransferOrdersPage.tsx:1235-1263`.

## Implementation notes
- `voucher-print.api.ts`: `[VoucherKind.STOCK_TRANSFER]: (id) => \`/inventory/stock/transfers/${id}/print-payload\``.
- `voucher-export.api.ts`: `EXPORT_PATH` tương ứng `/export`; `FALLBACK_FILENAME` = `phieu-chuyen-kho.xlsx`.
- Dialog: state `printing`/`exporting`; `canPrint = mode !== "create" && Boolean(initial?.id)`; hai handler try/catch/finally với `toast.error(getUserFacingApiErrorMessage(err))`; toolbar `disabled: !canPrint || printing` / `|| exporting`.
- Import `fetchVoucherPrintPayload`, `downloadVoucherExcel`, `renderVoucherHtml`, `printHtmlDocument`, `VoucherKind`.
