# T-03-01 — addProductByQuery hỏi server

## Context
Hiện tại (`use-checkout-cart-actions.ts:70-88`) rẽ ba nhánh trên
`filteredProducts.length`, mà `filteredProducts` là `catalog.filter(...)` trên mảng
10 400 phần tử. Ba nhánh chỉ đọc `=== 1`, `=== 0`, `else` — nên `limit=2` là đủ (A-05).

## Implementation notes
```ts
const addProductByQuery = useCallback(async () => {
  const ui = usePosCheckoutUiStore.getState();
  const toolbar = selectCatalogDraft(usePosCheckoutSessionStore.getState()).toolbar;
  const term = toolbar.query.trim();
  if (!term || !branchId) { ui.setCartError(CHECKOUT_ERRORS.PRODUCT_NOT_FOUND); return; }
  const { suggestions } = await searchCatalog(branchId, {
    q: term, view: "suggest", limit: 2,
  });
  // ba nhánh y như cũ, chỉ đổi nguồn mảng
}, [...]);
```
- Dùng `useSearchPosCatalog` sẵn có (feature trước), **không** thêm hook mới.
- Kiểu trả đổi `void` → `Promise<void>`; sửa khai báo trong `UseCheckoutCartActionsResult`.
- Caller duy nhất là `ProductSearchInput.handleSubmitQuery`, vốn đã gọi trong `.then()`
  — kiểm lại nó vẫn không await nhầm chỗ.
- Lỗi mạng: bắt và báo `PRODUCT_NOT_FOUND`. Im lặng ở đây nghĩa là Enter không làm gì
  cả, thu ngân bấm lại mà không biết vì sao.
- **Không** đụng `filteredProducts` trong file này ở ticket này; T-03-03 gỡ.

**Nói thẳng:** hai toast 0-khớp và nhiều-khớp **chưa được nhìn thấy lại trên UI** ở

chập chờn (chuỗi không vào được ô), rồi phiên trình duyệt hỏng hẳn
(`Cannot access a chrome-extension:// URL`). Dừng thay vì thử lại mù.

thấy trong phiên này ở [[project_pos_catalog_search_perf]], và mã dựng dialog
(`setCartError` → cùng component) **không đổi** trong feature này — thứ duy nhất đổi
là nguồn của con số đếm, và con số đó đã đo ở bảng trên.

### BUG tự gây, phát hiện nhờ đếm request — `limit` thiếu trong cache key

Lần chạy đầu, `addProductByQuery` **không phát request nào**: `CATALOG_KEYS.SEARCH_V2`
không có `limit`, nên lời gọi `limit=2` trúng entry cache của ô tìm (`limit=20`) và
im lặng nhận lại 20 dòng.

Ở ca này nó vô hại (0/1/nhiều ra cùng kết quả với 2 hay 20), nhưng key không mô tả
đúng giá trị là bug thật: một caller sau xin `limit=5` sẽ nhận 20 dòng mà không có
dấu hiệu gì. Đã thêm `limit` vào key + 3 test
(`react-query-key.constant.test.ts`). Chỉ phát hiện được vì đếm request thay vì tin
là "chắc nó gọi rồi".
