# T-03-02 — openForQuery hỏi server

## Context
`use-checkout-variant-selection.ts:88-96` rẽ ba nhánh trên cùng `filteredProducts`, rồi
nhánh "khớp 1" gọi `openForItem(line)` — hàm này chỉ đọc `line.productId`, `line.itemId`
và `line.name`.

Cả ba trường đó **có** trong `PosCatalogSuggestion` (`view=suggest` chỉ bỏ `locations`
và `quantityOnHand`), nên không cần shape đầy đủ.

## Implementation notes
- Cùng khuôn T-03-01: `searchCatalog(branchId, { q: term, view: "suggest", limit: 2 })`.
- `openForItem` nới kiểu tham số `PosCatalogLine` → `PosCatalogSuggestion`. Caller cũ
  truyền `PosCatalogLine` vẫn vào được (structural typing), như đã làm với
  `addProductByItem` ở feature trước.
- `openForQuery` đổi `void` → `Promise<void>`; sửa khai báo interface.
- Kiểm caller của `openForQuery` — nếu nó nằm trong một handler đồng bộ thì bọc `void`.
