# T-02-01 — Prop tắt danh sách gợi ý

## Context

Ba cách tắt dropdown, hai cách hỏng — đã đọc code để loại (A-01, ADR-01):

| Cách | Vì sao không |
|---|---|
| Trả `[]` từ `search` | `showDropdown` (`:493`) không phụ thuộc số gợi ý → vẫn render "Không có kết quả." (`:654`) |
| Đặt `minChars` rất lớn | `:362` cũng dùng `minChars` để bỏ qua debounce+`search` → **giết auto-add mã vạch** |
| Tháo popover, dùng `<input>` | Phải dựng lại debounce, bàn phím, clear, Enter — chép 4 thứ để bỏ 1 |

## Implementation notes

Thêm đúng một prop:

```ts
/**
 * Hide the suggestion list while still running `search` after the debounce.
 * For inputs whose results are rendered somewhere else (the product grid) but
 * that still need the `search` call, because that call is where barcode
 * auto-add lives. Defaults to false — every existing call site is unaffected.
 */
suppressSuggestions?: boolean;
```

- Mặc định `false`.
- `const showDropdown = !suppressSuggestions && open && trimmed.length >= minChars;`
  Đây là chỗ **duy nhất** được đụng. Không sửa `:362`, không sửa `runSearch`, không sửa
  điều hướng bàn phím.
- `aria-expanded` (`:581`) đi theo `showDropdown` nên tự đúng.
- Chú thích phải nói rõ vì sao `search` vẫn chạy — người sửa sau rất dễ "tối ưu" bằng cách
  bỏ luôn lượt gọi khi không hiện danh sách, và đó chính là lúc máy quét chết.
