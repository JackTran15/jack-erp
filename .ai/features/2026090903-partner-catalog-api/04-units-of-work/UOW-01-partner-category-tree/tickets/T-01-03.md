# T-01-03 — Query + handler cây nhóm hàng, productCount cộng dồn lên nhánh cha

## Context

ADR-04. Mẫu để copy: `modules/inventory/location/queries/search-item-category-tree.handler.ts`
(đã dựng cây adjacency-list trong RAM). Khác biệt: thêm `productCount` và cộng dồn lên nhánh cha.

## Implementation notes

- Hai truy vấn chạy `Promise.all`:
  1. nhóm ACTIVE của `actor.organizationId`;
  2. `SELECT i.category_id, COUNT(DISTINCT i.product_id) FROM items i WHERE i.organization_id = $1
     AND i.is_active = true AND i.product_id IS NOT NULL GROUP BY i.category_id`.
- Dựng cây rồi duyệt **hậu thứ tự**, cộng `productCount` từ lá lên gốc. Đây chính là lỗi D1 của
  feature báo cáo kho: nhóm cha hầu như không có item gắn trực tiếp, chỉ đếm trực tiếp thì
  "GIÀY DÉP" ra 0 (AC-03).
- `category-subtree.util.ts` export `collectCategorySubtreeIds(rootId, rows): string[]` — T-02-03
  dùng lại cho bộ lọc `categoryId`. Tách ra file riêng vì hai ticket ở hai UoW cùng cần nó;
  để trong handler thì ticket sau phải sửa file của ticket trước.
- Cây có thể nhiều gốc; `parentId` của gốc là `null`.
- Không trả `description`, `status`, `branchId`, `createdBy`.
