# T-01-04 — Controller cây nhóm hàng + OpenAPI + e2e xác thực

## Context

Endpoint đầu tiên chạm được của bề mặt đối tác, nên cũng là chỗ chứng minh đường xác thực
`X-Api-Key` chạy end-to-end.

## Implementation notes

- `@Controller('partner/catalog')`, `@Post('categories/tree')`, `@Version('2')` ⇒
  `POST /v2/partner/catalog/categories/tree`. URI versioning là toàn cục (`main.ts:48-51`) —
  KHÔNG tự thêm tiền tố `v2` vào chuỗi `@Controller`.
- `@UseGuards(PermissionGuard)` + `@RequirePermission('partner.catalog.read')`. KHÔNG `@Public()`.
  KHÔNG `BranchScopeGuard` — danh mục là dữ liệu cấp tổ chức.
- `@ApiOkResponse({ type: PartnerCategoryTreeResponseDto })` + `@ApiSecurity('api-key')` +
  `@ApiTags('Partner catalog')`, theo mẫu `inventory-item-v2.controller.ts:27`. Đây là chỗ đầu tiên
  trong repo dùng `@ApiSecurity` — scheme `'api-key'` đã khai sẵn ở `main.ts:112-115`.
- Controller chỉ dispatch `QueryBus`.
- e2e dựng theo `api-key-guard.e2e-spec.ts`: tạo key thật, gán role Đối tác, gửi kèm
  `X-Forwarded-For` nằm trong whitelist. **Ticket này tạo file e2e**; các ticket sau nối thêm vào
  cùng file và đã khai `depends_on` để không đụng nhau.
- **Bẫy đã ghi trong repo:** e2e boot ~215s, hook 60s đỏ sẵn kể cả với spec cũ; poller outbox có
  thể đua `resetDatabase()` làm suite thoát 1 dù test pass. Đọc output thật, đừng tin exit code.
