# T-02-05 — Controller tìm sản phẩm + nối sắp xếp + OpenAPI

## Context

Ghép slice tìm kiếm thành endpoint gọi được: nối bảng sắp xếp của T-02-04 vào handler, phơi
route, và chứng minh end-to-end bằng API key.

## Implementation notes

- `@Post('products/search')` + `@Version('2')` trên `@Controller('partner/catalog')`.
- **Thứ tự đăng ký route:** controller này sẽ có cả route tĩnh (`products/search`) lẫn route động
  (`products/:productId`, T-04-03). Express 5 khớp theo thứ tự đăng ký — cảnh báo đã ghi ở
  `inventory-location.module.ts:114-122`. Đặt `products/search` trước `products/:productId` trong cùng
  class. Hôm nay hai route khác HTTP method nên chưa đụng nhau; ràng buộc này để lần sau ai đó thêm
  `GET products/search` thì không vỡ âm thầm.
- `@ApiOkResponse` + `@ApiSecurity('api-key')` + `@RequirePermission('partner.catalog.read')`.
- Nối `partner-product-sort.ts` vào handler ở ticket này (T-02-04 chỉ viết bảng tra cứu).
