# T-05-02 — e2e chứng minh key đối tác không mở được endpoint kho nội bộ

## Context

ADR-02 nói mục tiêu bảo mật chỉ đứng vững nếu quyền của key đối tác không chạm tới endpoint
kho nội bộ. Đây là test biến câu đó thành thứ kiểm được.

## Implementation notes

- Tạo một API key gán role Đối tác (chỉ `partner.catalog.read`), rồi:
  - `POST /v2/inventory-items/search` → 403 (endpoint này trả `purchasePrice`);
  - `GET /inventory/items/products` → 403 (cũng trả giá vốn);
  - `POST /v2/partner/catalog/products/search` → 200.
- Thêm ca không credential → 401 (AC-21) và key thiếu quyền → 403 (AC-22), lần này ở cả 3 endpoint chứ
  không chỉ endpoint nhóm hàng như T-01-04.
- Dựng theo `api-key-guard.e2e-spec.ts` (đã có sẵn cách tạo key + `X-Forwarded-For` whitelist).
- **Bẫy:** e2e chạy nối tiếp, boot ~215s, `forceExit: true`, consumer kafkajs giữ handle mở nên teardown
  treo có thể giả dạng "suite failed" — đọc output test thật, đừng chỉ nhìn exit code.
