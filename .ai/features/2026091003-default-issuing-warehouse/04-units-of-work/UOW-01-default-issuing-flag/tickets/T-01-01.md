# T-01-01 — Migration is_default_issuing

## Context

Nhân bản `1784500000000-AddStorageDefaultReceiving.ts` với **hai khác biệt** ở
điều kiện backfill. Bản gốc chọn `is_main_storage = true` vì lịch sử `is_main_storage` từng
kiêm vai trò kho nhập mặc định. Với chiều xuất thì ngược lại: POS Kho tạm lọc bỏ sạch
`isMainStorage` (`use-fast-stock-transfer-data.ts:143-146`), nên gán cờ cho kho backing
showroom là gán cho đúng cái kho POS không bao giờ nhìn thấy — feature thành no-op mà không
có lỗi nào để lần. Xem ADR-04.

Hai cờ độc lập (A-02): không có ràng buộc chéo nào với `is_default_receiving`.

## Implementation notes

- Tên file và class theo quy ước `<epochMillis>-<PascalCase>.ts` /
  `<PascalCase><epochMillis>`, kèm thuộc tính `name`. Mốc gần nhất trong repo là
  `1789910000000-AddCatalogPaginationIndexes.ts`, nên `1789920000000` là mốc kế tiếp.
- Thứ tự trong `up()` bám đúng bản gốc: `ADD COLUMN` → `UPDATE` backfill → `CREATE UNIQUE INDEX`.
  Tạo index **sau** backfill để index không bao giờ nhìn thấy trạng thái trung gian.
- Backfill:
  ```sql
  UPDATE "storages" SET "is_default_issuing" = true
  WHERE "id" IN (
    SELECT DISTINCT ON ("branch_id") "id"
    FROM "storages"
    WHERE "is_main_storage" = false AND "is_active" = true AND "branch_id" IS NOT NULL
    ORDER BY "branch_id", "created_at" ASC, "id" ASC
  )
  ```
  `is_main_storage = false` và `is_active = true` là hai khác biệt so với bản gốc (xem A-03, ADR-04). Giữ `branch_id IS NOT NULL`.
- Index: `CREATE UNIQUE INDEX "UQ_storages_default_issuing_per_branch" ON "storages" ("branch_id") WHERE "is_default_issuing" = true`
- `down()`: drop index rồi drop column, cả hai dùng `IF EXISTS`.
- Entity: thêm cột ngay dưới `isDefaultReceiving` (`storage.entity.ts:21-22`), cùng kiểu và
  cùng dạng `comment`.
- **Không** chạy `pnpm migration:generate` — viết tay theo bản gốc. Generate sẽ bỏ mất backfill
  và tạo index thường thay vì partial index.

## Bằng chứng (2026-09-10)

- **Migration** `1789920000000-AddStorageDefaultIssuing.ts`: `ADD COLUMN` → backfill

  `created_at, id`) → `CREATE UNIQUE INDEX "UQ_storages_default_issuing_per_branch" ... WHERE is_default_issuing = true`;
  `down()` drop index rồi drop column. Chú thích nêu hai khác biệt so với migration kho nhập và lý do.
- **Entity:** thêm `isDefaultIssuing` ngay dưới `isDefaultReceiving`.
- **E2E** `storage-default-issuing.e2e-spec.ts` 7/7 trên `erp_test` (orchestrator chạy lại, xanh): cột mặc
  định false; partial unique index từ chối hai kho cùng chi nhánh (`23505`) và cho phép khác chi nhánh; một

  `pg_database` không còn DB đó. **Không** chạy trên `erp_test`, `erp_dev` hay `erp_dev_3008`.
