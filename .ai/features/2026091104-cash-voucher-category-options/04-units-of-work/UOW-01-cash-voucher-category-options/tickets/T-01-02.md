# T-01-02 — Đưa org đang có về danh sách mới

## Context

Seeder chỉ chạy lúc tạo org. `BANK_FEE` từng được thêm vào constant mà không có backfill, nên My Company trong
`erp_dev_3008` đến nay vẫn thiếu. Migration này đưa **mọi** org trong `organizations` về bảng "Danh sách đích"
(`03-logical-design.md`) mà không đè chỉnh sửa của org (ADR-01). Depends on T-01-01 vì e2e so kết quả với
`DEFAULT_CASH_VOUCHER_CATEGORIES` mới (AC-07).

## Implementation notes

- Danh sách là **literal trong migration**, không import constant — lý do như comment ở
  `1787500000001-BackfillDefaultCoaAccounts.ts`: migration mô tả dữ liệu tại thời điểm chạy.
- Set-based, không lặp theo org; thứ tự 3 bước:
  1. **Đổi tên**, 2 câu: `UPDATE cash_voucher_categories SET name = $new, updated_at = now() WHERE code = $code AND name = $old`
     (`CHI_TIEN_NUOC`: "Tiền nước" → "Tiền nước sinh hoạt"; `CHI_CCDC`: "Công cụ dụng cụ" → "Mua đồ dùng, công cụ, dụng cụ").
  2. **Đánh lại thứ tự**, một câu cho mỗi mã có `display_order` đổi:
     `UPDATE … SET display_order = $new, updated_at = now() WHERE code = $code AND display_order = $old`.
  3. **Chèn**, một câu cho mỗi mục trong 43 mục (không chỉ 14 mục mới, để lấp các mục thiếu sẵn như `BANK_FEE`):
     ```sql
     INSERT INTO cash_voucher_categories
       (organization_id, code, name, direction, is_active, display_order, created_by)
     SELECT o.id::varchar, $1, $2, $3::cash_voucher_category_direction_enum, true, $4, 'migration'
     FROM organizations o
     WHERE NOT EXISTS (
       SELECT 1 FROM cash_voucher_categories c
       WHERE c.organization_id = o.id::varchar AND c.code = $1)          -- tính cả dòng đã xoá mềm (A-08)
     AND NOT EXISTS (
       SELECT 1 FROM cash_voucher_categories c
       WHERE c.organization_id = o.id::varchar AND c.direction = $3::cash_voucher_category_direction_enum
         AND c.deleted_at IS NULL AND lower(btrim(c.name)) = lower(btrim($2)))  -- A-06
     ```
     `id`, `created_at`, `updated_at` lấy default của cột.
- `down()` là no-op, có comment: dòng đã chèn có thể đã được dòng phiếu tham chiếu; tên/thứ tự không phân biệt
  được với sửa tay về sau.
- `migrationsTransactionMode: 'each'` (`data-source.ts:50`) ⇒ lỗi giữa chừng rollback cả migration.
- Timestamp `1789930000000`: sau `1789920000000-AddStorageDefaultIssuing`. Trước khi tạo file, kiểm lại không có
  migration nào mới hơn trên `main`.
