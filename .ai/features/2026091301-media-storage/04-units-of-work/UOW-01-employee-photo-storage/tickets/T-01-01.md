# T-01-01 — MinIO local trong docker-compose, biến môi trường media, proxy Vite mô phỏng nginx

## Context

Repo chưa có object store nào (M1). Local phải giống production ở điểm quan trọng nhất: trình
duyệt gọi storage **cùng origin**, qua path mang tên bucket (A-06). Ở local, Vite dev server đóng
vai nginx.

## Implementation notes

- `docker-compose.yml`: thêm service `minio`. Image `minio/minio` ghim **một tag `RELEASE.*` cụ
  thể còn tải được**, không dùng `latest` — repo đã archive và không có image mới (A-03). Tra tag
  trên registry lúc làm, ghi tag và ngày tra vào comment. Lệnh `server /data --console-address :9001`;
  cổng `9000` (S3 API) và `9001` (console) — cả hai chưa bị service nào trong repo chiếm (M5).
  `MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD` lấy từ `MEDIA_S3_ACCESS_KEY` / `MEDIA_S3_SECRET_KEY` với
  default cho dev. Volume mới `erp-minio-data`, khai cạnh các volume ở `docker-compose.yml:98-104`.
- `apps/api/.env.example`: thêm 7 biến ở `03-logical-design.md` → Hạ tầng, giá trị local:
  `MEDIA_S3_ENDPOINT=http://localhost:9000`, `MEDIA_PUBLIC_BASE_URL=http://localhost:3000`,
  `MEDIA_S3_REGION=us-east-1`, `MEDIA_S3_ACCESS_KEY`, `MEDIA_S3_SECRET_KEY`,
  `MEDIA_BUCKET_PUBLIC=erp-media-public`, `MEDIA_BUCKET_PRIVATE=erp-media-private`.
- `apps/api/ecosystem.config.cjs:40-68`: thêm cả 7 biến vào whitelist env của PM2 — thiếu ở đây thì
  production không đọc được dù `.env` có (M4).
- `apps/backoffice-web/vite.config.ts`: `server.proxy` cho `/erp-media-public` và
  `/erp-media-private` → `http://localhost:9000`, `changeOrigin: false` (giữ `Host`), **không**
  rewrite path. Chữ ký presigned GET phủ path, đổi path là hỏng chữ ký.

## Done when

- [ ] `curl -i http://localhost:3000/erp-media-public/` trả XML lỗi của MinIO (qua proxy), không phải HTML của SPA
