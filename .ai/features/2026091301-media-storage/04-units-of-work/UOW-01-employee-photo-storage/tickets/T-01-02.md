# T-01-02 — Khung module media — bảng media_objects, entity, owner policies và stub mọi service

## Context

Ticket đầu tiên, không phụ thuộc gì. Quyết định ở G3 (Akenzy, 2026-09-13): **mọi** class của module
media được tạo ở đây dưới dạng stub rỗng và đăng ký sẵn trong `media.module.ts`, để không ticket nào
sau phải sửa file module — trước đó 9 cặp ticket chạy song song cùng sửa file này. Cùng cách
partner-catalog T-01-01 dựng khung mỏng để các slice sau cắm vào không tranh file.

Hằng số policy cũng nằm ở đây, để `MediaLinkService` (T-01-05) và API vé tải lên (T-01-04) cùng đọc
mà không phải chờ nhau.

## Implementation notes

- `media-object.entity.ts`: đúng các cột ở `03-logical-design.md` → Domain model; UUID PK
  `@PrimaryGeneratedColumn('uuid')`; `@CreateDateColumn` / `@UpdateDateColumn` UTC; **không** kế thừa
  `SoftDeleteEntity`. Enum `MediaOwnerType` và `MediaStatus` export từ file này.
- Migration viết tay (không `migration:generate`): bảng, unique `object_key`, index partial
  `(organization_id, owner_type, owner_id, sort_order) WHERE status = 'ATTACHED'`, index
  `(status, created_at)`; `down` xoá bảng.
- `media-owner-policies.ts`: `MEDIA_OWNER_POLICIES: Record<MediaOwnerType, { bucket: 'public' | 'private'; maxBytes; contentTypes: string[]; maxPerOwner; writePermissions: string[]; readPermissions: string[] }>`
  đúng bảng Owner policies của design. MIME: ảnh `image/jpeg`, `image/png`, `image/gif` (chỉ hàng
  hoá), `image/webp`; đính kèm thêm `application/pdf`, `application/vnd.ms-excel`,
  `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`, `application/msword`,
  `application/vnd.openxmlformats-officedocument.wordprocessingml.document`, `text/csv`.
- Stub: mỗi service/registry/job là `@Injectable() export class X {}` không constructor; hai
  controller là `@ApiTags('media') @Controller('media') export class X {}` không route nào; job chưa
  có `@Cron`. Stub không được có dependency, để module khởi động được trước khi thân được viết.
- `media.module.ts`: `@Global() @Module({ imports: [TypeOrmModule.forFeature([MediaObjectEntity])], controllers: [MediaUploadController, MediaDownloadController], providers: [ObjectStorageService, MediaUploadService, MediaLinkService, MediaQueryService, MediaOwnerReaderRegistry, MediaDownloadService, MediaCleanupJob], exports: [ObjectStorageService, MediaLinkService, MediaQueryService, MediaOwnerReaderRegistry] })`,
  cùng hình dạng `@Global()` với `apps/api/src/modules/redis/redis.module.ts:7-12`.
- **Kiểm trước khi đóng module**: T-01-04 và T-04-01 sẽ inject `RbacService`
  (`apps/api/src/modules/rbac/rbac.service.ts`). Nếu nó chưa sẵn có toàn cục, import module export nó
  ngay trong scaffold này — mục đích là sau T-01-02 không ai phải sửa `imports` của module nữa.
  `ConfigModule` đã global (`app.module.ts:58-70`), `ScheduleModule` đã đăng ký (`app.module.ts:95`).
- Đăng ký `MediaModule` trong mảng `imports` của `app.module.ts` (khối module nghiệp vụ `:100-140`).
