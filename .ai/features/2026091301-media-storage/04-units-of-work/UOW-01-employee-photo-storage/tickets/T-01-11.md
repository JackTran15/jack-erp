# T-01-11 — E2E — storage giả cho AppModule và kiểm vé tải lên

## Context

`test-app.ts:28-59` boot `AppModule` thật, chỉ override TypeORM; CI chỉ có Postgres và Redis
(`.github/workflows/ci.yml:17-40`). Muốn e2e đi qua luồng media mà không cần MinIO thì phải thay
`ObjectStorageService` bằng bản giả ở một chỗ duy nhất, để T-02-03 và T-04-09 dùng lại.

## Implementation notes

- `fake-object-storage.ts`: cài cùng các phương thức công khai của `ObjectStorageService`, lưu object
  trong `Map<key, { size, contentType }>`; có hàm `putFake(key, size, contentType)` để test giả lập
  việc trình duyệt đã tải file lên.
- `test-app.ts`: `.overrideProvider(ObjectStorageService).useValue(fake)` và export `fake` để spec dùng.
- `media-upload.e2e-spec.ts`:
  - Người dùng không có `inventory.write` xin vé `PRODUCT` → 403 (kiểm danh sách khoá cứng ở
    `test-app.ts:135-166` để chọn tài khoản đúng).
  - Admin xin vé → 201 có `upload.fields`.
  - `putFake` sai kích thước rồi `complete` → 400 `MEDIA_INVALID`; đúng kích thước → 200 `UPLOADED`.
- Suite chạy nối tiếp, `forceExit` (CLAUDE.md): đọc output test thật, không chỉ dòng exit.
