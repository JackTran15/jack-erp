# T-04-06 — Component danh sách đính kèm dùng chung — tải lên, gỡ, tải về

## Context

7 dialog đang có cùng một nút "Tài liệu đính kèm" bị disable, copy-paste ở hai kiểu layout
(`FieldRow` ở dialog kho, `FormField` ở dialog quỹ). Một component thay cả 7, để T-04-07 và T-04-08
mỗi dialog chỉ đổi đúng một hàng.

## Implementation notes

- `interface Props { ownerType; value: MediaAttachment[]; onChange: (ids: string[], items: MediaAttachment[]) => void; readOnly?: boolean }`,
  named export, không `export default`.
- Dùng `useMediaUpload(ownerType, value)` (T-01-09) cho tải lên và gỡ. **Hợp đồng hook** (re-review T-01-09,
  2026-09-14): `value` chỉ được nhận khi danh sách chưa bị đụng vào, và bị bỏ qua hẳn nếu đến sau lần `add()` đầu
  tiên. Dialog điền state sau khi mount, nên chỉ render component khi detail chứng từ đã nạp xong. `mediaIds` đã
  memo theo `files`; đẩy id lên cha trong handler, hoặc effect phụ thuộc `mediaIds`, không tạo mảng mới mỗi render.
  `retry` chỉ chạy với dòng lỗi còn giữ `file`; dòng bị chặn phía client thì không có nút thử lại. Mỗi dòng: tên file, kích thước
  định dạng `Intl` `vi-VN`, trạng thái, nút tải về, nút gỡ (ẩn khi `readOnly`).
- `media-download.api.ts`: `getDownloadUrl(id)` qua `erpApi` + `requireErpData`; bấm tải về thì gọi
  rồi `window.location.assign(url)` — response storage đã có `Content-Disposition: attachment`. Không
  đưa link vào query cache.
- Primitive từ `@erp/ui`, icon từ `lucide-react` (`Paperclip`, `Download`, `X`), `cn()` cho class.
  Chuỗi tiếng Việt.
