# T-04-08 — Bốn dialog chứng từ quỹ và ngân hàng dùng danh sách đính kèm thật

## Context

Hàng "Tài liệu đính kèm" bị disable, dùng `FormField`, nằm trong `generalInfo`:
`ReceiptVoucherDialog.tsx:861-867`, `PaymentVoucherDialog.tsx:1096-1102`,
`DepositPaymentVoucherDialog.tsx:1104-1107`, `DepositReceiptVoucherDialog.tsx:866-869`. Kiểu đã khai
`attachmentIds` nhưng không dialog nào gửi: `cash-vouchers.types.ts:128,154,333,388`,
`bank-vouchers.types.ts:81,120,159,184`.

## Implementation notes

- Thay đúng hàng disable bằng `<MediaAttachmentList ownerType=... />` (T-04-06):
  `CASH_RECEIPT`, `CASH_PAYMENT`, `BANK_PAYMENT`, `BANK_RECEIPT` theo thứ tự 4 dialog trên.
- Nạp `attachments` từ detail khi mở; gửi `attachmentIds` trong payload tạo và sửa.
- `readOnly` theo đúng điều kiện mà dialog đang dùng để khoá các trường khác — chứng từ đã đảo,
  không phải nhập tay, đã xoá (luật `assertEditable`, `editable-voucher.util.ts:43-66`).
- Thêm kiểu `attachments` vào response detail ở hai file types.
- Khoá nút lưu khi đang tải file.
