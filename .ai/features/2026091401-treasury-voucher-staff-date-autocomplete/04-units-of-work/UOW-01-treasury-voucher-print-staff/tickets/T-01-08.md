# T-01-08 — Khuôn in quay về không có tên dưới chữ ký

## Context

T-01-01 thêm `signatureNames?: (string | null)[]` vào `VoucherPrintPayload` và dạy `render-voucher-html.ts` /
`voucher-xlsx.writer.ts` in tên dưới chữ ký. Sau T-01-07 không mapper nào đặt trường này nữa (A-17, ADR-08), nên nó là
code chết do chính feature này tạo ra — gỡ đi (Akenzy chọn "Bỏ hẳn phần in tên").

T-01-01 là thay đổi duy nhất trên 5 file trong `touches` kể từ `main`, nên đích đến là **nội dung của `main`** cho cả 5
file. Depends on T-01-07 vì còn mapper đặt `signatureNames` thì gỡ trường sẽ vỡ type.

## Implementation notes

- Trước khi sửa: `git log --oneline main..HEAD -- <5 file>` và `git diff main -- <5 file>` — xác nhận diff chỉ là phần
  của T-01-01. Nếu có thay đổi khác thì chỉ gỡ phần `signatureNames` / `.signature-name` / `SIGNATURE_NAME_GAP_ROWS` /
  `writeSignatureNames`, không đè thay đổi kia.
- Nếu diff đúng chỉ là T-01-01: đưa từng file về nội dung `main` bằng `git show main:<path> > <path>` (không dùng
  `git checkout` / `git stash` / `git restore` trên cây làm việc chung).
- Chạy `pnpm build:shared` sau khi sửa `voucher-payload.ts`.
