# T-03-02 — Các thẻ input viết tay

## Context

T-03-01 phủ mọi ô đi qua `@erp/ui`. Phần còn lại là thẻ `<input>` viết tay. Quét ngày 14/09/2026 (script bên dưới) tìm
thấy các ô dạng text / search / number / tel / email không có `autoComplete` trong 16 file ở `touches`. Ô `type="date"`
bỏ qua (Chrome không gợi ý lịch sử trên ô ngày), checkbox / radio / file / hidden cũng bỏ qua. Theo A-02, trang đăng ký
org / chi nhánh (onboarding) cũng thuộc backoffice nên cũng tắt.

Không phụ thuộc T-03-01: không file chung.

## Implementation notes

- Thêm `autoComplete="off"` vào từng thẻ `<input>` text-like thiếu thuộc tính. Không đổi gì khác trên dòng đó.
- `BaseDataTable.tsx:487` dùng `type={kind}` biến — thêm thuộc tính bất kể `kind`.
- `FilterHeaderCell.tsx:110` `type` là biến — như trên.
- Script quét (chạy từ gốc repo, `python3`):
  ```python
  import re, pathlib
  for p in pathlib.Path('apps/backoffice-web/src').rglob('*.tsx'):
      s = p.read_text()
      for m in re.finditer(r'<input\b', s):
          end = s.find('/>', m.start()); tag = s[m.start():end if end != -1 else m.start() + 400]
          t = re.search(r'type=["{]\s*"?([a-z]+)', tag)
          if t and t.group(1) in ('checkbox', 'radio', 'file', 'hidden', 'date', 'range', 'color'): continue
          if 'autoComplete' not in tag:
              print(f"{p}:{s[:m.start()].count(chr(10)) + 1}")
  ```
  Kết quả được phép còn lại: dòng comment trong `LookupField.tsx` (chữ `<input>` trong docblock, không phải thẻ).
