# T-01-04 — Tải ảnh trên dòng

## Context
Ba helper đã có trong `lib/media/media-upload.api.ts`: `createUpload(body)` → vé,
`uploadToStorage(upload, file, signal)` → `fetch` trần lên storage, `completeUpload(mediaId)`.
`useMediaUpload` là hook theo form; ở đây cần một **hàm** chạy được ngoài React cho N file, dùng
chung với trang ảnh nhanh (T-02-03), nên viết `uploadGoodsImages`. Thông điệp lỗi tiếng Việt lấy
theo bảng Error taxonomy của `03-logical-design.md`; chuỗi giới hạn dùng lại của
`validateFileAgainstLimits`.

## Implementation notes
- `upload-goods-images.ts`: `uploadGoodsImages(ownerType: "PRODUCT" | "ITEM", files: File[],
  opts?: { signal?: AbortSignal; concurrency?: number }) → Promise<UploadedGoodsImage[]>` với
  `UploadedGoodsImage = { file, mediaId } | { file, error: string }`. Với mỗi file:
  `validateFileAgainstLimits` (lỗi ⇒ không gọi API) → `createUpload({ ownerType, fileName,
  contentType, size })` → `uploadToStorage` → `completeUpload`. Concurrency mặc định 3 (hàng đợi
  đơn giản, không thêm dependency). Map `UploadFailedError`/`HttpError` code `MEDIA_QUOTA_EXCEEDED`
  ⇒ "Hết hạn mức tải lên trong ngày, thử lại sau"; còn lại ⇒ "Tải ảnh thất bại, thử lại".
- `set-item-images.api.ts`: `setItemImages(assignments)` POST `/inventory/items/set-images` với
  `X-Idempotency-Key` derive từ `(id, imageIds)` đã sắp — copy cách băm FNV-1a của
  `set-item-active-status.api.ts`. Trả `{ updated, failed }`.
- `RowImageUploadButton` (`row: { type, id, code }`, `onDone`): `<input type="file" multiple
  accept=".jpg,.jpeg,.png,.gif,.webp">` ẩn + nút "Tải ảnh" (icon `FolderOpen`). Chọn > 10 ⇒ toast
  "Tối đa 10 ảnh", không tải. Chạy `uploadGoodsImages(type === "product" ? "PRODUCT" : "ITEM", files)`;
  nếu **bất kỳ** file lỗi ⇒ toast lỗi, **không** gọi `set-images` (tránh thay bộ ảnh bằng bộ thiếu);
  đủ ⇒ `setItemImages([{ id, imageIds }])`; `failed[0]` ⇒ toast theo reason; `updated` ⇒ `onDone(thumbnail)`.
  Trong lúc chạy: nút hiện "Đang tải…" và vô hiệu.
- Trang: `onDone` ⇒ `queryClient.setQueryData(["product-images", submitted], …)` cập nhật
  `thumbnailUrl`/`imageCount` của dòng rồi `invalidateQueries({ queryKey: ["product-images"] })`.
  Với bộ lọc MISSING, dòng vừa có ảnh biến mất sau refetch — đúng ý.
