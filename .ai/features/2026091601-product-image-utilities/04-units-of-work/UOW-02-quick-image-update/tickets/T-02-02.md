# T-02-02 — Trang Cập nhật ảnh nhanh (phần thả và phân loại)

## Context
Bố cục theo ảnh tham chiếu: header "Cập nhật k/N ảnh *(Chỉ hỗ trợ định dạng ảnh (.jpg, .jpeg,
.png, .gif, .webp) và dung lượng < 2MB)*", khối **Lưu ý** ba dòng (quy tắc `Mã SKU (STT)` 01..10
cho mẫu mã, `Mã SKU` cho hàng lẻ / biến thể — biến thể gắn vào mẫu mã, ghi đè ảnh đang có), lưới
thẻ ảnh (thumbnail, nút (x) góc, nút **Đổi ảnh** đè lên ảnh, tên file, dòng trạng thái), chân trang
**Quay lại** trái và **Cập nhật** phải. Mục menu "Cập nhật ảnh nhanh" đã được T-01-03 thêm vào
`InventoryItemsPage`; ticket này thêm **route** trong `App.tsx` và trang.

Trang này chỉ phân loại; tải lên và gắn là T-02-03. Vì thế ticket này **không** gọi `/media/uploads`.

## Implementation notes
- `quick-image-files.ts` — model thuần (không React) để T-02-03 dùng lại:
  `QuickImageFile { key, file, previewUrl, localError: string | null, resolved: ResolvedImageName | null,
  status: 'pending' | 'uploading' | 'done' | 'failed', error?: string }`;
  `classify(files, existing)`; `countUpdatable(list)` = số thẻ `localError == null && resolved.match
  != null && resolved.error == null`; `groupByOwner(list)` → `Map<ownerId, QuickImageFile[]>` đã sắp
  theo `seq` rồi tên (`Intl.Collator('vi', { numeric: true })`); `markDuplicateSeq(list)` đánh
  `DUPLICATE_SEQ` cho thẻ đến sau khi thả thêm (AC-16); `statusLabel(f)` → chuỗi tiếng Việt theo
  bảng Error taxonomy: "Mẫu mã X" / "Hàng hóa X" / "Gắn vào mẫu mã X (mã biến thể)" /
  "Không có mã SKU hàng hóa trùng tên ảnh" / "STT phải từ 01 đến 10" / "Trùng STT NN với file khác
  của mẫu mã X" / lỗi giới hạn.
- `resolve-image-names.api.ts`: `resolveImageNames(names)` POST `/v2/inventory-items/resolve-image-names`,
  tự chia lô 500, ghép kết quả theo thứ tự.
- Thả file: vùng thả (`onDrop`/`onDragOver`) + `<input type="file" multiple accept=…>`; với mỗi file
  `validateFileAgainstLimits("PRODUCT", file)` ⇒ `localError`; tạo `URL.createObjectURL`; gọi resolve
  cho các tên chưa lỗi; thẻ hiện "Đang kiểm tra…" trong lúc chờ. Thả thêm ⇒ nối vào cuối, thẻ cũ
  giữ nguyên, chạy `markDuplicateSeq` trên toàn danh sách.
- Thẻ: `<img loading="lazy">`, (x) ⇒ bỏ thẻ + `revokeObjectURL`; **Đổi ảnh** ⇒ input file đơn,
  thay `file`, phân loại lại một thẻ (resolve 1 tên). Thẻ `done` (T-02-03) không có Đổi ảnh.
- Header: "Cập nhật **k**/N ảnh" với k từ `countUpdatable` (A-16); N = số thẻ.
- Quay lại ⇒ `/admin/inventory-items` (T-02-03 thêm xác nhận khi đang tải). Nút Cập nhật ở ticket
  này: `disabled` khi k = 0, `onClick` để trống cho T-02-03 (không toast "đang triển khai").
- Route `/admin/inventory-items/images/quick` trong `App.tsx` cạnh route images.
- `useEffect` cleanup revoke mọi `previewUrl` khi unmount.
