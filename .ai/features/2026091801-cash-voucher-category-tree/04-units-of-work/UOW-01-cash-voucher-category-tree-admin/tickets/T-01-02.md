## Implementation notes

- DTO: `SearchCashVoucherCategoryTreeDto { @IsOptional @IsString search?; @IsOptional @IsEnum(CashVoucherCategoryDirection)
  direction?; @IsOptional @IsBoolean isActive? }`; `CashVoucherCategoryTreeNodeDto { id, code, name, description|null,
  direction, isActive, displayOrder, parentGroupId|null, children: [] }` với `@ApiProperty` đầy đủ (Swagger sinh
  type cho api-client); `SearchCashVoucherCategoryTreeResponseDto { data }`.
- Handler: `repo.find({ where: { organizationId, direction?, isActive? }, order: { displayOrder: 'ASC', name: 'ASC' } })`;
  `byId`; `isRoot = !parentGroupId || !byId.has(parentGroupId)`; `childrenOf` giữ thứ tự `all`; `search` tỉa cây
  y hệt handler Nhóm hàng hoá (node khớp giữ nguyên cả con cháu; không khớp giữ nếu có con khớp).
- Controller: `@ApiTags('cash-voucher-categories') @Controller('cash-voucher-categories') @UseGuards(PermissionGuard)`,
  `@Post('tree') @Version('2') @RequirePermission('accounting.cash_voucher_category.read')`, dispatch qua `QueryBus`.
- Module: thêm controller vào `controllers`, handler vào `providers`.
- Spec (repo mock): lồng đúng; anh em theo `displayOrder` rồi `name`; `direction`/`isActive` truyền vào `where`;
  `search` giữ cha của node khớp và bỏ nhánh không khớp; mồ côi thành gốc; org khác không lẫn (kiểm `where`).
- Sau khi API chạy (:4000): `pnpm openapi:generate`; commit `schema.ts` + `openapi.snapshot.json`; kiểm
  `operations["CashVoucherCategoryTreeController_tree"]` có trong schema.
