# T-01-03 — Chế độ cây theo cấu hình

## Context

`CrudListPage.tsx` gắn cứng Nhóm hàng hoá: `isCategoryTree = entityKey === "inventory-item-categories"` (`:200`)
và bốn so sánh literal nữa (`:470` ô tên mở dialog sửa, `:638` `handleCreate` mở dialog, `:739` `handleRowClick`
chỉ chọn dòng, `:807` `handleEdit`), cộng nguồn dữ liệu `:244-288`, `:326`, ô Mã `:433-468`, thanh công cụ
`:854-878`, footer `:949`, `onSaveAndAddNew` `:962-971`. `useCrudApi.ts:115-117,142-144,161-163` invalidate
`["item-category-tree"]` theo literal. `itemCategoryTree.ts` map tay từng trường của node Nhóm hàng hoá.

`ItemCategoriesPage.tsx:35-37` và `ItemCategoryTreeSelect.tsx` vẫn dùng `useItemCategoryTree` — **không đụng**.

## Implementation notes

- `crudTree.ts`: `CrudTreeConfig { path; queryKey; searchKeys; filterKeys }` và `CRUD_TREE_ENTITIES` đúng như
  `03-logical-design.md` › Contracts › Frontend. `path` là union literal của hai đường dẫn để `erpApi.POST` type-check.
- `useCrudTree(entityKey, body, enabled)`: `useQuery({ queryKey: [cfg.queryKey, body], queryFn: erpApi.POST(cfg.path,
  { body }), enabled: enabled && Boolean(cfg), placeholderData: prev => prev })`. Response type generic
  `{ data: TreeNode[] }`.
- `itemCategoryTree.ts`: `flattenCategoryTree<N extends { id: string; children: N[] }>(nodes, collapsed?, depth?)`
  trả `Omit<N,'children'> & { __depth; __hasChildren; __collapsed }` bằng cách spread `...rest` (bỏ `children`);
  `collectParentIds` generic tương tự. Giữ tên export và `FlatCategoryRow`/`ItemCategoryTreeNode` cho caller cũ.
- `CrudListPage.tsx`: `const treeConfig = entityKey ? CRUD_TREE_ENTITIES[entityKey] : undefined; const
  isCategoryTree = Boolean(treeConfig)`; bốn literal → `isCategoryTree`; body cây = `{ search }` từ `searchKeys`
  (giá trị đầu tiên khác rỗng) + mỗi khoá trong `filterKeys` có `columnFilters[key]?.value` → pass-through, riêng
  `'true'|'false'` → boolean; **không** thêm khoá nào khi giá trị rỗng để body Nhóm hàng hoá vẫn là `{}`/`{ search }`
  (A-09). `useItemCategoryTree` trong trang thay bằng `useCrudTree`.
- `useCrudApi.ts`: `const tree = CRUD_TREE_ENTITIES[entityKey]; if (tree) void qc.invalidateQueries({ queryKey:
  [tree.queryKey] })` ở ba chỗ.
- Không đổi `DIALOG_MODE_ENTITIES`, `CRUD_V2_SEARCH`, `ENTITY_COLUMN_CONFIGS`.
