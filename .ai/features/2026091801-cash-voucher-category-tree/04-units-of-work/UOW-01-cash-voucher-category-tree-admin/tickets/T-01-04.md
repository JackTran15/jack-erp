## Implementation notes

- `CrudFormDialog.tsx`: `FORM_DEFAULTS: Record<string, Record<string, unknown>> = { "inventory-item-categories":
  { status: "ACTIVE" }, "cash-voucher-categories": { isActive: true } }`; áp ở hai chỗ khởi tạo/reset thay cho
  literal; `isItemCategory` → `isTreeEntity = Boolean(CRUD_TREE_ENTITIES[config.entityKey])`. Ở nhánh `relation`,
  nếu `config.entityKey === "cash-voucher-categories" && field.key === "parentGroupId"` và `values.direction` có giá
  trị → `filters={{ direction: values.direction }}` (thread `values` xuống `FieldInput` nếu chưa có).
- `TreeSelectInput.tsx`: prop `filters?: Record<string, unknown>`; khi có khoá → `query.filters = JSON.stringify(filters)`;
  đưa vào deps của `loadPage`; đổi `filters` ⇒ tải lại trang 1 (`replace: true`). `hydrateParents` giữ nguyên.
- `CrudFieldInput.tsx`: thêm `"cash-voucher-categories.parentGroupId": { entityKey: "cash-voucher-categories",
  placeholder: "Tìm theo mã hoặc tên mục thu/chi…" }`.
- `navConfig.ts`: sau `/admin/payment-accounts` thêm `{ to: "/admin/cash-voucher-categories", label: "Danh mục thu chi",
  permission: "accounting.cash_voucher_category.read" }`. Không sửa `App.tsx`.
