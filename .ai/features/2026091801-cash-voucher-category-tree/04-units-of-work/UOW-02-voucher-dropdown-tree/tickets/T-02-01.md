# T-02-01 — Dropdown theo cây

## Context

`use-cash-voucher-categories.ts:13-44` gọi `GET /admin/entities/cash-voucher-categories/records?pageSize=100&sortBy=
displayOrder&filters={direction}`; `useCategoryNameMap` (`:46-57`) và ba trang lưới/sổ quỹ dựa vào nó.
Bốn dialog render `<select>` thuần: `ReceiptVoucherDialog.tsx:509-536` (Mục thu), `PaymentVoucherDialog.tsx:579-606`
(Mục chi), `DepositReceiptVoucherDialog.tsx` (~`:478`), `DepositPaymentVoucherDialog.tsx:582-608` — option
`{c.name}`; `getValue` hiện tên ở chế độ xem. `flattenCategoryTree` generic có từ T-01-03.

## Implementation notes

- Hook: `erpApi.POST("/v2/cash-voucher-categories/tree", { body: direction ? { direction } : {} })` →
  `flattenCategoryTree(res.data)` → map thành `CashVoucherCategory` kèm `depth: row.__depth`, `parentGroupId`. Giữ
  `queryKey: treasuryQueryKeys.cashVoucherCategories(direction)`, `staleTime: 5 * 60_000`, **không** lọc `isActive`
  (A-11). Export `formatCategoryOptionLabel(c) = " ".repeat((c.depth ?? 0) * 3) + c.name`.
- `cash-vouchers.types.ts`: `CashVoucherCategory` thêm `parentGroupId?: string | null; depth?: number; displayOrder?: number`.
- 4 dialog: chỉ đổi text của `<option>` thành `formatCategoryOptionLabel(c)`; `getValue`, `onChange` (ghi `categoryId` +
  `category` = `c.name` gốc) không đổi. `DepositPaymentVoucherDialog.tsx:495,505` (tên cứng cho rút tiền/chuyển
  cửa hàng) không đụng.
