# T-01-02 — Entity + migration schema

## Context
Bảng toàn cục, mẫu `reporting/invoice-report/report-type.entity.ts`: `@Entity`, `@PrimaryGeneratedColumn('uuid')`,
không `organizationId`, không `SoftDeleteEntity`. e2e dựng schema bằng `synchronize(true)` từ decorator,
prod dựng bằng migration này — hai thứ phải cho ra cùng bảng, cùng index, cùng tên constraint.

## Implementation notes
- `geo_provinces`: `id uuid PK default gen_random_uuid()` (theo cách các migration hiện có tạo uuid —
  đọc `CreateReportTypes` và bắt chước), `code varchar(16) NOT NULL UNIQUE`, `name varchar(100) NOT NULL`,
  `is_active boolean NOT NULL DEFAULT true`, `effective_from date NOT NULL`, `merged_from jsonb NOT NULL DEFAULT '[]'`,
  `created_at`/`updated_at timestamptz NOT NULL DEFAULT now()`.
- `geo_wards`: `id`, `code varchar(8) NOT NULL`, `name varchar(100) NOT NULL`, `province_code varchar(16) NOT NULL`,
  `district_code varchar(8) NULL`, `is_current boolean NOT NULL DEFAULT false`, timestamps.
  `UNIQUE (province_code, code)`; index `(is_current)`; index `(province_code)`. **Không FK**.
- Entity: `@Column({ name: 'merged_from', type: 'jsonb' }) mergedFrom: { code: string; name: string }[]`;
  `@Column({ name: 'effective_from', type: 'date' }) effectiveFrom: string` (TypeORM trả `date` dạng chuỗi
  YYYY-MM-DD với driver pg — xác nhận khi viết DTO ở T-01-04). `@Unique(['provinceCode', 'code'])`,
  `@Index(['isCurrent'])`, `@Index(['provinceCode'])` — đặt **tên** index/constraint trùng với migration
  để `migration:generate` không thấy khác biệt.
- `down`: `DROP TABLE geo_wards; DROP TABLE geo_provinces`.
- Không đăng ký entity ở đâu ngoài `TypeOrmModule.forFeature` trong `GeoModule` (T-01-04); glob
  `**/*.entity.ts` của `data-source.ts` tự thấy.
