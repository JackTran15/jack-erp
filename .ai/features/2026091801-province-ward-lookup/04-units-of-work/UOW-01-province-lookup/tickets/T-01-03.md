# T-01-03 — Loader + migration dữ liệu

## Context
ADR-01: migration nạp, e2e nạp lại cùng hàm sau `resetDatabase()`. Loader vì thế không được phụ
thuộc Nest DI — nhận `QueryRunner | DataSource` và chạy SQL thô, để cả migration (`queryRunner`) lẫn
e2e (`app.get(DataSource)`) gọi được.

## Implementation notes
- `export interface GeoDataset { provinces: ProvinceSeed[]; wards: WardSeed[] }` với hình dạng đúng
  hai file JSON của T-01-01. `export async function upsertGeoDataset(runner, dataset): Promise<{ provinces: number; wards: number; current: number }>`.
- Tỉnh: một `INSERT ... VALUES ($1,$2,...),(...) ON CONFLICT (code) DO UPDATE SET name = EXCLUDED.name,
  is_active = EXCLUDED.is_active, effective_from = EXCLUDED.effective_from, merged_from = EXCLUDED.merged_from,
  updated_at = now()`. `merged_from` truyền `JSON.stringify(...)` với cast `::jsonb`.
- Phường: lô 1 000 dòng/câu, `ON CONFLICT (province_code, code) DO UPDATE SET name = EXCLUDED.name,
  district_code = EXCLUDED.district_code, updated_at = now()`. Tham số hoá (`$n`), không nối chuỗi.
- Cuối: `UPDATE geo_wards SET is_current = (province_code IN (SELECT code FROM geo_provinces))`; trả
  `current` = `SELECT count(*) ... WHERE is_current`.
- Migration `LoadGeoDataset2026`: `readFileSync(path.join(__dirname, 'data', 'geo-2026', 'provinces.json'))`
  + `wards.json`, `JSON.parse`, gọi loader với `queryRunner`, `console.log` một dòng số liệu.
  `down`: `TRUNCATE TABLE geo_wards, geo_provinces`.
- Migration import loader từ `../../modules/geo/geo-dataset.loader` — chấp nhận vì loader là hàm
  thuần không DI; dữ liệu (thứ cần bất biến) vẫn nằm cạnh migration.
- Kiểm A-06 khi có DB: `SELECT unaccent('Đà Nẵng Phường Đống Đa')` phải ra `Da Nang Phuong Dong Da`;
  ghi kết quả vào mục Done when.
