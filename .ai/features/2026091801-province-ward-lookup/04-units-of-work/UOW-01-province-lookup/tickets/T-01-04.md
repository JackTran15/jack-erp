# T-01-04 — Module + hai route provinces

## Context
ADR-03: chỉ `AuthGuard` toàn cục (đã là `APP_GUARD`), không `PermissionGuard`, không `@Actor()`.
`ValidationPipe` toàn cục `forbidNonWhitelisted` — DTO query phải khai đủ. Truy vấn đơn giản → service
thường, không CQRS.

## Implementation notes
- `GeoController`: `@ApiTags('Geo') @ApiBearerAuth() @ApiSecurity('api-key') @Controller('geo')`.
  Method `@Get('provinces') @Version('2')` và `@Get('provinces/:code') @Version('2')` — route tĩnh
  khai trước route có `:param` (giữ thứ tự khi T-02-01 thêm `wards`). `@ApiOkResponse({ type })`,
  `@ApiOperation({ summary })` tiếng Việt như các controller v2.
- `ProvinceListQueryDto { @IsOptional() @IsString() @MaxLength(100) q?: string }`;
  `ProvinceDto { code, name, isActive, effectiveFrom, mergedFrom: MergedFromDto[] }`;
  `ProvinceListResponseDto { data: ProvinceDto[] }`.
- `GeoService.listProvinces(q?)`: QueryBuilder trên `ProvinceEntity`, `orderBy('unaccent(lower(p.name))')
  .addOrderBy('p.code')`; nếu `q`: `andWhere("unaccent(lower(p.name)) LIKE '%' || unaccent(lower(:q)) || '%'", { q: escapeLikeTerm(q.trim()) })`.
  `q` rỗng sau trim → coi như không có.
- `findProvince(code)`: `findOne({ where: { code } })` → `NotFoundException('Không tìm thấy tỉnh/thành')`.
- Map entity → DTO ở service (hàm `toProvinceDto`), `effectiveFrom` là chuỗi `YYYY-MM-DD` (kiểm kiểu
  driver trả về; nếu là `Date`, format bằng `toISOString().slice(0,10)`).
- `GeoModule`: `TypeOrmModule.forFeature([ProvinceEntity, WardEntity])`, `controllers: [GeoController]`,
  `providers: [GeoService]`. Đăng ký trong `app.module.ts`.
- Không đọc `X-Branch-Id`, không lọc theo tổ chức — không có gì để lọc.
