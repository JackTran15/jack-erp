# T-02-01 — Hai route wards

## Context
Hợp đồng ở `03-logical-design.md` mục "GET /v2/geo/wards" và "/wards/:code". ADR-04: mặc định chỉ
hiện hành; `provinceCode` chỉ định thắng `includeLegacy`. Mã phường duy nhất trong thời kỳ (A-07).

## Implementation notes
- `WardSearchQueryDto`: `q?` (`@IsString @MaxLength(100)`), `provinceCode?` (`@IsString @MaxLength(16)`),
  `includeLegacy?: boolean` (`@IsOptional @Transform(({ value }) => value === 'true' || value === true) @IsBoolean`, mặc định `false`),
  `page = 1` (`@Type(() => Number) @IsInt @Min(1)`), `limit = 20` (`@IsInt @Min(1) @Max(100)`). Tất cả `@ApiPropertyOptional`.
- `WardFindQueryDto { provinceCode?: string }`.
- `WardDto { code, name, provinceCode, provinceName: string | null, districtCode: string | null, isCurrent }`;
  `WardSearchResponseDto { data: WardDto[]; total; page; limit }` — khai `nullable: true` ở `@ApiProperty` cho hai field null.
- `searchWards(dto)`: QueryBuilder `w` LEFT JOIN `ProvinceEntity p ON p.code = w.provinceCode`
  (`leftJoin(ProvinceEntity, 'p', 'p.code = w.province_code')` + `addSelect('p.name', 'provinceName')` hoặc `getRawMany` —
  chọn cách cho `getManyAndCount` không nhân đôi `total`; nếu dùng raw, đếm bằng query riêng cùng `where`).
  `where`: `provinceCode` → `w.province_code = :pc`; else nếu `!includeLegacy` → `w.is_current = true`;
  `q` → `unaccent(lower(w.name)) LIKE '%' || unaccent(lower(:q)) || '%'` với `escapeLikeTerm(q.trim())`.
  `orderBy('unaccent(lower(w.name))').addOrderBy('w.province_code').addOrderBy('w.code')`;
  `offset((page-1)*limit).limit(limit)`. `Promise.all([rows, count])`.
- `findWard(code, provinceCode?)`: `provinceCode` → `{ code, provinceCode }`; else `{ code, isCurrent: true }`;
  kèm LEFT JOIN tỉnh để có `provinceName`; không có → `NotFoundException('Không tìm thấy phường/xã')`.
- Controller: `@Get('wards') @Version('2')` khai **trước** `@Get('wards/:code') @Version('2')`; giữ hai route
  provinces phía trên. Cùng decorator Swagger như T-01-04.
- Đo: trên DB đã nạp, `EXPLAIN ANALYZE` câu `q=ba dinh` (không provinceCode) — ghi `Execution Time` vào Done when.
