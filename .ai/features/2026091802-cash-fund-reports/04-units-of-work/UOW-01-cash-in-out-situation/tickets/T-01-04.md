# T-01-04 — Templates, export, print

## Context

Toàn bộ là sao chép có đổi tên từ debt-report: `report_templates` dùng chung, phân biệt bằng
`domain`/`reportType`; `ExportPipeline` + `XlsxStreamWriter` + `HttpResponseSink` đã có;
`ReportExportService.materialize` sinh `ReportDocumentPayload`. `cashFundReportLabel(key)`
trả nhãn tiếng Việt cho tên file / tiêu đề (A-08).

## Implementation notes

- `GetCashFundReportDocumentHandler`: `countRows` nếu definition khai; chọn
  `TimePartitionKeysetFetcher` khi `definition.exportSource` có, ngược lại `SingleShotFetcher`;
  phụ đề = kỳ + "Xem theo cửa hàng" + "Nhân viên" (`document-subtitle` của report-core).
- Dòng `bold`/`indentLevel` đi qua `xlsx-style.ts` (`bold` đã hỗ trợ) — kiểm bằng spec với
  một definition giả có 3 dòng.
- Template DTO: `columns[] { key, visible, pinned, order, label }`, `scope` chain/branch qua
  `template-scope.ts`.
