# T-02-04 — Drill-down IV → Bảng kê

## Context

`report-drilldown.ts` là bảng resolver `(reportType, column) → DrillDownAction`;
`ReportDrillDownDialog` mở một `ReportPage` con với `reportType` + `filters`. Dòng IV của #2
mang `lineKey: 'closing'`; ô `cash`/`deposit` của nó là link (registry đặt `link: true` có
điều kiện theo `row.lineKey === 'closing'` — kiểm `ReportColumnConfig.tableConfig.link` có
nhận hàm không; nếu chỉ boolean, để resolver trả `null` cho các dòng khác).

## Implementation notes

- Resolver cho `('cash-in-out-situation', 'cash')` và `('…', 'deposit')`: trả
  `{ kind: 'report', drillDown: { reportType: REPORT_TYPE_CASH_FUND.CASH_IN_OUT_LIST, title:
  'BẢNG KÊ THU CHI', subtitle: <kỳ + Tiền mặt/Chuyển khoản>, filters: { ...ctx.filters,
  [PAYMENT_METHOD]: 'cash' | 'deposit', [STORE]: theo chi nhánh header } } }` khi
  `row.lineKey === 'closing'`, ngược lại `null`.
