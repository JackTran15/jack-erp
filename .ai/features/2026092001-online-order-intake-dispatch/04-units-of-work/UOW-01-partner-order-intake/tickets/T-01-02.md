# T-01-02 — Schema đơn nới ra khỏi ràng buộc chi nhánh

## Context
ADR-01: không dựng bảng đơn thứ hai. ADR-05: địa chỉ giao là snapshot, không FK
sang `geo_*` vì dataset địa giới là thứ đổi (`geo_wards.merged_from`).

## Implementation notes
- `salesperson_id`: `NOT NULL` → nullable. `salesperson_name` cũng nullable.
- Thêm: `sales_channel_id uuid` (FK `sales_channels`), `external_order_id varchar`,
  `shipping_fee numeric(18,2) default 0`, `recipient_name`, `recipient_phone`,
  `ship_province_code`, `ship_province_name`, `ship_ward_code`, `ship_ward_name`,
  `ship_address_line`.
- `UNIQUE (organization_id, sales_channel_id, external_order_id)` — partial index
  `WHERE external_order_id IS NOT NULL` để đơn mobile (không có id ngoài) không
  đụng ràng buộc.
- Đơn mobile hiện có: `sales_channel_id` NULL, mọi cột mới NULL/0 — không backfill.
- `branch_id` KHÔNG đổi (đã nullable từ đầu, `1789950000000-CreateSalesOrders.ts:20`).
