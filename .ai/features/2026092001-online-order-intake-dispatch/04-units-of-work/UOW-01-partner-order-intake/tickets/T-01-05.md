# T-01-05 — Bằng chứng đường partner

## Context
Hai thứ chỉ e2e mới chứng minh được: ràng buộc unique chống trùng khi chạy thật,
và việc đơn `branch_id IS NULL` **không** lọt vào lưới của bất kỳ chi nhánh nào.

## Implementation notes
- Chạy với `OUTBOX_RELAY_DISABLED=1` — e2e có thể xanh hết test mà vẫn FAIL vì
  `outbox_messages` chưa tồn tại lúc relay khởi động.
- Dựng: 1 org, 2 chi nhánh, 1 kênh `WEB`, 1 API key mang `partner.order.create`.
- Ca kiểm: tạo đơn → 201; gửi lại → 200 + cùng id; key sai quyền → 403;
  `GET /mobile/sales-orders` với `X-Branch-Id` của từng chi nhánh → 0 dòng.
