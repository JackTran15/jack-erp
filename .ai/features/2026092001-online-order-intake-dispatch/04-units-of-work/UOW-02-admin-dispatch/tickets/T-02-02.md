# T-02-02 — Đường đọc và phân đơn cấp tổ chức

## Context
ADR-07: `/mobile/sales-orders` dùng `BranchScopeGuard` và `list()` hard-filter
`so.branchId = actor.branchId` (`sales-order.service.ts:271`). Không nới guard cũ
— dựng controller mới.

## Implementation notes
- `@Controller('admin/sales-orders')`, `@UseGuards(AuthGuard, PermissionGuard)`,
  **không** `BranchScopeGuard`.
- `GET ?unassigned=true` → `pos.sales-order.dispatch`; `GET` → `pos.sales-order.read-all`.
- `POST :id/dispatch { branchId }` → `pos.sales-order.dispatch`:
  - kiểm `status === SENT`, không thì 409 `ORDER_NOT_DISPATCHABLE`
  - `UPDATE sales_orders SET branch_id = :b WHERE id = :id AND branch_id IS NULL`
    — 0 dòng ⇒ 409 `ORDER_ALREADY_DISPATCHED` (chặn hai Admin phân cùng lúc)
  - ghi `sales_order_dispatch_events` trong **cùng transaction**
  - **không** gọi `PosSessionService` (ADR-02)
- `listForOrganization(query, actor)` mới trong service — không sửa `list()` cũ.
- Hai permission thêm vào `permissions.seed.ts` theo đúng lối đặt tên
  `pos.sales-order.*` đã có.
