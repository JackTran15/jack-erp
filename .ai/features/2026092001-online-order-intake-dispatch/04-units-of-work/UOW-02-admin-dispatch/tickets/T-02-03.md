# T-02-03 — Lưới điều phối

## Context

`ORDER_COLUMNS` + `OrdersPageTable` đã có — chỉ đổi nguồn dữ liệu và thanh hành động.

## Implementation notes
- `useAdminSalesOrders({ unassigned: true, ... })` qua `erpApi` +
  `requireErpData`, bọc TanStack Query. `queryKey: ["admin-sales-orders", "unassigned", page, filters]`.
- **Không** đọc `_mock/orders.mock.ts`.
- `DispatchBranchDialog`: chọn chi nhánh từ danh sách chi nhánh của org, xác nhận
  → `useMutation` POST dispatch → `invalidateQueries(["admin-sales-orders"])`.
- Chọn nhiều dòng → phân hàng loạt: gọi tuần tự, dòng nào 409 thì báo riêng dòng
  đó, không nuốt lỗi cả mẻ.
- Không có cột "Chi nhánh" ở màn này — mọi dòng đều chưa phân.
