# T-03-02 — Lưới tra cứu toàn chuỗi

## Context
`ORDER_COLUMNS` khai `OrderColumnKey = Exclude<keyof OrderRow, "id">` — thêm cột
nghĩa là thêm field vào `OrderRow` trước, rồi mới thêm định nghĩa cột.

## Implementation notes
- `OrderRow` thêm `branchName: string`; `ORDER_COLUMNS` thêm
  `{ key: "branchName", header: "Chi nhánh", width: 160, filterKind: "select", renderer: "text" }`.
- Đơn chưa phân render `(Chưa phân)`; giá trị lọc tương ứng gửi `UNASSIGNED`.
- Tập cột mặc định của `/orders` (lưới chi nhánh) **không** bật `branchName`;
  `/orders/all` và `/orders/dispatch` có tập riêng.
- Nav: "Tất cả đơn hàng" → `/orders/all`, ẩn khi thiếu `pos.sales-order.read-all`.
