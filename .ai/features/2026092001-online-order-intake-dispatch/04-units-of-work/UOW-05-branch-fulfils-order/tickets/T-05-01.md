# T-05-01 — approve() chép kênh và phí giao từ đơn sang hoá đơn

## Context
`approve()` (`sales-order.service.ts:374-430`) đã tạo hoá đơn nháp qua
`invoiceService.createDraftIn(manager, dto, { ...actor, branchId })` trong cùng
transaction. Ticket này chỉ thêm hai trường vào dto đó.

## Implementation notes
- `sales_channel`: lấy **snapshot nhãn** trên đơn (`sales_orders.sales_channel`),
  không join lại `sales_channels` — ADR-03, chứng từ giữ chuỗi.
- `shipping_fee` → `invoices.shipping_fee_amount`.
- Đơn mobile không có `sales_channel_id`: giữ nguyên hành vi hôm nay
  (`sales_channel` vẫn là chuỗi kênh của app tư vấn, phí = 0).
- `createDraftIn` phải chuyển hai trường xuống `computeAmountDue` — nếu không,
  `amount_due` của hoá đơn nháp thiếu phí và thu ngân thấy sai số ngay trên màn hình.

## Done when
- [x] Spec: đơn web có phí → hoá đơn nháp `amount_due` = tiền hàng + phí
- [x] Spec: đơn mobile → `shipping_fee_amount` = 0, hành vi không đổi
- [x] Spec: `invoices.sales_order_id` và `sales_channel` đúng sau approve
