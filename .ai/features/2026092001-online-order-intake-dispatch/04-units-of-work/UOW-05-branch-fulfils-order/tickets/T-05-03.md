# T-05-03 — /orders đổi từ mock sang API thật

## Context
`OrdersPage` đang đọc `_mock/orders.mock.ts`. `OrderRow` là hợp đồng mà
`ORDER_COLUMNS`, bộ lọc và dialog cột đều dựa vào — giữ nguyên nó, chỉ đổi nguồn.

## Implementation notes
- `use-branch-sales-orders.ts`: gọi `/mobile/sales-orders` qua `erpApi` +
  `requireErpData`, TanStack Query, `queryKey: ["branch-sales-orders", page, filters]`.
  Endpoint này đã hard-filter theo `X-Branch-Id` nên không cần lọc lại phía client.
- `order-mapper.ts`: hàm thuần `toOrderRow(dto): OrderRow`. Test riêng — đây là
  chỗ duy nhất biết cả hai hình dạng.
- Cột chưa có backing (8 cột vận chuyển) map về chuỗi rỗng / 0; chúng sẽ bị ẩn ở T-05-04.
- `_mock/orders.mock.ts` giữ lại cho `OrdersAllPage`/dev, không xoá ở ticket này.
