# T-11-01 — Service: dời guard duyệt sang approve(), confirm ở chi nhánh, trả về pool xoá duyệt

## Context
ADR-12, §7: điều phối không duyệt; chi nhánh duyệt; thu ngân chỉ xử lý đơn web đã duyệt.

## Implementation notes
- `dispatch()`: bỏ guard `confirmed_at IS NULL → ORDER_NOT_CONFIRMED`.
- `confirm(id, actor)`: điều kiện `status = SENT AND branch_id = actor.branchId AND salesperson_id IS NULL`; đơn không có chi nhánh / đơn mobile / không SENT → 409 `ORDER_NOT_CONFIRMABLE`; đơn chi nhánh khác → 403 `ORDER_NOT_HELD_BY_BRANCH`. Cập nhật có điều kiện `branch_id = actor.branchId` (đua với trả về pool). Duyệt lại: no-op. Trả view chi nhánh.
- `approve()` (thu ngân): đơn `salesperson_id IS NULL` và `confirmed_at IS NULL` → 409 `ORDER_NOT_CONFIRMED`, kiểm TRƯỚC `PosSessionService` và trước khi tạo nháp.
- `returnToPool()`: set `confirmed_at = NULL, confirmed_by = NULL` trong cùng câu cập nhật.
- `list()` với `awaitingCashier`: loại đơn `salesperson_id IS NULL AND confirmed_at IS NULL`.
- `toView()` (mobile/chi nhánh) thêm `confirmedAt` và `needsConfirmation` (= đơn web) — bổ sung, không đổi field cũ.
