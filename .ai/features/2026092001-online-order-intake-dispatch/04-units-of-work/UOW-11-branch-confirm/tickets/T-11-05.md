# T-11-05 — Nút "Duyệt đơn" + cảnh báo theo tồn chi nhánh trên /orders của chi nhánh

## Context
Task 1 ở đúng chỗ: chi nhánh duyệt đơn web được phân về, cảnh báo theo tồn chi nhánh, đồng ý vẫn duyệt.

## Implementation notes
- Hooks `use-branch-sales-orders.ts`: `useBranchStockCheck(orderIds)` → `POST /mobile/sales-orders/stock-check`; `useBranchConfirmSalesOrders` lặp per-id `POST /mobile/sales-orders/:id/confirm`, gom confirmed/failed như bản admin cũ.
- Toolbar `/orders`: nút "Duyệt đơn" (CheckCheck), chỉ bật khi có dòng tick là đơn cần duyệt (`needsConfirmation && !confirmedAt`). Luồng như T-09-05: stock-check → đủ hết thì duyệt ngay, có thiếu thì mở `ConfirmOrdersDialog` (Huỷ / Vẫn duyệt), lỗi hiện cạnh mã đơn.
- Mapper + cột trạng thái: "Chờ duyệt" / "Đã duyệt" chỉ cho đơn `needsConfirmation` (AC-48: đơn tư vấn viên không có nhãn).
