# T-11-06 — Đơn đã xử lý không còn "Chờ duyệt"

## Context
Verify UOW-11 (S9.png, 2026-09-24): dòng "Khách web E2E" — đơn web đã **Đã xử lý** từ
trước khi có bước duyệt — vẫn mang nhãn "Chờ duyệt". `toOrderRow` mang
`needsConfirmation` của server (= đơn web) nguyên xi; cột trạng thái và nút "Duyệt đơn"
chỉ đọc cờ đó, không xét trạng thái. Hệ quả kép: nhãn sai, và tick đơn đó thì nút
"Duyệt đơn" sáng rồi server trả 409.

## Implementation notes
- `order-mapper.ts`: `needsConfirmation = dto.needsConfirmation === true && dto.status === "SENT"`.
  Đơn đã xử lý / huỷ / từ chối không còn gì để duyệt nên không mang nhãn duyệt nào.
- Không đổi server (`needsConfirmation` vẫn là "đơn web"), không regen api-client.
