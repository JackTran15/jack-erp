# T-12-01 — Nút "Điều phối (n)" + DispatchOrdersDialog chọn chi nhánh từng đơn

## Context
A-48 / ADR-13: tick đơn trước, bấm Điều phối mới chọn chi nhánh từng đơn trong dialog.

## Implementation notes
- Toolbar: `[Điều phối (n)] | [Nạp]` (icon `Store`), khoá khi chưa tick; bỏ Validate/Lưu khỏi toolbar và bỏ `branchByOrder`, `dispatchErrors`, `useBranchPickerColumn`, `extraColumn` khỏi trang.
- `DispatchOrdersDialog` (AppModal, `interface Props`, named export): props `open`, `onOpenChange`, `orders` (id, code, recipient — chụp lúc mở), `onDispatched(ids)`. Bảng: Mã đơn · Người nhận · Chi nhánh (SingleSelect mỗi dòng, có "(Bỏ chọn)") · Kết quả; ô SingleSelect ở header cột Chi nhánh điền mọi dòng. Footer: [Validate] ngay trái [Lưu] (+ Đóng).
- Validate: `useStockCheck` với `{orderId, branchId}` các dòng đã chọn → mở `ValidateDispatchDialog` (chỉnh props nếu cần); đóng báo cáo thì lựa chọn vẫn còn.
- Lưu: `useDispatchSalesOrders` với các dòng đã chọn; dòng OK → "Đã phân về <CN>"; dòng lỗi → giữ chi nhánh + lỗi tại dòng; tất cả OK → toast + đóng; trang bỏ tick các đơn đã phân.
- Mỗi lần mở là một mẻ mới (reset state).
