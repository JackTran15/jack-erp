# T-13-02 — Hai route GET history (Admin + chi nhánh) + response DTO + regen api-client

## Context
ADR-14: Admin xem mọi đơn trong tổ chức, chi nhánh chỉ đơn mình đang giữ.

## Implementation notes
- Admin: `GET /admin/sales-orders/:id/history`, `@RequirePermission([dispatch, readAll])` (mảng = OR), `@ApiOkResponse(SalesOrderHistoryResponseDto)`.
- Chi nhánh: `GET /mobile/sales-orders/:id/history`, quyền `read`, gọi `timeline(..., { heldByBranchId: actor.branchId })`. Đặt route trước `@Get(':id')` nếu cần (thực ra `:id/history` không đụng `:id`).
- DTO có `@ApiProperty` đủ để api-client sinh đúng kiểu (không để `Record<string, never>`).
- Regen api-client trên một cổng trống (4199 đang có server demo — dùng 4201), `rtk proxy curl` nếu cần curl.
