# T-13-04 — OrderHistoryModal + nút "Lịch sử" trên Điều phối, Tất cả đơn, Đơn hàng chi nhánh

## Context
A-49: modal qua nút; A-52: nút "Lịch sử" trên toolbar áp cho dòng đang chọn.

## Implementation notes
- `useOrderHistory(orderId, scope: 'admin' | 'branch', enabled)` — TanStack Query, key `["order-history", scope, orderId]`.
- `OrderHistoryModal` (AppModal, `interface Props`, named export): tiêu đề "Lịch sử đơn <mã>" + trạng thái hiện tại; danh sách dọc theo thời gian (giờ `Intl` vi-VN), mỗi mốc: nhãn loại tiếng Việt (Nhận đơn / Phân về … / Chi nhánh duyệt / Trả về pool / Thu ngân xử lý / Từ chối / Huỷ đơn), người, chi nhánh (từ → đến khi có), lý do, mã hoá đơn, badge trạng thái sau. Icon lucide theo loại. Trạng thái rỗng / đang tải / lỗi.
- Nút "Lịch sử" (lucide `History`): `/orders/dispatch` và `/orders/all` dùng scope admin, `/orders` dùng scope branch; khoá khi chưa có dòng đang chọn. `/orders/all` chưa có toolbar — thêm `PageToolbar` chỉ với nút này.
