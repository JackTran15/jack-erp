# T-01-01 — Exclude stopped pairs from the ledger arm of the sku-breakdown `cells` CTE

## Context

`StockSummaryDetailService.getSkuBreakdown` (`stock-summary-detail.service.ts:142`) builds its
row set in the `cells` CTE (`:165-180`): tracked `stock_balances` rows `UNION` every
`(item, location)` pair with ledger history in the storage. The second arm has no
`is_tracked` check, so a pair the user stopped with "Ngừng theo dõi" — which keeps its ledger
rows, only the flag flips — comes straight back as a `0 / 0` row. ADR-01 in
`03-logical-design.md` is the decision; the exact SQL is in its "Approach (a)".

## Implementation notes

- In the ledger arm (`:173-179`), after `WHERE sle.organization_id = $1 AND sle.posted_at < $5`,
  add the `NOT EXISTS (SELECT 1 FROM stock_balances ut WHERE ut.organization_id = $1 AND
  ut.item_id = sle.item_id AND ut.location_id = sle.location_id AND ut.is_tracked = false)`
  block, before `${EXCLUDE_VOIDED_DOCS_SQL}`. Use the alias `ut` (the file already uses `sb`
  for the balance arm and `balance` for the CTE). One-line comment above it in the file's
  voice, e.g. `-- A pair explicitly stopped ("Ngừng theo dõi") is not a row, whatever its history.`
- Do not touch the balance arm (`:167-171`, already `is_tracked = true`), `balance`, `period`,
  `reserved`, or anything in `getLedgerCard`.
- Keep the `$1..$6` parameter list unchanged — the predicate reuses `$1`.
- Unit spec: the file currently covers `getLedgerCard` only. Add a
  `describe("StockSummaryDetailService.getSkuBreakdown")` with one test that calls
  `getSkuBreakdown` against a `dataSource.query` mock (`getSkuBreakdown` issues its main SQL
  and `loadPendingTransfers`'s query inside one `Promise.all`; with a `branchId` both run —
  queue `[]` twice via `mockResolvedValueOnce`) and asserts on the first call's SQL text that the
  ledger arm contains `is_tracked = false` inside a `NOT EXISTS` — i.e.
  `expect(query.mock.calls[0][0]).toMatch(/NOT EXISTS\s*\(\s*SELECT 1 FROM stock_balances ut[\s\S]*ut\.is_tracked = false/)`.
  This pins the predicate cheaply; the row-set proof is T-01-02's e2e.
- The e2e that T-01-02 writes needs a stopped pair with ledger history and a tracked pair at
  quantity 0 in the same group — nothing in this ticket has to anticipate that.
