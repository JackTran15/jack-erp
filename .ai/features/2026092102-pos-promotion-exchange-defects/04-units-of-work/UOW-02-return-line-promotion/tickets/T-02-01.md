# T-02-01 — `EligibleLine.promotions[]`

## Context
`ReturnEligibilityService.getEligibleLines` (`return-eligibility.service.ts:126`)
trả `refundableUnitPrice` (đã trừ KM) nhưng không có tên CTKM. Snapshot
`invoice_checkout_promotions` của HĐ gốc có `name`/`type`/`line_discounts[]`
với `lineId = invoice_items.id`; `invoice.service.ts:322` đã đọc bảng này qua
`this.dataSource.getRepository(InvoiceCheckoutPromotionEntity)` (entity **không**
nằm trong `TypeOrmModule.forFeature` của `PosModule` — đi qua `DataSource`, không
`@InjectRepository`).

## Implementation notes
- Thêm `export interface EligibleLinePromotion { programId; code; name; type;
  unitDiscount }` và `promotions: EligibleLinePromotion[]` vào `EligibleLine`
  (interface, không phải DTO class — endpoint không có Swagger response).
- Inject `DataSource`; sau khi load `items`, đọc snapshot
  `where: { invoiceId, organizationId: actor.organizationId }, order: { priority, createdAt }`.
  Dựng `Map<lineId, EligibleLinePromotion[]>`: với mỗi row, mỗi
  `lineDiscounts[]` (null → bỏ), tìm item theo `lineId`; `unitDiscount =
  round2(discountAmount / Number(item.quantity))` (quantity 0 → bỏ). Không lọc
  theo `type` (A-12).
- Map trả `promotions: byLine.get(it.id) ?? []`. Không đổi `refundableUnitPrice`.
- **`checkout-return.service.spec.ts` (G3 mở lại 2026-09-22):** file này dựng
  `new ReturnEligibilityService(invoiceRepo, itemRepo, debtRepo)` trực tiếp ở 2 chỗ
  (AC-09/AC-10 của exchange-invoice-returnable); thêm `dataSource as never` làm đối
  số thứ 4 — mock `getRepository` trả `find: []` để hai case đó giữ nguyên số.
- Unit spec: thêm `describe('getEligibleLines promotions')` — mock `DataSource.getRepository().find`
  trả 1 snapshot với 2 lineDiscounts (1 khớp, 1 lạ) → dòng khớp có 1 promotion
  với unitDiscount đúng, dòng lạ bị bỏ; snapshot rỗng → `[]`; `lineDiscounts: null` → `[]`.
- e2e mới `eligible-returns-promotions.e2e-spec.ts`: seed `itemDiscountBody(item685)`,
  post SALE 2 × SKU-685 qua saga v2 (mẫu `checkout-saga-promotion.e2e-spec.ts`
  AC-19) → GET eligible-returns: `promotions[0] = { name "Giảm giá hàng hóa 30%",
  type ITEM_DISCOUNT, unitDiscount 205500 }`, `refundableUnitPrice 479500` (AC-05);
  SALE không CTKM → `promotions: []` (AC-06). File riêng, không đụng spec cũ.
