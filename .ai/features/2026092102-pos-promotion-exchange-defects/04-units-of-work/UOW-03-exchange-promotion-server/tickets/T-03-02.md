# T-03-02 — Evaluate + totals của phiếu đổi

## Context
`CheckoutReturnService.checkout` (`:122`) load items, `computeTotals` (`:591`)
cộng `lineTotal` OUT thành `newSubtotal`, `netAmount = newSubtotal − returnedNet`.
Không có bước CTKM. `EvaluatePromotionStep` của saga cho thấy cách dựng
`EvaluateCartDto` từ `InvoiceItemEntity` và dispatch `EvaluateCartQuery` qua
`QueryBus` (đã có trong `PosModule`: `CqrsModule` + `PromotionModule`).

## Implementation notes
- `checkout-return.dto.ts`: `selectedProgramIds?: string[]`, `excludedProgramIds?: string[]`
  với đúng decorator của `checkout-v2.dto.ts:101–117` (`@ApiPropertyOptional({ type:
  [String], format: 'uuid' }) @IsOptional() @IsArray() @IsUUID('4', { each: true })`).
- Service: inject `QueryBus`. Sau khi load `items` và trước `computeTotals`:
  ```
  const outItems = items.filter(it => it.direction === ItemDirection.OUT);
  const evaluation = outItems.length
    ? await this.evaluateNewLines(invoice, outItems, dto, actor)   // EvaluateCartQuery
    : null;
  ```
  `evaluateNewLines` dựng `EvaluateCartDto` y hệt `evaluate-promotion.step.ts:56–66`
  (`lineId = item.id`, `manualLineDiscount = Number(item.lineDiscount) || undefined`,
  `customerId = invoice.customerId ?? undefined`, hai mảng id từ dto). Chỉ import
  từ `promotion/application` (query + dto), không `promotion/domain`.
- `ComputedTotals += newPromotionDiscount, newNet`; `computeTotals(items,
  originalInvoice, originalItems, newPromotionDiscount = 0)`:
  `newNet = round(newSubtotal − newPromotionDiscount)`; `netAmount = round(newNet −
  returnedNet)`; `refundedAmount = round(max(returnedNet − newNet, 0))`.
  `newSubtotal` giữ nguyên nghĩa (gross, vào `invoice.subtotal`).
- Giữ `evaluation` trên một biến cục bộ để T-03-03 ghi snapshot (`appliedPrograms`)
  — không thêm field vào entity. Viết phần đầu của `checkout()` (load → validate →
  HĐ gốc → evaluate → `computeTotals`) thành một khối liền để T-03-06 tách ra
  thành `prepare()` mà không phải sắp lại.
- `this.logger.log` một dòng khi `newPromotionDiscount > 0` (Observability).
- `checkout-return.service.spec.ts`: thêm provider `QueryBus` mock trả evaluation
  rỗng (`promotionDiscount: 0, appliedPrograms: []`) → mọi case cũ giữ nguyên số;
  thêm 2 case: (a) mock trả `promotionDiscount 60000` cho phiếu đổi OUT 200.000 /
  returnedNet 685.000 → `netAmount −545000`, `refundedAmount 545000`; (b) phiếu
  RETURN thuần (không OUT) → `queryBus.execute` **không** được gọi (AC-14 nửa
  server: dòng IN không vào engine).
