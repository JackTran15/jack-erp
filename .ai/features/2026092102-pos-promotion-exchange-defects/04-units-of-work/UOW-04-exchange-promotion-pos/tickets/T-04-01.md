# T-04-01 — Preview ở mọi variant

## Context
`use-checkout-promotion-preview.ts:66–78`: `isSale` false → slice về `idle`,
không gọi evaluate. `buildEvaluateCartLines` (`evaluateCartPayload.ts`) chỉ gửi
`manualLineDiscount` khi `lineDiscount.type === "amount"`; draft/exchange gửi
`{type, value}` và BE quy ra tiền rồi bơm vào engine (`evaluate-promotion.step.ts:64`),
nên với `percent` preview đang lệch BE.

## Implementation notes
- Hook: bỏ nhánh `if (!isSale)`. Dòng gửi evaluate:
  - `INVOICE_RETURN`: `selectPurchaseCart(state).filter(l => !l.isReturnCredit)`
  - `QUICK_EXCHANGE`: `selectPurchaseCart(state)` (returnCart là mảng riêng)
  - `SALE`: như cũ.
  Chọn bằng một selector nhỏ trong hook (không thêm selector vào store để
  không đụng `checkout-session.store.ts`). Khóa `cartKey` tính trên tập đã lọc.
  Cập nhật docstring ("Chỉ chạy ở luồng SALE" → bỏ). Giỏ chỉ có dòng trả →
  `lines: []` vẫn gọi (AC-20 ý 3).
- `buildEvaluateCartLines`: `const manual = lineDiscountAmount(line); ...(manual > 0
  ? { manualLineDiscount: manual } : {})` — import từ `checkoutUtils.ts`. Cập
  nhật docstring nói rõ vì sao gửi số tiền (mirror BE).
- Không đụng `use-checkout-exclude-preview.ts` (đã dùng `buildEvaluateCartLines`
  → tự đúng).
