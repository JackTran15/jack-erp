# T-01-01 — Portal cho dropdown của TreeSelectInput

## Context

`TreeSelectInput.tsx:426` render danh sách `absolute z-50` trong `wrapRef`; `AppModal` (`[contain:layout_paint]`,
lớp bọc body `overflow-hidden`) và Radix `PopoverContent` (wrapper có `transform`) đều cắt hoặc giam nó. `LookupField.tsx`
cùng thư mục đã giải quyết: `:346-404` đo `rect` + `portalTarget` trong `useLayoutEffect`, `:333-343` click-ngoài xét
`popoverRef`, `:319-331` tự tải khi trang đầu không lấp đầy, `:524-540` `createPortal` với `data-lookup-popover`,
`zIndex: 70`, `pointerEvents: "auto"`. Chép cơ chế đó; không sửa `LookupField` (ADR-01).

Host của component: `CrudFormDialog` (FieldInput, `:585-595`), `CrudFieldInput`, `CrudRecordDialog`,
`ItemCategoryCreateDialog`, `ProductSelectDialog`, `CategorySelectDialog` (dialog); `StockSummaryFilterPopover`,
`ReportFilterLine` (Radix Popover); `InventoryItemCreateForm` qua `CrudCreatePage`/`CrudEditPage` (trang thường).

## Implementation notes

- Thêm `import { createPortal } from "react-dom"`, `useLayoutEffect`; state `rect: { top, left, width, maxHeight } | null`,
  `portalTarget: HTMLElement | null`; `popoverRef`, `scrollRef`.
- Hằng số: `POPOVER_GAP = 4`, `POPOVER_VIEWPORT_MARGIN = 8`, `POPOVER_MAX_HEIGHT = 320`, `POPOVER_MIN_HEIGHT = 140` (A-03).
- `useLayoutEffect([open])`: đóng ⇒ `rect = null`, `portalTarget = null`. Mở ⇒ `target = wrapEl.closest('[role="dialog"]') ?? document.body`;
  `measure()` như LookupField `:359-395` (đặt dưới nếu `availableBelow ≥ MIN` hoặc `≥ availableAbove`; nếu `target !== body`
  thì trừ `target.getBoundingClientRect()`); `window.addEventListener("scroll", measure, true)` + `resize`; cleanup gỡ cả hai.
- Handler click-ngoài (`:335-348`): thêm `if (popoverRef.current?.contains(target)) return;` trước khi đóng — không thì
  bấm vào một mục sẽ đóng dropdown **và** `setInputText(allOptionLabel ?? "")` đè lên chuỗi `handleSelect` vừa đặt
  (cả hai setState cùng batch, cái sau thắng).
- Render: thay `<div className="absolute z-50 …">` bằng `open && rect && portalTarget ? createPortal(<div ref={popoverRef}
  data-lookup-popover="" style={{ position: "fixed", top, left, minWidth: width, zIndex: 70, pointerEvents: "auto" }}
  className="overflow-hidden rounded-md border bg-background shadow-md">…</div>, portalTarget) : null`. Khung cuộn:
  `ref={scrollRef}`, `style={{ maxHeight: rect.maxHeight }}`, giữ `overflow-y-auto overscroll-contain` và `onScroll`.
  Bỏ `max-h-64`. Giữ `bg-background` như hiện tại (không đổi sang `bg-popover`) để không đổi màu.
- Tự lấp khung (A-05): `useEffect([open, loading, hasMore, allItems.length])`: nếu `open && !loading && hasMore` và
  `scrollRef.current.scrollHeight <= clientHeight + 1` ⇒ `void loadPage(paging.page + 1, query, false)`. Không có
  `loadingMoreRef` riêng vì `loading` đã bao cả tải trang sau.
- `onMouseDown` + `preventDefault` trên `li` giữ nguyên — ô nhập giữ focus, `blur` không xảy ra.
- Không thêm prop; `TreeSelectInputProps` giữ nguyên chữ ký.
