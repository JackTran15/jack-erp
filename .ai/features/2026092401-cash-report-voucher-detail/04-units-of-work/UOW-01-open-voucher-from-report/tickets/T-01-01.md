## Implementation notes

- `report.interface.ts`: `export interface VoucherDetailTarget { id: string; kind: CashFundDocumentKind }`;
  `ReportState.detailVoucher`; `ReportActions.setDetailVoucher`.
- `report.store.ts`: `detailVoucher: null` ở state khởi tạo và trong reset (dòng ~162, cạnh `detailInvoice`).
- `report-drilldown.ts`:
  - `DrillDownAction` thêm `{ kind: "voucherDetail"; target: VoucherDetailTarget }`.
  - `DrillDownContext` thêm `can: (permission: string) => boolean`.
  - `VOUCHER_READ_PERMISSION: Record<CashFundDocumentKind, string>` =
    `accounting.cash_receipt.read` / `cash_payment` / `bank_receipt` / `bank_payment`.
  - `voucherDetail` resolver: đọc `CASH_FUND_ROW_KEYS.VOUCHER_ID/VOUCHER_KIND`; `null` nếu thiếu id, kind lạ, hoặc `!can(VOUCHER_READ_PERMISSION[kind])`.
  - `DRILL_DOWNS["cash-in-out-list"] = { documentNumber: voucherDetail }`, `DRILL_DOWNS["expense-list-by-category"] = { documentNumber: voucherDetail }`.
- `ReportPageTableView.tsx`: `const { has } = usePermissionCheck()`, truyền `can: has` vào ctx; `runDrillDown` rẽ `voucherDetail` → `setDetailVoucher`.
