# T-01-02 — Dialog xem phiếu trong báo cáo

## Context

Sổ quỹ tiền mặt dựng dialog phiếu ở `LedgerCashPage.tsx:141-160, 294-345`; Sổ tiền gửi ở
`LedgerDepositPage.tsx:196-202, 547-570`. Ticket này gom đúng phần đó vào một component đọc
`detailVoucher` của report store.

## Implementation notes

- Chọn hook theo `target.kind`: `useCashReceipt(id, kind === "CASH_RECEIPT")`, `useCashPayment`,
  `useBankReceipt`, `useBankPayment` — hook không dùng truyền `enabled = false`.
- Tiền mặt: map qua `cashReceiptToVoucherDetail(detail, useCategoryNameMap(IN))` /
  `cashPaymentToVoucherDetail(detail, useCategoryNameMap(OUT))` (`pages/treasury/cash-vouchers.adapters.ts`).
  Tiền gửi: truyền thẳng như `LedgerDepositPage`.
- Render `ReceiptVoucherDialog` / `PaymentVoucherDialog` / `DepositReceiptVoucherDialog` /
  `DepositPaymentVoucherDialog` từ `pages/treasury/documents` với `mode={TreasuryVoucherDialogModeEnum.VIEW}`,
  **không** truyền `onRequestEdit` / `onSave`. `onOpenChange(false)` → `setDetailVoucher(null)`.
- Đang tải: overlay "Đang tải dữ liệu..." như `LedgerCashPage.tsx:285-292`; lỗi: `AppModal` nhỏ "Không tải được chi tiết phiếu." + Đóng.
- `ReceiptVoucherDialog.onOpenInvoice(code)` → `setDetailInvoice({ code, id: null })` (A-08).
- Mount `<ReportVoucherDetailDialog />` trong `ReportPage.tsx` cạnh `<InvoiceDetailDialog />` và trong `ReportDrillDownBody`; cập nhật comment ở đó cho cả hai dialog.
