# T-02-02 — processBatch: confirm nếu cần + approve; approve set AWAITING_PICKUP

## Context
A-01 (chốt): một cú bấm = confirm + approve. ADR-07 batch.

## Implementation notes
- `approve()` update thêm `deliveryStatus: AWAITING_PICKUP` + event PROCESS trong cùng transaction.
- `processBatch(ids, actor)`: tuần tự; mỗi id: nếu `needsConfirmation` → `confirm`; rồi `approve`; bắt lỗi → `{id, ok:false, code, message}`.
- `BatchSalesOrderDto { ids: uuid[] 1..100 }`; `POST process`, `pos.sales-order.approve`.
- Lỗi đơn không SENT → `ORDER_NOT_PROCESSABLE`.
