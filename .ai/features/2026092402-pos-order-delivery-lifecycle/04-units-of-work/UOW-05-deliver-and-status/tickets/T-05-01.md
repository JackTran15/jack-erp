# T-05-01 — deliverBatch + deliveryStatusBatch (không gồm RETURNED) + permission deliver

## Context
Máy trạng thái §2 thiết kế; ADR-07.

## Implementation notes
- deliver: AWAITING_PICKUP|FAILED → IN_TRANSIT; hoá đơn `is_draft` → INVOICE_NOT_FINALIZED; `deliveryPartnerId` tuỳ chọn, có thì phải active cùng tổ chức (DELIVERY_PARTNER_INACTIVE); fee/partner bỏ trống → NULL; `delivered_at` chỉ set lần đầu.
- delivery-status: kiểm `DELIVERY_TRANSITIONS`; → COMPLETED cần remaining_amount = 0 (DEBT_OUTSTANDING); event DELIVERY_STATUS mang from→to.
- `FOR UPDATE`, một transaction mỗi đơn; permission `pos.sales-order.deliver`.
