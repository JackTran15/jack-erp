# T-01-01 — targetType theo từng dòng trên lưới Giảm giá hàng hóa

## Context
Ô tra cứu phạm vi *Hàng hóa* (`GoodsDiscountGrid.tsx:205`) gán `targetId: item.id` từ `/inventory/items`, nhưng `itemDiscountToDto` (`promotion.mapper.ts:555`) hardcode `PRODUCT`, còn engine so `PRODUCT` với `productId` (`line-matching.ts:24`). `addFromPicker` cũng bỏ `draft.targetType`. ADR-03.

## Implementation notes
- Thêm `targetType: PromotionTargetType` vào `GoodsDiscountRow`; `blankGoodsDiscountRow()` mặc định `ITEM`
- Ô tra cứu *Hàng hóa* → `ITEM`; ô tra cứu *Nhóm hàng hóa* → `CATEGORY`; `addFromPicker.toRow` giữ `draft.targetType`
- `itemDiscountToDto`: `targetType = scope === GROUP ? CATEGORY : r.targetType`
- `itemDiscountFromDetail`: `targetType: l.targetType`
- Không sửa `promotion.mapper.spec.ts` (không chạy — A-08); không đụng API

## Done when
- [x] `GoodsDiscountRow` có `targetType`, mọi nơi tạo dòng đều gán
- [x] Mapper gửi `targetType` theo dòng, nhóm vẫn `CATEGORY`
- [x] `itemDiscountFromDetail` đọc lại `targetType`
- [x] `pnpm --filter @erp/backoffice-web exec tsc --noEmit` sạch
