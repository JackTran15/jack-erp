# T-04-04 — Dialog Nhập khẩu + gộp vào lưới

## Implementation notes
- `importItemDiscountLines(method, file)` (multipart) trong `item-discount-excel.api.ts`
- `ItemDiscountImportDialog`: chọn file → gọi API → bảng lỗi (dòng, mã, lý do) + số dòng hợp lệ → **Áp dụng** / **Hủy**; dòng chú thích *"Bấm Lưu để lưu chương trình"*
- Gộp: khớp theo `targetId`; có → ghi đè `value`, không → thêm trước dòng trống cuối; giữ `targetType` từ response
- Nút **Nhập khẩu** cạnh **Xuất khẩu**, cùng điều kiện ẩn/hiện; lỗi 400 hiện thông báo của server trong dialog
