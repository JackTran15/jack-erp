# T-01-02 — GoodsDiscountRow mang unit + sellingPrice

## Context
`GetPromotionHandler` đã trả `unit`/`sellingPrice` cho dòng `ITEM`. Picker draft đã có `unit`/`sellingPrice`. Chỉ lưới đang vứt đi.

## Implementation notes
- **Trước khi code**: gọi `GET /inventory/items?pageSize=1` trên API local, xác nhận có `sellingPrice` (A-13). Không có thì dừng, `aidlc block`
- `GoodsDiscountRow`: `unit: string`, `sellingPrice: number | null`; `blankGoodsDiscountRow` → `""`, `null`
- Ô tra cứu: `ItemOption.sellingPrice`, gán vào `onSelect`
- `addFromPicker`: `PRODUCT` → `unit: ""`, `sellingPrice: null` (A-04); `ITEM` → từ draft
- `itemDiscountFromDetail`: `l.unit ?? ""`, `l.sellingPrice ?? null`
- `itemDiscountToDto` **không** gửi hai trường này
- Nhóm hàng hóa: `""` / `null`
