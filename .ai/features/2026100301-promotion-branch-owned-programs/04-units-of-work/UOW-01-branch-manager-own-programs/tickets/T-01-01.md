# T-01-01 — Program owner column and domain field

## Context
ADR-01 and ADR-04. `promotion_programs.branch_id` (BaseEntity) means "creator's branch" and
stays untouched; ownership is a new column. NULL = chain-owned, and every existing row stays
NULL (A-05).

## Implementation notes
- Migration timestamp must exceed the newest on `main` when you start (today `1790100800000`).
  `ADD COLUMN owner_branch_id uuid NULL REFERENCES branches(id)`, index
  `IDX_promotion_programs_org_owner (organization_id, owner_branch_id)`; `down` drops both.
- Entity: `@Column({ name: 'owner_branch_id', type: 'uuid', nullable: true }) ownerBranchId?: string | null`.
- Domain: `ownerBranchId?: string` on props, readonly field, constructor, `toProps()`.
  `validate()`: when set, `branchIds` must equal `[ownerBranchId]` → issue
  `{ field: 'branchIds', code: 'OWNER_SCOPE_MISMATCH' }`.
- Mapper (`promotion.mapper.ts`): map both directions; `null` ↔ `undefined`.
- Fixture: default `ownerBranchId: undefined` so engine specs stay green.
