# T-02-01 — Chain-manager list

## Context
A-08: chain managers stop being narrowed to the active branch. New optional request field
`owner?: { value: 'CHAIN' | uuid }` (03-logical-design.md › Contracts).

## Implementation notes
- `searchScope().kind === 'chain'` → no branch predicate; then `owner.value === 'CHAIN'` →
  `p.owner_branch_id IS NULL`, a uuid → `p.owner_branch_id = :owner`.
- Branch managers: `owner` is ignored, not rejected (their scope is fixed).
- DTO: class-validator — `CHAIN` or UUID v4; `@ApiPropertyOptional` (global `forbidNonWhitelisted`).
