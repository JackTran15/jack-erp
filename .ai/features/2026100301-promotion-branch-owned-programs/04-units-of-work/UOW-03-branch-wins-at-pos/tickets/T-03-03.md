# T-03-03 — Price by the invoice's branch

## Context
ADR-07. `load-draft.step.ts` finds the draft by `organizationId` only, and both
`EvaluatePromotionStep` and `CheckoutReturnService.evaluateNewLines` hand `actor` straight to
`EvaluateCartQuery`, whose `findActive` and `cart.branchId` read `actor.branchId`. A draft
from HN checked out under an HCM session would get HCM's branch-owned programs.

## Implementation notes
- Both call sites: `new EvaluateCartQuery(dto, { ...actor, branchId: invoice.branchId ?? actor.branchId })`.
- Only the actor passed to the query changes; nothing else in the saga reads it differently.
