# T-01-02 — API key crypto util

## Context
Logic thuần, không phụ thuộc entity/DB — cả nhánh tạo key (UOW-01) lẫn nhánh xác thực key
(UOW-02) đều cần, nên tách thành util dùng chung (layer `shared`) thay vì viết lặp ở hai
service khác nhau.

## Implementation notes
- `generateApiKey(): { raw: string; prefix: string }` — `crypto.randomBytes(32)`, encode
  base64url; `prefix` là 8 ký tự đầu để hiển thị trong danh sách admin.
- `hashApiKey(raw: string): string` — SHA-256 hex; không cần salt riêng (secret đã đủ
  entropy từ `randomBytes(32)`, khác bối cảnh password người dùng).
- Không import gì từ TypeORM/NestJS — giữ pure function, test không cần bootstrap module.

## Done when
- [x] `hashApiKey` deterministic (cùng input → cùng output)
- [x] `generateApiKey` không sinh trùng `raw` trong 10k lần chạy thử (test xác suất)
- [x] Unit test cho cả hai hàm, không mock gì (pure function)
