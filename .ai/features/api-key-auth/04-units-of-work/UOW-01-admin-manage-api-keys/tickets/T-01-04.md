# T-01-04 — Nav entry cho API Keys

## Context
Route `/admin/:entityKey` đã tự động render `CrudListPage` cho mọi entity đăng ký — không
cần sửa `App.tsx`. Chỉ thiếu mục sidebar để người dùng tìm thấy trang.

## Implementation notes
- Đặt trong module "Cấu hình" (`id: "settings"`) → section `settings-main`, ngay cạnh
  "Quản lý vai trò" (`iam.role.read`) — cùng nhóm ngữ nghĩa "ai/cái gì được truy cập hệ
  thống", hợp lý hơn nhóm `catalog-suppliers` (nhà cung cấp) ban đầu dự tính.
- `permission: "api-key.read"` — `resolveRouteAccess` (`routeAccess.ts`) tự đọc field này
  qua `findNavMatch`, không cần đăng ký gì thêm ở nơi khác để gate route.
