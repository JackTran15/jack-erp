# T-02-01 — trust proxy + Swagger

## Context
A-01 (confirmed): API sau reverse proxy/LB ở production. Không có `trust proxy` hôm nay →
`req.ip` sai theo ADR-03 (03-logical-design.md).

## Implementation notes
- `app.set('trust proxy', config.get<number>('TRUST_PROXY_HOPS', 1))` sau khi tạo `app`.
- Thêm `.addApiKey({ type: 'apiKey', name: 'X-Api-Key', in: 'header' }, 'api-key')` vào
  `DocumentBuilder`, cạnh 3 khai báo header hiện có (`X-Branch-Id`, `X-Request-Id`,
  `X-Idempotency-Key`).

## Done when
- [x] `req.ip` trả đúng IP client khi giả lập `X-Forwarded-For` qua supertest với
      `app.set('trust proxy', 1)`
- [x] `/docs` hiện API key mới trong Swagger UI
