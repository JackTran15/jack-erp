# T-05-03 — Sinh lại api-client

## Context

Feature thêm hai endpoint (`activate`, `deactivation-impact`) và một query param
(`includeInactive`). CLAUDE.md quy định: đổi endpoint thì chạy API rồi `pnpm openapi:generate`,
commit cả snapshot lẫn file generated, và **không sửa tay file generated**.

Để cuối cùng vì hợp đồng còn có thể đổi trong lúc làm UOW-01..04; sinh sớm chỉ tạo diff rác.

## Implementation notes

- Khởi động API (`make dev-api`), đợi `/docs-json` trả về, rồi `pnpm openapi:generate`
- Soát diff: chỉ được thấy hai endpoint mới và một param mới. Thấy gì khác thì có ai đó đã
  đổi hợp đồng ngoài phạm vi — dừng và hỏi
- `pnpm build:shared` để chắc `@erp/api-client` còn compile
