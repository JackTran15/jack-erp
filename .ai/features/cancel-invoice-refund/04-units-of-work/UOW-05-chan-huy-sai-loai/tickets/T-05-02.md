# T-05-02 — E2E điều kiện hủy

## Context

Guard chỉ có giá trị nếu chứng minh được rằng khi bị chặn thì **không có** hệ quả nào
xảy ra — không phiếu chi, không đổi kho, không đổi trạng thái.

File e2e riêng để không tranh với hai file e2e của các lát cắt khác.

## Implementation notes

- Dựng một hóa đơn bán rồi checkout-return một phần để có hóa đơn RETURN thật, theo cách
  `pos.e2e-spec.ts` đang làm.
- Case 1: hủy hóa đơn RETURN → 400.
- Case 2: hủy hóa đơn SALE gốc (đã có RETURN trỏ tới) → 400.
- Sau mỗi case: assert `status` hóa đơn không đổi, không có dòng mới trong `cash_payments`,
  và tổng tồn kho không đổi.
