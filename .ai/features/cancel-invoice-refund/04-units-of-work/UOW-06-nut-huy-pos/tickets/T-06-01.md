# T-06-01 — Lớp gọi API cho việc hủy

## Context

`invoice.service.ts` đã có `checkout`, `checkoutReturn`, `redeemPoints`, `remove` — thêm
`cancel` theo đúng khuôn đó. Hook đặt trong `use-query-invoice.ts` cạnh các mutation khác.

Không phụ thuộc ticket backend nào: endpoint đã tồn tại và đã chạy được từ trước epic.

## Implementation notes

- `cancelInvoice(id, body: { reason: string })` → `POST /invoices/:id/cancel`, dùng đúng
  helper `http` mà các hàm khác trong file đang dùng, `encodeURIComponent(id)` như chúng.
- `useCancelInvoiceMutation()`: `onSuccess` invalidate theo **prefix** `["invoices"]` để cả
  danh sách lẫn chi tiết cùng nạp lại.
- Lỗi cứ để ném ra cho component xử lý — T-06-02 chịu trách nhiệm hiển thị (AC-20).
- Kiểu dữ liệu lấy từ chỗ sẵn có; không tự khai lại type đã có trong `@erp/shared-interfaces`.
