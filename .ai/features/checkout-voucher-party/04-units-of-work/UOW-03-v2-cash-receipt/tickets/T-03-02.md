# T-03-02 — post-journal đưa journalEntryId vào CheckoutContext

## Context

Phiếu thu voucher-only phải link tới bút toán và movement đã ghi. `post-journal.step` đang
lưu `savedEntry` vào biến cục bộ rồi bỏ đi; `post-cash.step` chạy **sau** nó
(`checkout-saga.controller.ts:183-185`, A-11) nên chỉ cần một slot trong context là đủ, không
phải đảo thứ tự bước nào.

## Implementation notes

- Thêm vào `CheckoutContext`, kèm comment theo đúng giọng các slot đang có ("slot nào do bước
  nào điền"):

```ts
/** Set by post-journal; read by post-cash to link the Phiếu thu to the sale's entry. */
journalEntryId?: string;
/** Set by post-cash; the receipt links the movement it just wrote. */
cashMovementId?: string;
/** Set by post-cash once the Phiếu thu exists — for trace and close-saga. */
cashReceiptId?: string;
```

- `post-journal.step`: `ctx.journalEntryId = savedEntry.id;` sau khi lưu. Một dòng, không đổi
  gì khác.
- Nhánh `ctx.replayed` của `post-journal` trả về sớm nên không set slot — đúng, vì
  `post-cash` cũng return sớm trong cùng trường hợp.
- Không thêm slot nào không có người đọc: nếu T-03-03 cuối cùng không dùng `cashMovementId`
  riêng (vì nó tự tạo movement trong cùng bước) thì bỏ slot đó khỏi ticket này.
