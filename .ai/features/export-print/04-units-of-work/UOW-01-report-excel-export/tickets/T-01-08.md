# T-01-08 — Test đối chiếu export với search

## Context

Đây là test chứng minh A-01 đúng trên dữ liệu thật, không chỉ trên mock. Nếu test này đỏ thì ADR-03 sai và exporter phải lặp trang.

## Implementation notes

- Seed một tập dữ liệu đủ để có nhiều hơn một trang ở `POST search`
- Gọi `POST search` lấy `total` + `totals`, rồi gọi `POST export`, đọc lại workbook bằng exceljs
- Khẳng định: số dòng dữ liệu trong file == `total`; dòng tổng cộng == `totals`
- Khẳng định: request với bộ lọc cho ra hơn 50k dòng trả 400 và body không phải file

- [x] Test đọc file thật bằng exceljs, không chỉ kiểm tra content-type

      reportType lạ

## Ghi chú khi chạy

- **Phải chạy với `DB_NAME=erp_test` tường minh.** `apps/api/.env` đặt `DB_NAME=erp_dev`
  và `global-setup.ts` dùng `process.env.DB_NAME || 'erp_test'`, nên `pnpm test:e2e`
  trần sẽ trỏ vào **DB dev** rồi `synchronize(true)` xoá sạch. Lần chạy đầu đã trúng bẫy
  này; DB dev thoát nạn nhờ lỗi drop view `pg_stat_statements_info` chặn giữa chừng.
- Suite báo "Test Suites: 1 failed" dù **7/7 test pass**: `OutboxRelayService` poll nền
  trúng đúng lúc `resetDatabase` đang drop/recreate bảng `outbox_messages` → lỗi ngoài
  test. Race có sẵn của harness (mọi spec gọi `createTestApp()` rồi `resetDatabase()`
  đều dính), không phải do ticket này.
