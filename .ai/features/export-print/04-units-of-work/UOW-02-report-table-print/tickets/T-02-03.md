# T-02-03 — renderReportTableHtml — payload thành HTML A4

## Context

Đối trọng client-side của `ReportWorkbookBuilder`: cùng payload vào, khác định dạng ra. Xem `renderInvoiceHtml.ts` của pos-web để lấy cách tổ chức (hàm thuần, HTML tự chứa, escape đầy đủ).

## Implementation notes

- `renderReportTableHtml(payload, orientation: 'landscape' | 'portrait')` trả chuỗi HTML tự chứa, CSS inline
- `@page { size: A4 landscape; margin: 10mm }` điều khiển hướng giấy
- Đầu trang: tên chi nhánh, tên báo cáo, các dòng bộ lọc — cùng thông tin với khối đầu workbook
- `table-layout: fixed` + thu cỡ chữ theo số cột để bảng rộng không tràn
- Escape mọi giá trị chuỗi — copy hàm `escapeHtml` của `renderInvoiceHtml.ts`
- Số căn phải, định dạng theo `Intl` locale `vi-VN`; dòng tổng in đậm
- `thead` lặp lại mỗi trang bằng `display: table-header-group`
