# T-09-01 — xlsx-style.ts — hằng số và helper trình bày dùng chung

## Context

ADR-11: hai Writer (`XlsxStreamWriter` cho báo cáo, `VoucherXlsxWriter` cho chứng từ) phải tuân
cùng một chuẩn trình bày. Khai chuẩn đó hai lần là lặp lại đúng sai lầm mà feature này sinh ra để
dừng. File này là nơi duy nhất giữ nó.

Số đo lấy từ `03-logical-design.md` §"House style", vốn đọc trực tiếp từ `xl/styles.xml` của 4 file
mẫu — không ước lượng.

## Implementation notes

- Hằng số: `HEADER_FILL_ARGB = 'FFFDE9D9'`, `NUMBER_FORMAT = '#,##0'`,
  `FONT_SIZE_BODY = 12`, `FONT_SIZE_TITLE = 18`, `SIGNATURE_ROW_HEIGHT = 31.5`
- `THIN_BORDER: Partial<ExcelJS.Borders>` — `thin` cả 4 cạnh
- `bodyFont(opts?: { bold?: boolean; italic?: boolean; size?: number })` trả `ExcelJS.Font`
  luôn gắn `name: GENERATED_XLSX_FONT_NAME` (import từ `common/utils/excel-workbook-font.util`)
- `writeBannerRow(sheet, text, opts, lastColumn)` — thêm một dòng chỉ có ô A, merge `A..lastColumn`
  khi `lastColumn > 1`, gán font + alignment, rồi `commit()`. Merge **trước** commit; đây là ràng
  buộc của `WorkbookWriter` (ADR-08), không phải sở thích
- `writeBlankRow(sheet)` — một dòng trống đã commit
- Không import `exceljs` type nào ra ngoài file này ngoài những gì chữ ký hàm cần; file này là
  tri thức trình bày, không phải tầng trừu tượng trên exceljs
