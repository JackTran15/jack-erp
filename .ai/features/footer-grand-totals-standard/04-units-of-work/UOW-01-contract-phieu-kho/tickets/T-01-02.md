# T-01-02 — Ba handler phiếu kho trả `totals`

## Context
Ba handler này (đợt 1) trả `totalAmount` scalar. Logic tính **không đổi** — chỉ đổi chỗ đặt giá trị
trong response, để khớp contract ở T-01-01.

## Implementation notes
- Giữ nguyên `buildQuery`, `TOTAL_AMOUNT_SUBQUERY`, `Promise.all` — chỉ đổi câu `return`:
  `totalAmount: Number(...)` → `totals: { totalAmount: Number(...) }`.
- Cập nhật ghi chú DTO response ở cả ba dto tương ứng.
- Spec: đổi các khẳng định `result.totalAmount` → `result.totals.totalAmount`. **Giữ nguyên** ý
  nghĩa test — nhất là test bất biến `limit` (1 vs 100) và test "không join `lines` ở nhánh totals".
