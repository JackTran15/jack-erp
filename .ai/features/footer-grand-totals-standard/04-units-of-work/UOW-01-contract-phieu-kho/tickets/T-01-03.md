# T-01-03 — Ba trang phiếu kho đọc `totals.totalAmount`

## Context
Ba trang giữ `totalAmount` trong state `records` và đọc ở `footer:`. Đổi sang `totals`.

## Implementation notes
- State `records` đổi từ `& { totalAmount: number }` sang `& { totals: { totalAmount: number } }`.
- Nhánh lỗi (catch) hiện set `totalAmount: 0` → `totals: { totalAmount: 0 }`.
- `footer:` đọc `records.totals.totalAmount`; giữ nguyên `showTotalFooter` và comment giải thích
  đây là tổng toàn tập.
- Không đổi cách hiển thị: vẫn `formatMoneyInteger`.
