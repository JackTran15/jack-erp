# T-01-04 — 3 trang phiếu kho đọc totalAmount từ API

## Context
Cả ba trang có cùng cấu trúc: state `records = { data, total, page, pageSize }` set sau khi
`POST` search, một `useMemo` cộng dồn `records.data`, rồi gán vào `footer:` của cột tiền.

Vị trí cụ thể:
- `PurchaseOrdersPage.tsx` — set state `:208-213`, `totalSum` `:475-478`, `footer:` `:532`
- `GoodsIssuePage.tsx` — fetch `:185-196`, `totalSum` `:434-438`, `footer:` `:500`
- `StockTransferPage.tsx` — set state `:245-250`, `totalSum` `:349-352`, `footer:` `:460`

## Implementation notes
- Thêm `totalAmount` vào state `records` và vào type response của lời gọi `apiClient.post`.
- Xoá `totalSum` (`useMemo` cộng dòng) và các helper chỉ còn nó dùng (`orderTotal`/`issueTotal`/
  `transferTotal`) **nếu** không còn chỗ nào gọi — chúng đang được cột `render` dùng cho từng dòng,
  nên nhiều khả năng giữ lại; chỉ xoá thứ thật sự thành mồ côi.
- `footer:` đọc `formatMoneyInteger(records.totalAmount)`; giữ `showTotalFooter` để ẩn khi đang
  tải hoặc rỗng.
- Comment ngay tại `footer:` rằng đây là tổng toàn tập do server tính, theo mẫu
  `pages/promotions/vouchers/VouchersTable/VouchersTable.tsx:133`.
- Chạy API rồi `pnpm openapi:generate`; commit cả `packages/api-client/openapi.snapshot.json` và file schema sinh ra.
