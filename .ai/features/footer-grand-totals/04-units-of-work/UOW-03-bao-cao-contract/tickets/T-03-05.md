# T-03-05 — Trang Hàng hóa xuất kho tạm chạy trên hợp đồng mới

## Context
Trang này hiện tự cộng footer ở `:167` và bị trần `pageSize: 200` ở `:135`. Đây là trang đầu tiên
chuyển sang hợp đồng mới, và là bằng chứng demo của cả UOW-03.

## Implementation notes
- Bật cờ phân trang server của shell cho trang này.
- Xoá hàm `columnSummary` cộng client; footer do shell lấy từ `totals`.
- Khai báo spec cột: cột nào lọc được, ánh xạ sang biểu thức SQL nào, kiểu số hay text.
- Xoá `pageSize: 200` cứng ở `:135`.

báo `NUMERIC_COLUMNS` để bốn cột số dùng toán tử số thay vì khớp chuỗi trên số đã định dạng.
