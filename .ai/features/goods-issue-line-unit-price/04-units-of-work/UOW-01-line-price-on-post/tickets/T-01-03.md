# T-01-03 — E2E INV-2 sau khi ghi sổ

## Context

Unit test với mock không chứng minh được INV-2, vì nó không chạm sổ thật. A-08 (không luồng ẩn
nào khác gửi `unitPrice`) mới chỉ được xác minh bằng grep — e2e trên DB thật là bằng chứng thứ hai.

## Implementation notes

- Mở rộng `goods-issue-roundtrip.e2e-spec.ts` sẵn có; không tạo file spec mới.
- Dựng một phiếu xuất hai dòng cùng mã hàng, hai đơn giá, cùng `locationId`.
- Sau khi POST, query `stock_ledger_entries` theo `reference_id` và khẳng định:
  đúng hai dòng, `SUM(quantity)` bằng tổng số lượng phiếu (dấu âm), `SUM(line_value)` bằng
  đúng tổng `quantity × unitPrice` của phiếu.
- Nhớ e2e chạy `maxWorkers: 1` và `forceExit: true`; kiểm **output test thật**, đừng tin exit
  code của jest e2e — poller outbox có thể đua với `resetDatabase()` và làm suite thoát code 1
  dù mọi test pass.
