# T-01-01 — Add SHOW_DEPOSIT_ORDER_CONTROLS constant + gate "Đặt cọc" row

## Context

pos-web has no existing feature-flag mechanism (A-01, confirmed). This ticket creates the
single hardcoded switch the whole feature hangs off, and uses it to hide the "Đặt cọc" row
in the payment summary panel. Follows the pos-web constants convention: one file per concern,
UPPER_SNAKE_CASE value, named export, no `index.ts` — see sibling
`apps/pos-web/src/constants/pos-menu.constant.ts`.

`PaymentSummaryBlock.tsx:129-144` currently always renders the "Đặt cọc"
`PosSummaryRow` — as a clickable button when the `onDepositClick` prop is passed, as plain
text otherwise. It is never absent. Gating must hide the row itself, not just its
clickability: AC-01 requires the row/button to not be visible at all.

Do not touch `PaymentSummaryPanel.tsx` or `DepositDialog.tsx` — per `03-logical-design.md`,
once the row itself doesn't render, the `onDepositClick` wiring
(`PaymentSummaryPanel.tsx:147-159,185,192-198`) and `DepositDialog.tsx` become naturally
unreachable. Leaving them untouched is intended (ADR-01), not an oversight.

## Implementation notes

- New file:
  ```ts
  // apps/pos-web/src/constants/feature-flags.constant.ts
  export const SHOW_DEPOSIT_ORDER_CONTROLS = false;
  ```
- In `PaymentSummaryBlock.tsx`, wrap the existing `PosSummaryRow` block for "Đặt cọc"
  (lines 129-144) so it renders only when `SHOW_DEPOSIT_ORDER_CONTROLS` is `true`:
  ```tsx
  {SHOW_DEPOSIT_ORDER_CONTROLS ? (
    <PosSummaryRow
      label={
        onDepositClick ? (
          <button ...>Đặt cọc</button>
        ) : (
          "Đặt cọc"
        )
      }
      value={formatVnd(deposit)}
    />
  ) : null}
  ```
- Import the constant from `@erp/pos/constants/feature-flags.constant` (matches this file's
  existing `@erp/pos/...` import alias style).
- Do not change the `onDepositClick`/`deposit` props, the component's exported `Props`
  interface, or any other row in this file (points, promotion, return-fee rows stay as-is).
- No test-writing in this ticket — regression coverage is T-01-03's scope.
