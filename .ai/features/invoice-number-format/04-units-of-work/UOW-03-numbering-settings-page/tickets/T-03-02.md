# T-03-02 — `DocumentNumberingPage`: ô dấu phân cách, `YYMMDD`, xem trước đúng

## Context

Hai hàm xem trước đang hardcode dấu gạch:

```ts
const datePart = form.includeDate ? `-${form.dateFormat}` : "";
const sequencePart = `-${"0".repeat(...)}`;
const suffixPart  = form.suffix.trim() ? `-${form.suffix.trim()}` : "";
```

Với rule hoá đơn mới (tiền tố rỗng, separator rỗng) chúng sẽ hiện `-YYMMDD-0000` trong khi
số thật là `2608210001`. Xem trước sai còn tệ hơn không có xem trước.

Lưu ý: hai hàm này xem trước theo **token**, không phải ngày thật — `INV-YYYYMM-00000`. Giữ
nguyên quy ước đó (AC-14 chờ `YYMMDD0000`), đừng nhân tiện đổi sang render ngày thật.

## Implementation notes

- Thêm `"YYMMDD"` vào `DATE_FORMAT_OPTIONS` (dòng ~59) và vào **cả hai** union type
  `dateFormat` (dòng ~28 của `DocumentNumberRule` và ~49 của `RuleFormState`). Đặt đầu danh sách.
- Thêm `separator: string` vào `DocumentNumberRule` và `RuleFormState`; mặc định form là `"-"`
  cho rule mới, và nạp từ `rule.separator` khi mở sửa (dòng ~333). Nối vào payload
  create/update (dòng ~363, ~374).
- Ô nhập mới "Dấu phân cách" đặt cạnh Tiền tố / Hậu tố. **Cho phép rỗng** — đó là cả mục đích
  của nó; đừng thêm `required`.
- `buildPreview` và `buildFormatPreview` phản chiếu đúng `formatDocumentNumber` phía server,
  gồm **cả nhánh tắt**:
  ```ts
  const sep = form.separator;
  const seq = "0".repeat(Number(form.sequenceLength) || 5);
  if (!form.includeDate && !form.suffix.trim()) return `${form.prefix.trim()}${seq}`;
  return [form.prefix.trim(), ...(form.includeDate ? [form.dateFormat] : []),
          seq, ...(form.suffix.trim() ? [form.suffix.trim()] : [])].join(sep);
  ```
  Bỏ nhánh tắt thì rule "Phiếu thu" sẽ hiện `PT-000000` trong khi số thật là `PT000000` —
  đúng loại lệch mà cả feature này đang đi sửa, chỉ khác là lệch trên màn cấu hình.
- Bỏ `|| "PREFIX"` trong `buildPreview`: tiền tố rỗng nay là hợp lệ, hiện chữ `PREFIX` sẽ
  làm người dùng tưởng mình quên điền.
- `DEFAULT_PREFIX` map (dòng ~598): `[DocumentType.INVOICE]: ""` và `[DocumentType.RETURN]: ""`.
- Nhập từ `@erp/ui`, icon từ `lucide-react`, không đụng file nào khác.
