# T-01-03 — pos-web đọc customer inline

## Context

`useInvoiceListV2Query` (`use-query-invoice.ts:262-284`) chạy
`Promise.all(ids.map(customerService.get))` sau mỗi lần search. Với 100 dòng/trang là tối
đa 100 request nối thêm. `useReturnableInvoicesQuery` trong cùng file (dòng ~228) đã là
bản mẫu của hình dạng sau khi sửa — nó gọi
`mapInvoiceToReturnRow(inv, inv.customer ?? null, …)` và không enrich gì.

## Implementation notes

1. `interfaces/customer.interface.ts` — thêm `code?: string | null` vào `CustomerRow`.
   Field optional nên không consumer nào phải đổi (A-07).
2. `use-query-invoice.ts` — trong `useInvoiceListV2Query`, xoá cả khối `ids`/`entries`/`byId`
   và đổi phần map thành:
   ```ts
   const rows = res.data.map((inv) => mapInvoiceToListRow(inv, inv.customer ?? null));
   ```
   Giữ nguyên `queryKey`, `staleTime`, `placeholderData` — không đụng.
3. `invoiceListMapper.ts` — chữ ký `mapInvoiceToListRow` **không đổi**. Chỉ sửa docblock:
   `customer` nay do BE trả inline, không còn enrich từ `customerService.get`. Cùng cách
   `returnInvoiceMapper.ts` đã ghi.
4. Gỡ import `customerService` **chỉ khi** không còn chỗ nào trong file dùng — T-01-04 xoá
   nốt chỗ còn lại, nên ở ticket này import có thể vẫn còn. Đừng xoá sớm rồi build đỏ.

Điểm dễ sai: `InvoiceListRowCustomer` trong mapper khai `code`/`name`/`phone` optional —
`CustomerRow` sau khi thêm `code` là tương thích cấu trúc, không cần cast.

Chuỗi UI giữ nguyên tiếng Việt; comment trong pos-web theo phong cách file hiện có.
