# T-01-04 — Xoá hook N+1 còn sót

## Context

`useInvoiceListQuery` (`use-query-invoice.ts:298-341`) là hook tiền-v2 của trang
`/invoices`. Nó đã bị `useInvoiceListV2Query` thay thế nhưng chưa ai xoá, và mang **cùng**
vòng `Promise.all(customerService.get)` mà T-01-03 vừa gỡ khỏi hook v2. Để lại là để sẵn
một cái bẫy cho người tiếp theo nối lưới vào.

Đã grep toàn `apps/pos-web/src` và `apps/backoffice-web/src`: không importer nào ngoài
chính file khai báo (A-10, user chốt xoá 2026-08-25).

## Implementation notes

Xoá hook và mọi import chỉ nó dùng. Sau khi xoá, kiểm lại từng import trong file trước khi
gỡ — vài cái dùng chung với hook khác:

- `customerService` — sau ticket này không còn chỗ nào dùng trong file → gỡ
- `INVOICE_LIST_DEFAULT_PAGE_SIZE` — kiểm còn ai dùng trong file không
- `INVOICE_KEYS.LIST` — nếu không còn ai gọi, để nguyên trong file constant (dead code có
  sẵn, ngoài phạm vi), chỉ gỡ import ở đây
- `invoiceService.list` / `ListInvoicesParams` — **không** xoá; đó là API service dùng chung,
  ngoài phạm vi ticket này

Không đụng `useInvoiceListV2Query`, không đụng hook nào khác.
