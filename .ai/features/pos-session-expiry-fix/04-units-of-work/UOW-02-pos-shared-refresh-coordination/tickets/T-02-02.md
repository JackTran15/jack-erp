# T-02-02 — http.ts uses the shared refreshOnce

## Context
`http.ts:13-55` has its own `refreshPromise`/`refreshOnce`/`tryRefreshToken`. `request()`
(~93-106) and `requestBlob()` (~130-143) both call `refreshOnce()` on a 401.

## Implementation notes
- Delete `http.ts`'s local `refreshPromise`, `refreshOnce`, `tryRefreshToken`.
- Import `refreshOnce` from `./token-refresh` instead; `request()`/`requestBlob()`'s call
  sites don't otherwise change.
- Double-check no other file in pos-web imports `refreshOnce`/`tryRefreshToken` from
  `http.ts` directly (grep before deleting the exports, if they were exported).

## Done when
- [ ] `http.ts` no longer declares its own `refreshPromise`
- [ ] `request()` and `requestBlob()`'s 401-handling behavior is otherwise unchanged
      (single retry, redirect-to-login on exhausted refresh)
- [ ] `pnpm --filter @erp/pos-web build` type-checks clean
