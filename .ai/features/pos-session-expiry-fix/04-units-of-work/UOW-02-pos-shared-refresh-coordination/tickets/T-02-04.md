# T-02-04 — Tests prove single-flight refresh and shared failure handling

## Context
Per A-04, no component-rendering test tooling exists in pos-web — this is a plain-function
test, matching `api-axios.test.ts`'s existing style (mock `localStorage`, spy on the
network call, no DOM). Testing `token-refresh.ts`'s `refreshOnce` directly proves the
coordination property both `http.ts` and `api-axios.ts` now delegate to, without needing to
wire through two different HTTP mocking styles (fetch + axios) in one test.

## Implementation notes
- `token-refresh.ts` uses `axios.post` (corrected post-T-02-01; see that ticket's
  "Post-acceptance correction" note) — **do not** copy `api-axios.test.ts`'s
  `vi.spyOn(axios, "post")` pattern. Verified during T-02-03 that it doesn't work in this
  repo's vitest setup (`AssertionError: expected "wrap" to be called 1 times, but got 0
  times` — a pre-existing, environment-level spy/ESM-interop issue, confirmed present even
  against unmodified pre-feature code, out of scope to fix here). Use `vi.mock("axios", ...)`
  (module-level mock) instead — confirmed working in this environment: mock the default
  export's `post` as a `vi.fn()`, import `axios` normally in the test, assert on
  `(axios.post as any).mock.calls`.
- AC-07: call `refreshOnce()` twice without awaiting the first (simulating two
  near-simultaneous 401s from the two different clients) — assert the mocked `axios.post` was
  called exactly once, and both calls resolve to the same result.
- AC-08: mock `axios.post` to reject (network error) or resolve with no `accessToken` — assert
  both concurrent `refreshOnce()` callers resolve to `false` (not one resolving, one hanging or
  throwing), and that both tokens are cleared exactly once, not twice.
- Follow `api-axios.test.ts`'s `fakeLocalStorage()` helper pattern rather than inventing a
  new one.

## Done when
- [ ] AC-07 test passes: exactly one network call for two concurrent `refreshOnce()` calls
- [ ] AC-08 test passes: shared failure resolves both callers, tokens cleared once
- [ ] `npx vitest run token-refresh.test.ts` (or the workspace equivalent) passes
