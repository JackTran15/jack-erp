# T-01-07 — Regenerate api-client

## Context

Quy ước repo (CLAUDE.md): đổi endpoint thì phải chạy `pnpm openapi:generate` và commit
cả `openapi.snapshot.json` lẫn `schema.ts`. `pos-web` không dùng client generate ra —
nó có `http` wrapper và interface viết tay — nhưng snapshot vẫn phải khớp, nếu không
lần regenerate sau sẽ đẻ ra một diff lẫn lộn hai feature.

## Implementation notes

- API phải đang chạy ở `:4000` (`make dev-api`) thì `openapi:generate` mới đọc được
  `/docs-json`.
- **Kiểm trước khi chạy**: `:4000` có thể đang là API dựng từ một worktree khác — chạy
  `curl -s localhost:4000/docs-json | grep mainShowroomQuantity` để chắc đúng bản có
  thay đổi của ticket này.
- Không sửa tay `schema.ts`.
