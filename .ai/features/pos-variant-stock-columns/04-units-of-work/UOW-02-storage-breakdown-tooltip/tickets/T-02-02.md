# T-02-02 — DTO cho phân rã theo kho

## Context

Một DTO mới, `PosVariantStorageDto`, đặt cạnh `PosVariantLocationDto` đã có. Hai cái
này **không** thay thế nhau: `locations` phân rã theo vị trí (kệ/ô) và đang được
`variantToCatalogLine` dùng để suy ra `defaultLocationId`; `storages` phân rã theo kho
và chỉ phục vụ tooltip. Bỏ hay đổi `locations` sẽ làm hỏng đường thêm hàng vào giỏ.

## Implementation notes

```ts
export class PosVariantStorageDto {
  @ApiProperty({ format: 'uuid' }) storageId: string;
  @ApiProperty() name: string;
  @ApiProperty({ description: 'Raw on-hand at this storage; may be negative.' })
  quantity: number;
  @ApiProperty({ description: 'True for the storage backing the branch main showroom.' })
  isMainShowroom: boolean;
}
```

- Thêm `@ApiProperty({ type: [PosVariantStorageDto] }) storages` vào
  `PosProductVariantDto`, mô tả rõ đây là kho của **chi nhánh hiện tại**, đã sort sẵn.
- Nối qua `toVariantDto`; thiếu extras thì mặc định `[]`.
- Mô tả Swagger bằng tiếng Anh.
