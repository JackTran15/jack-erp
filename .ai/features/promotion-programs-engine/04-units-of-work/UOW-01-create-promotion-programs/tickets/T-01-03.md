# T-01-03 — Domain model và ports

## Context

Ranh giới cho phép unit-test engine mà không cần DB hay Nest container. **Cấm import
`@nestjs/*` và `typeorm`** dưới `domain/` — kiểm bằng
`grep -rE "from '(@nestjs|typeorm)" apps/api/src/modules/promotion/domain/` → 0 kết quả.

## Implementation notes

- `PromotionProgram.create(props)` chạy validate rồi trả aggregate; mọi field `readonly`,
  không có setter công khai; thao tác sửa trả instance mới.
- `DomainValidationError` gom **nhiều** issue `{ field, code, message }` — form 5 hình thức có
  rất nhiều trường, báo từng lỗi một sẽ khiến người dùng lưu đi lưu lại.
- Invariant BR-004: `NAME_REQUIRED`, `END_DATE_BEFORE_START_DATE`,
  `DISCOUNT_VALUE_NOT_POSITIVE`, `PERCENT_OVER_100`, `TIER_RANGE_INVALID`,
  `TIER_RANGE_OVERLAP`, `TIERS_EMPTY`, `REWARD_LINES_EMPTY`, `CUSTOMER_GROUP_IDS_EMPTY`,
  `CARD_TIER_ID_REQUIRED`, `BUY_QUANTITY_INVALID`, `GIFT_QUANTITY_INVALID`.
- `REWARD_LINES_EMPTY` **trừ** `INVOICE_DISCOUNT`, `TIERED_DISCOUNT` + `INVOICE_VALUE`, và
  `BUY_M_GET_N` + `CHEAPEST` (A-27 — `CHEAPEST` tặng chính SP rẻ nhất trong lưới `CONDITION`).
- `TimeWindow.contains()` xử lý ca qua đêm bằng OR: `start <= end ? (at >= start && at <= end)
  : (at >= start || at <= end)`.
- `DateWindow.contains()`: `start` null = không giới hạn đầu, `end` null = không giới hạn cuối
  (A-04 → AC-30 lưu được CTKM vô thời hạn).
- `CustomerScope.matches()` phủ 4 `applyTo`; nhánh `BIRTHDAY` phủ 4 `birthdayMatch`, trong đó
  `RANGE` so ngày-trong-năm và **quấn vòng năm** (sinh nhật 30/12 với `afterDays=5` phải khớp
  1–4/01) — cùng kỹ thuật với ca qua đêm. Khách vãng lai chỉ khớp `ALL_CUSTOMERS`.
- `roundVnd` là nơi **duy nhất** làm tròn về đồng.
- Port khai báo bằng `Symbol()` + `interface`, không phải `abstract class`.
- Aggregate mang sẵn `groups[]` (mỗi group có `lines[]` + `tiers[]`), `condition`,
  `branchIds[]`, `customerGroupIds[]` — repository nạp/ghi trọn gói, engine không lazy-load.
