# T-03-02 — Cổng chặn giữa backend và frontend

## Context

Mọi ticket FE từ T-03-03 trở đi phụ thuộc type sinh ra từ đây. File sinh tự động — **cấm sửa
tay**.

## Implementation notes

```bash
make dev-api                      # terminal riêng, đợi API lắng nghe :4000
pnpm openapi:generate
git diff --stat packages/api-client/src/generated/schema.ts
```

- Nếu `openapi:generate` báo không kết nối được `:4000`: kiểm `DISABLE_SWAGGER` và `NODE_ENV`
  — `/docs-json` bị tắt khi `NODE_ENV=production` hoặc `DISABLE_SWAGGER=1`.
- Diff chỉ được chứa endpoint mới của promotion/voucher. **Nếu diff động tới module khác thì
  dừng lại**, tìm nguyên nhân (thường là ai đó đổi DTO mà chưa regen) — không commit đè.
- Enum ra dạng `string` trần nghĩa là thiếu `@ApiProperty({ enum: … })` ở DTO → quay lại sửa
  DTO rồi regen, không vá ở file sinh.
- Commit riêng cho bước regen, không trộn với thay đổi logic.

13 route phải có mặt: 8 route `/v2/promotions/*` (`search`, `{id}` GET/PUT/DELETE, base POST,
`{id}/duplicate`, `{id}/status`, `evaluate`) và 5 route `/v2/vouchers/*` (`search`, base POST,
`{id}` PUT/DELETE, `{id}/duplicate`).
