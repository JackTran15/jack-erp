# T-05-02 — Cửa sổ giờ nửa khoảng

## Context

D5. `time-window.ts:24-33`:

```ts
/** Either bound missing = open all day. */
contains(at: TimeOfDay): boolean {
  if (!this.start || !this.end) return true;   // ← dòng 26
```

Đặt 18:00, bỏ trống giờ kết thúc → chạy 24/24, nên bán lúc 09:00 vẫn được giảm. Akenzy chốt: phải là
"từ 18:00 đến hết ngày".

Nhánh qua đêm (dòng 32, `start > end`) **đang đúng** và phải giữ nguyên. Anh em `DateWindow`
(`date-window.ts:19-24`) đã xử lý độc lập từng đầu — theo đúng mẫu đó.

## Implementation notes

```ts
contains(at: TimeOfDay): boolean {
  if (!this.start && !this.end) return true;                  // cả hai trống = cả ngày
  const target = toMinutes(at);
  if (!this.end)   return target >= toMinutes(this.start!);   // 18:00 → hết ngày
  if (!this.start) return target <= toMinutes(this.end);      // đầu ngày → 18:00
  const start = toMinutes(this.start), end = toMinutes(this.end);
  return start <= end ? target >= start && target <= end
                      : target >= start || target <= end;      // qua đêm — giữ nguyên
}
```

- Sửa cả comment `/** Either bound missing = open all day. */` — nó đang mô tả đúng hành vi cũ, để
  lại sẽ thành sai lệch.
- **Không** thêm validate "both-or-neither" (**A-08**): một khi nửa khoảng đã có nghĩa thì bắt buộc
  cả hai lại cắt mất cấu hình hợp lệ.
- `time-window.spec.ts` hiện có test khoá hành vi "thiếu một đầu = cả ngày". Sửa nó, và **ghi trong
  message/comment rằng đây là đổi hành vi có chủ ý, dẫn A-07** — nếu không, người review sẽ đọc
  thành "sửa test cho qua".
- Không đụng schema: `start_time` / `end_time` vẫn nullable độc lập.
