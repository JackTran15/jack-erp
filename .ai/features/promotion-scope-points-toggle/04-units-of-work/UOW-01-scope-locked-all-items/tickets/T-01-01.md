# T-01-01 — Replace the "Phạm vi áp dụng" RadioGroup with a locked display

## Context

`ApplyScopePromotionSection.tsx` currently renders an editable `RadioGroup` (2 options:
`NON_PROMO_ONLY` / `ALL_ITEMS`) bound to `form.applyScope`. The business wants the choice
removed entirely — the section should always communicate "Tất cả hàng hóa trong hóa đơn"
(the `ALL_ITEMS` label) with no way to change it. See ADR-01 in `03-logical-design.md`.

## Implementation notes

- Remove the `RadioGroup` import and usage; remove the now-unused `onChange` wiring for
  `applyScope` from this component (the prop itself can stay on `Props` if other sections
  in the same file still need `onChange`, but this component no longer calls it).
- Render the "Phạm vi áp dụng" `<h2>` heading unchanged, followed by a static line using the
  same label text already defined in `APPLY_SCOPE_OPTIONS` for `ApplyScope.ALL_ITEMS`
  (`program-form.constants.ts:64`, "Tất cả hàng hóa trong hóa đơn") — do not hardcode a
  second copy of that string; import and look it up, so the two can never drift.
- This ticket does not change what the section is bound to (`form.applyScope`) or what gets
  saved — that is T-01-02. This ticket is UI-only.
- Do not touch `APPLY_SCOPE_OPTIONS` itself (T-01-02's concern) or any of the other 4
  promotion-variant components — none of them import this file today; keep it that way.

## Done when

- [x] Opening the invoice-discount form shows no radio buttons in "Phạm vi áp dụng" —

- [x] No compile/type error from the now-unused `RadioGroup` import being removed
- [x] `PromotionProductDiscount`, `PromotionTieredDiscount`, `PromotionBuyGet`,
      `PromotionGift` are untouched and still do not render this section
