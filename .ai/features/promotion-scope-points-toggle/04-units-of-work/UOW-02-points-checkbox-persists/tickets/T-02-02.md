# T-02-02 — Entity field: `PromotionProgramEntity.accruePoints`

## Context

Adds the TypeORM column mapping for the column T-02-01 created. `synchronize: false`
everywhere in this repo, so the entity field must match the migration exactly or the app
will read/write against a column that silently doesn't match what TypeORM thinks the type
is.

## Implementation notes

Add next to `invoiceScope` (`promotion-program.entity.ts:93-100`), following the same
`@Column` style already used for `autoApply` (line 90-91, also a plain non-nullable
boolean with a default — a closer pattern match than `invoiceScope`, which is nullable):

```ts
@Column({ name: 'accrue_points', type: 'boolean', default: false })
accruePoints: boolean;
```

Not optional/nullable (unlike `invoiceScope?: PromotionInvoiceScope | null`) — every row has
a concrete `true`/`false`, matching the column's `not null` constraint.
