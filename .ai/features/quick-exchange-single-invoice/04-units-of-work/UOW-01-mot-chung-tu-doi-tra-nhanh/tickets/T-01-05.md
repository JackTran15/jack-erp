# T-01-05 — Regenerate `@erp/api-client`

## Context

`originalInvoiceId` chuyển từ required sang optional trong schema OpenAPI. Quy ước repo:
chạy API rồi `pnpm openapi:generate`, commit cả file sinh ra lẫn snapshot; **không** sửa tay
`schema.ts`.

## Implementation notes

```bash
make dev-api            # API phải đang chạy ở :4000
pnpm openapi:generate
```

- Kiểm diff: chỉ `CreateExchangeInvoiceDto.originalInvoiceId` rời khỏi mảng `required`.
  Nếu diff động tới endpoint khác thì có ai đó đã sửa DTO ngoài phạm vi — dừng lại và hỏi,
  đừng commit chung.
- pos-web gọi API qua `http` wrapper riêng chứ không qua `@erp/api-client`, nên bước này
  không mở khoá gì cho FE — nó giữ hợp đồng khỏi trôi.

## Done when

- [ ] `pnpm openapi:generate` chạy xong không lỗi
- [ ] Diff của `openapi.snapshot.json` chỉ chạm `CreateExchangeInvoiceDto`  ← **đây là chỗ chặn**
- [ ] `packages/api-client/src/generated/schema.ts` được commit cùng snapshot
- [ ] `pnpm build` toàn workspace xanh

## Bị chặn — phải chạy lại trên cây sạch

Đã chạy thật 14/08/2026 rồi **revert**, vì tiêu chí thứ hai không đạt. Snapshot sinh ra từ
API đang chạy, mà API đó phục vụ working tree đang mang **thay đổi API chưa commit của việc
khác** (`columnFilters`, `maximum: 200 → 50000` ở các endpoint inventory-report). Diff ra 108
dòng thay vì đúng một dòng `required` — gom nhầm việc của người khác vào commit này.

Hai điều đã xác nhận được trong lúc thử:

- Contract **đang cũ thật**: `CreateExchangeInvoiceDto.required` vẫn liệt kê
  `originalInvoiceId`. Sau khi regen đúng, nó còn `['sessionId','reason','returnLines','newLines']`.
- Không có hệ quả runtime: pos-web gọi API qua `lib/common/http`, không qua
  `@erp/api-client`. Contract cũ không làm hỏng luồng nào đang chạy.

Cạm bẫy cho người chạy lại: nếu không với tới được API, `scripts/generate-openapi.mjs`
**âm thầm rơi về `openapi-stub.json`** và ghi đè `schema.ts` — lần thử đầu tiên nó xoá 25.250
dòng mà vẫn exit 0. Luôn xem `git diff --stat packages/api-client/` trước khi stage.

Chạy lại khi các thay đổi inventory-report kia đã commit, hoặc trên một cây chỉ có epic này.
