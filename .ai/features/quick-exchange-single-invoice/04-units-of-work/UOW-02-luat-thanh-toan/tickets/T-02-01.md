# T-02-01 — Ẩn `DebtCheckRow` / `RefundToDebtRow` ở luồng nhanh

## Context

`PaymentSection.tsx:180` hôm nay chọn giữa hai hàng bằng đúng dấu của net:
`{isRefundFlow ? <RefundToDebtRow /> : <DebtCheckRow />}`. Cả hai đều vô nghĩa khi không có
hoá đơn gốc (ADR-03), nên cần thêm một điều kiện thứ hai.

Điều kiện phải là **"luồng đổi trả và không có hoá đơn gốc"**, không phải
`variant === QUICK_EXCHANGE`: luồng SALE bình thường vẫn phải giữ `DebtCheckRow`.

`checkout-session.store.ts` là một trong bốn file sẽ conflict khi `feat/promotions` merge
(A-05) — thêm selector mới ở cuối khối selector, đừng chen vào giữa.

## Implementation notes

- Selector mới trong `checkout-session.store.ts`, đặt cạnh `selectIsReturnExchangeInvoice`:

  ```ts
  /** Luồng đổi trả KHÔNG có hoá đơn gốc (đổi trả nhanh) — không có công nợ nào để cấn (ADR-03). */
  export function selectIsQuickReturnFlow(state: PosCheckoutSessionState): boolean {
    const session = selectActiveSession(state);
    if (!session) return false;
    return (
      session.checkoutVariant !== CheckoutVariantEnum.SALE && !session.originalInvoiceId
    );
  }
  ```

- `PaymentSection.tsx`: đọc selector, rồi
  `{isQuickReturnFlow ? null : isRefundFlow ? <RefundToDebtRow /> : <DebtCheckRow />}`.
  Giữ nguyên `showKeepChange` / `showForgiveShortage` — hai cái đó vẫn có nghĩa.
- **Không** sửa `DebtCheckRow` hay `RefundToDebtRow`: chúng còn phục vụ SALE và
  đổi trả theo hoá đơn.
- AC-11 (nút Thanh toán khoá khi thu thiếu) không cần code mới:
  `use-checkout-collect-state.ts:73` đã bỏ chặn **chỉ khi** `debt && selectedCustomer`.
  Checkbox ẩn ⇒ `debt` không bao giờ bật ⇒ nút khoá. Ticket chỉ cần **kiểm** điều này đúng,
  và ghi vào Done when — không thêm điều kiện thứ hai vào hook đó.
