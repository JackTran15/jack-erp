# T-01-02 — Module phạm vi dùng chung

## Context

Hai mươi handler ở bốn miền (`inventory-reports`, `reporting/{invoice,debt,profit}-report`)
hiện giống nhau đến từng dòng và **tất cả** chỉ lọc `organizationId` — đã đếm: 0/20 handler
nhắc tới `branchId`. ADR-05 gom ngữ nghĩa phạm vi vào một module thuần để 20 handler chỉ còn
gọi, thay vì 20 bản sao có cơ hội lệch nhau.

Module này là TypeScript thuần: không `@nestjs/*`, không decorator TypeORM — chỉ nhận
`ActorContext` và trả về vị từ / entity. Nhờ vậy test được bằng unit test không cần DB.

## Implementation notes

Xuất bốn thứ (hợp đồng đầy đủ ở `03-logical-design.md` § Contracts):

- `resolveTemplateScope(scope, actor): { scope: TemplateScope; branchId: string | null }`
  — `'chain'` → `null`; `'branch'` → `actor.branchId`, rỗng thì ném
  `BadRequestException('Branch scope requires an active branch')`; bỏ trống → `'branch'` nếu
  `actor.branchId` có, ngược lại `'chain'` (giữ tương thích cho client chưa gửi `scope`).
- `readScopeWhere(actor, resolved)` — `branch` → `(branchId = :b OR branchId IS NULL)`;
  `chain` → `branchId IS NULL`. Trả về mảng điều kiện `FindOptionsWhere` để handler dùng
  thẳng trong `repo.find`/`findOne` (TypeORM: mảng = OR).
- `pickEffective(rows, resolved)` — gom theo `(reportType, name)`, ưu tiên hàng có
  `branchId === resolved.branchId`, không có thì lấy hàng `branchId == null`. Giữ nguyên thứ
  tự `sortOrder ASC, createdAt DESC` mà handler đã sắp.
- `cloneForBranch(row, branchId, userId)` — entity mới sao y `reportType/name/description/
  columns/filters/sortOrder`, gắn `branchId` + `createdBy = userId`, **không** mang theo `id`.

Kèm theo:
- `TemplateScope` = `'chain' | 'branch'` khai ở `packages/shared-interfaces/src/invoice-report/template.ts`,
  và thêm `scope: TemplateScope` + `branchId: string | null` vào `InvoiceReportTemplateView`.
- `toTemplateView` (`report-template.view.ts`) điền hai trường mới từ `e.branchId`.

Toàn bộ mã và comment bằng tiếng Anh.

## Ghi chú khi làm

- `readScopeWhere` / `writeScopeWhere` trả `FindOptionsWhere` chứ không phải chuỗi SQL, nên
  test khẳng định được **vị từ** thay vì kết quả. Ba ca so `IsNull()` bằng
  `value instanceof FindOperator && value.type === 'isNull'` — so bằng `toEqual({branchId: null})`
  sẽ xanh cả khi mã dùng `null` trần, đúng cái bẫy T-02-01 phải tránh.
- `TemplateScope` đặt ở `packages/shared-interfaces/src/invoice-report/template.ts` cạnh
  `InvoiceReportTemplateView` (đã thêm `scope` + `branchId`), vì FE cũng cần kiểu này.
- Toàn bộ suite `@erp/api`: 3434 pass / 2 fail. Hai ca đỏ nằm trong `auth.service.spec.ts`
  (`switchBranch` → `ForbiddenException: Branch not assigned to user`) và **đỏ sẵn trên cây
  sạch** — kiểm bằng `git stash -u` rồi chạy lại. Không liên quan thay đổi này.
