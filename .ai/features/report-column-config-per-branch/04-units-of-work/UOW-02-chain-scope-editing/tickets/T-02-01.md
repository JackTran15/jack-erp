# T-02-01 — Xoá chỉ trong phạm vi đang đứng

## Context

Đọc dùng `readScopeWhere` (chi nhánh **hoặc** chuỗi) để kế thừa được. Xoá thì không: nếu
delete cũng dùng vị từ đọc, người đứng ở chi nhánh sẽ xoá được bản chuỗi mà cả tổ chức đang
kế thừa. Đó là khác biệt duy nhất giữa `readScopeWhere` và `writeScopeWhere`, và là lý do
`writeScopeWhere` tồn tại.

## Implementation notes

- `writeScopeWhere(actor, resolved)` khớp **đúng** `branchId`:
  ```ts
  { organizationId: actor.organizationId,
    branchId: resolved.branchId === null ? IsNull() : resolved.branchId }
  ```
  `IsNull()` là bắt buộc — `{ branchId: null }` trong `findOne` của TypeORM không dịch thành
  `IS NULL`, nó sinh `branch_id = NULL` và luôn trả rỗng, khiến xoá bản chuỗi ở chế độ chuỗi
  cũng 404 (im lặng sai theo chiều ngược lại).
- Delete handler đổi từ `{ id, organizationId }` sang `{ id, ...writeScopeWhere(actor, resolved) }`,
  với `resolved = resolveTemplateScope(scope, actor)`; `scope` lấy từ `@Query('scope')` đã nối ở T-01-04.
- Thông điệp 404 giữ nguyên.
