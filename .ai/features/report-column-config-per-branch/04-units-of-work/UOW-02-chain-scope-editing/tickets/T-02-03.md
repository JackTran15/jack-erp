# T-02-03 — Test cho đường chuỗi

## Implementation notes

Bổ sung vào spec của update (đã tạo ở T-01-06) và tạo spec mới cho delete:

| Ca | Kỳ vọng | AC |
| -- | ------- | -- |
| update, `scope='chain'`, hàng đích `branchId = null` | `repo.save` nhận entity **có** `id` cũ (UPDATE tại chỗ, không tách bản) | AC-05 |
| update, `scope='chain'`, id là hàng của một chi nhánh | ném `NotFoundException` | AC-05 |
| update, `scope='chain'` | `findOne` được gọi với vị từ chỉ có `IsNull()` cho `branchId`, không có nhánh OR | AC-05 |
| delete, `scope='branch'`, id bản chuỗi | ném `NotFoundException`, `softRemove` **không** được gọi | AC-06 |
| delete, `scope='chain'`, id bản chuỗi | `softRemove` được gọi đúng một lần | AC-06 |

Ca thứ ba khẳng định trên **vị từ** truyền vào `findOne` chứ không chỉ trên kết quả: đây là
chỗ duy nhất phân biệt "đọc đúng phạm vi chuỗi" với "đọc phạm vi chi nhánh rồi tình cờ ra
cùng hàng".
