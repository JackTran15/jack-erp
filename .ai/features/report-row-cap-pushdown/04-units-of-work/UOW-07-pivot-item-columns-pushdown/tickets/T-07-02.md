# T-07-02 — Spec cột total bằng truy vấn con trên stock_balances

## Context

Cột "Tổng" là tổng tồn toàn tổ chức của một mặt hàng. Nó chỉ tồn tại sau khi gấp ô ở JS, nên muốn lọc được thì phải dựng lại bằng SQL ở bước chọn mặt hàng — nếu không, lọc sẽ chạy sau khi trang đã bị cắt.

## Implementation notes

- Spec `total` → truy vấn con tương quan `(SELECT COALESCE(SUM(sb.quantity),0) FROM stock_balances sb WHERE sb.item_id = i.id AND sb.organization_id = $1 AND (<branchIds>))`
- Truy vấn con phải mang ĐÚNG bộ lọc chi nhánh mà `itemPageSql` đang dùng, nếu không tổng sẽ tính cả chi nhánh đã bị loại
- kind `number`

## Done when

- [x] Lọc `total > N` trả đúng tập mặt hàng
- [x] Khi có `branchIds`, `total` chỉ cộng các chi nhánh trong phạm vi — test với fixture nhiều chi nhánh
- [x] `total` (số dòng) không đổi khi bộ lọc rỗng
