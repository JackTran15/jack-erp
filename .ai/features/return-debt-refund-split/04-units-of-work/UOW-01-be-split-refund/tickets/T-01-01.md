# T-01-01 — Cột `invoices.offset_amount`

## Context

ADR-02: phần cấn trừ phải có nguồn sự thật riêng, không suy lại từ `invoice_debts` (dòng
ADJUSTMENT có thể bị vòng đời huỷ phiếu tác động). Migration viết tay theo quy ước repo —
**không** dùng `migration:generate`, nó sinh drift khổng lồ trên schema này.

## Work

- Migration: `ALTER TABLE invoices ADD COLUMN offset_amount numeric(18,2) NOT NULL DEFAULT 0`
  + `down()` drop cột.
- `InvoiceEntity`: `@Column({ name: 'offset_amount', type: 'numeric', precision: 18, scale: 2, default: 0 })
  offsetAmount: number;` đặt ngay cạnh `refundedAmount`, kèm chú thích English rằng
  `cashOut = refundedAmount − offsetAmount`.
