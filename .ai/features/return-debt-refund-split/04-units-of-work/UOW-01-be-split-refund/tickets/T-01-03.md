# T-01-03 — Dòng công nợ điều chỉnh + hợp đồng API

## Context

`createReturnDebtAdjustment` đang chỉ chạy trong nhánh `OFFSET`. Sau T-01-02 nó phải chạy
bất cứ khi nào `offsetAmount > 0`, vì đó là thứ tab Công nợ hiển thị (AC-13) và là thứ
`cancel-return` dựa vào để hoàn nguyên.

## Work

- Gọi `createReturnDebtAdjustment` khi `offsetAmount > 0`, số tiền `-offsetAmount`.
- `CheckoutReturnDto`: giữ `refundMethod` với `OFFSET` hợp lệ nhưng ghi rõ trong
  `@ApiProperty` là alias tương thích ngược của `CASH`; `validateRefundMatrix` bỏ nhánh
  ràng buộc riêng cho OFFSET do client gửi.
- Response phiếu trả (và Swagger) khai báo `offsetAmount`.

## Done when

- [x] Phiếu trả có cấn trừ luôn có đúng 1 dòng `invoice_debts` ADJUSTMENT mang mã phiếu trả
- [x] Gọi lại cùng `X-Idempotency-Key` không sinh dòng ADJUSTMENT thứ hai
- [x] Client cũ gửi `refundMethod: "OFFSET"` vẫn 201 và cho kết quả tách y hệt `CASH`
- [x] `/docs-json` hiện trường `offsetAmount`
