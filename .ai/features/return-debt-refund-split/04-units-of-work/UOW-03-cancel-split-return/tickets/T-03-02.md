# T-03-02 — Thu lại `refundedAmount − offsetAmount`

## Context

`buildCollectionLegs` L414 lấy `Number(invoice.refundedAmount)` làm số tiền thu lại. Với
phiếu tách, số đó lớn hơn số thật đã chi.

## Work

- `const cashOut = Number(invoice.refundedAmount) - Number(invoice.offsetAmount ?? 0);`
  dùng `cashOut` cho cả nhánh CASH và BANK, `return []` khi `cashOut <= 0`.
- Cập nhật chú thích của hàm: OFFSET không còn là một `refundMethod`, mà là phần
  `offsetAmount` được hoàn nguyên bên trong transaction.

## Done when

- [x] Huỷ phiếu tách sinh chân thu lại đúng 300.000
- [x] Huỷ phiếu cấn trừ toàn phần không sinh chân thu nào
- [x] Phiếu lịch sử (`offset_amount = 0`) thu lại đủ `refundedAmount` như trước
