# T-04-03 — Xem trước khoản tách

## Context

Quy ước pos-web: gọi API qua `services/`, wrap bằng hook trong `hooks/react-query/`,
queryKey lấy từ `react-query-key.constant.ts`, component riêng của trang không prefix `Pos`.

## Work

- `invoiceService.getOutstandingDebt(id)`; hook `useOutstandingDebt(originalInvoiceId)`
  chỉ enabled khi đang ở luồng hoàn tiền và có `originalInvoiceId`.
- `DebtOffsetRow`: hiện "Trừ công nợ" = `min(khoản hoàn, dư nợ)` và số tiền chi ra =
  phần còn lại, định dạng `vi-VN`.
- Render trong `PaymentSection` ở nhánh `isRefundFlow`, ẩn hoàn toàn khi `remainingDebt = 0`
  hoặc chưa tải xong hoặc lỗi (không chặn thao tác).
