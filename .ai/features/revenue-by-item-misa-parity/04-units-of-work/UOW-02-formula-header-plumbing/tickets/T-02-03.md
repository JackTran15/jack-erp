# T-02-03 — Trang in: `<th>` 2 dòng

## Context

`renderReportTableHtml` dựng header bằng
`columns.map((column) => \`<th>${escapeHtml(column.label)}</th>\`)`. Sau T-02-01 payload đã
mang `desc`, nên trang in phải vẽ nó — nếu không thì file Excel và trang in nói khác nhau,
đúng thứ ADR-01 của `export-print` tồn tại để chặn.

Trang in đi đường CSS riêng, **không** import hằng số từ `xlsx-style.ts` — `xlsx-style.ts`
đã tuyên bố rõ là không chia sẻ hằng số trình bày qua ranh giới BE/FE.

## Implementation notes

Header cell:

```ts
const headerCells = columns
  .map((column) => {
    const label = escapeHtml(column.label);
    return column.desc
      ? `<th>${label}<span class="formula">${escapeHtml(column.desc)}</span></th>`
      : `<th>${label}</th>`;
  })
  .join("");
```

`escapeHtml` cho cả `desc` — nội dung có `(`, `)`, `/`, `=` thì vô hại, nhưng `desc` đến từ
payload nên vẫn escape theo đúng lệ của file.

CSS, thêm vào khối `<style>` đã có:

```css
th .formula { display: block; font-weight: normal; font-size: 0.85em; }
```

`display: block` cho xuống dòng mà không cần `<br>`; `font-weight: normal` để ký hiệu nhẹ
hơn nhãn, giống ảnh #2. Không đặt màu — trang in là đen trắng.

Test trong `render-report-table-html.test.ts`, theo cách file đang khẳng định chuỗi HTML:
- cột có `desc` → HTML chứa `<span class="formula">(2)=(3)/(1)</span>` trong `<th>` tương ứng
- cột không có `desc` → `<th>` đó không chứa `class="formula"`
- `desc` chứa ký tự cần escape → được escape
