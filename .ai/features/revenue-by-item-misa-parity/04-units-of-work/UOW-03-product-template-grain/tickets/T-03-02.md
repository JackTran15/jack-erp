# T-03-02 — Đảo `GROUP_BY_LABELS_VI`

## Context

`get-invoice-report-document.handler.ts:19`:

```ts
const GROUP_BY_LABELS_VI: Record<ReportGroupBy, string> = {
  [ReportGroupBy.ITEM]: 'Mẫu mã',
  [ReportGroupBy.PARENT]: 'Hàng hóa',
  [ReportGroupBy.GROUP]: 'Nhóm hàng hóa',
};
```

Hai dòng đầu ngược nghĩa. Bằng chứng, cả ba đều nằm trong repo:

- `resolveGrain` (`revenue-by-item.report.ts:59`): `PARENT` → grain `'parent'`
- `dimensionOf` case `'parent'` (`revenue-by-item.aggregator.ts:116`): gộp theo
  `r.parentId` = sản phẩm cha = **mẫu mã**
- comment trong `buildColumns` (`revenue-by-item.report.ts:100`): gọi `statBy=item` là
  `"Hàng hoá"`

Nên `ITEM` phải là `Hàng hóa` và `PARENT` phải là `Mẫu mã`. Hôm nay dòng tham số của mọi
export ở grain `item` đang ghi sai là `Nhóm theo: Mẫu mã`.

## Implementation notes

Đảo 2 dòng:

```ts
// Grain label for the parameter line. Follows `resolveGrain` in
// RevenueByItemReport: PARENT groups by the parent product ("mẫu mã"), ITEM
// keeps one row per SKU/variant ("hàng hóa").
const GROUP_BY_LABELS_VI: Record<ReportGroupBy, string> = {
  [ReportGroupBy.ITEM]: 'Hàng hóa',
  [ReportGroupBy.PARENT]: 'Mẫu mã',
  [ReportGroupBy.GROUP]: 'Nhóm hàng hóa',
};
```

Không đổi gì khác trong file này — nhãn `Nhóm theo:` và luật "chỉ in filter đang bật" là
việc của T-04-02.

Spec mới (`get-invoice-report-document.handler.spec.ts`) — module này chưa có spec cho
handler; theo lệ `*.handler.spec.ts` của các handler khác trong `invoice-report/queries/`:
- `invoiceFilterSummary({ statBy: ReportGroupBy.PARENT })` → chuỗi chứa `Mẫu mã`
- `invoiceFilterSummary({ statBy: ReportGroupBy.ITEM })` → chuỗi chứa `Hàng hóa`
- `invoiceFilterSummary({ statBy: ReportGroupBy.GROUP })` → chuỗi chứa `Nhóm hàng hóa`

`invoiceFilterSummary` đã là hàm exported nên test được trực tiếp, không cần dựng handler.
