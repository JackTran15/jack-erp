# T-02-02 — Registry drill-down thay nhánh invoiceCode cứng trong ReportPageTableView

## Context
`ReportPageTableView.tsx:425-440` quyết định ô có phải link không bằng một điều kiện cứng:

```tsx
const content = col.tableConfig?.link ? (
  col.column === "invoiceCode" && raw ? (<a onClick={…}>{raw}</a>) : (raw ?? "")
) : isReportNumberColumn(col) ? formatReportNumber(raw) : (raw ?? "");
```

Kéo theo một lỗi phụ: cột **số** mà backend trả `link: true` rơi vào nhánh `raw ?? ""` và **mất
định dạng số** hoàn toàn (AC-15).

## Implementation notes
- Module thuần `_lib/report-drilldown.ts`, **không import React** — để còn test được khi
  `backoffice-web` có vitest:
  ```ts
  type DrillDownAction =
    | { kind: 'invoiceDetail'; code: string }
    | { kind: 'report'; drillDown: ReportDrillDown };

  export function resolveDrillDown(
    backendKey: string, columnKey: string,
    ctx: { raw: ReportCellValue; row: ReportRow; filters: Partial<ReportFilterValues> },
  ): DrillDownAction | null;
  ```
- Ticket này đăng ký **hai** mục `invoiceCode` — `invoice-order-listing` và
  `invoice-item-revenue-detail` — tái lập đúng hành vi cũ. Mục `date` là T-02-06, mục `itemName`
  là T-03-04.
- Nhánh cell viết lại: `resolveDrillDown(...)` trả khác `null` → render `<a>`; ngược lại **luôn**
  đi qua `isReportNumberColumn` / `formatReportNumber` như cột thường. Cờ `link` của backend không
  còn tham gia quyết định click.
- `raw` rỗng/null → resolver trả `null` ⇒ không render link rỗng.
- `backendKey` lấy qua `getReportBackendKey(reportType)` từ report store, không hard-code.
- Giữ nguyên mọi thứ khác trong hàm render ô: căn lề, cột ghim, `indentLevel`, `--row-bg`.
