# T-02-03 — State drillDown trong report store và factory dựng state cho bảng lồng

## Context
`ReportPageTableView` nằm sâu bốn tầng dưới `ReportPage` và props cố ý chỉ có `{rows, totals}`.
Nó đã lấy `setDetailInvoiceCode` từ report store — drill-down mới đi theo đúng lối đó, không
prop-drilling.

## Implementation notes
- `report.interface.ts`: thêm
  ```ts
  export interface ReportDrillDown {
    reportType: string;                     // report type FE của dialog
    title: string;                          // 'BẢNG KÊ HÓA ĐƠN'
    subtitle: string;                       // 'Ngày 19/08/2026'
    filters: Partial<ReportFilterValues>;   // đã narrow + allow-list
  }
  ```
  cùng `drillDown: ReportDrillDown | null` trên state và `setDrillDown` trên actions.
- `report.store.ts`: khởi tạo `drillDown: null` ngay cạnh `detailInvoiceCode: null`; `reset()`
  phải xoá nó — nếu quên, đổi report type khi dialog đang mở sẽ để lại dialog mồ côi.
- `report.factory.ts`: `buildDrillDownReportState(parent, drillDown)` dựng state khởi tạo cho
  provider lồng — `reportType` của dialog, `filters` đã narrow, `branch` **kế thừa từ cha** (query
  key và đường xuất khẩu phải trùng), `columnFilters` rỗng, trang về 1.
- Không đụng `detailInvoiceCode`: hai state song song, không thay thế nhau.

## Done when
- [x] `drillDown` + `setDrillDown` có trên store, khởi tạo `null`
- [x] `reset()` xoá `drillDown`
- [x] `buildDrillDownReportState` kế thừa `branch` của cha và đặt `columnFilters` rỗng, trang 1
- [x] `detailInvoiceCode` giữ nguyên hành vi
- [x] `pnpm --filter @erp/backoffice-web build` xanh
