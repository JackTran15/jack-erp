# T-02-05 — Tách ReportExportButtons và nối In / Xuất khẩu vào chân dialog

## Context
`ReportPageToolbar` dựng request In/Xuất khẩu từ đúng bốn nguồn store — `config`, `columns`
(table store), `appliedRequest`, `branch` (report store) — cộng `branchId` toàn cục. Vì dialog
lồng chính hai store đó, hai nút chạy đúng trong dialog mà **không cần** tham số hoá gì ở backend.

Chỉ vướng một thứ: toolbar còn kèm nút cấu hình cột (`Settings2`) + `ColumnConfigDialog`, thứ
không thuộc về chân dialog.

## Implementation notes
- Tách nguyên vẹn cặp `DropdownMenu` **In** + `Button` **Xuất khẩu** (`ReportPageToolbar.tsx:120-161`)
  sang `ReportExportButtons`. Di chuyển, không viết lại — logic dựng request giữ nguyên từng dòng.
- `ReportPageToolbar` sau đó là `<ReportExportButtons /> + nút cấu hình cột`.
- Chân dialog: `<ReportExportButtons /> <Button>Đóng</Button>`.
- **Không** truyền request qua props. Component tự đọc store; trong dialog nó đọc store lồng — đó
  chính là cơ chế làm cho AC-09 đúng.
- Tiêu đề file mang nhãn báo cáo gốc ("BẢNG KÊ HÓA ĐƠN VÀ ĐƠN HÀNG"). Đã chấp nhận (A-08) — đừng
  sửa kèm.
