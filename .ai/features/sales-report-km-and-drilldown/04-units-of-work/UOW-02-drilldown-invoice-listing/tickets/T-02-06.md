# T-02-06 — Mục registry cho cột Ngày và allow-list filter kế thừa của dialog A

## Context
Mục cuối cùng làm dialog A chạy: `('daily-sales-summary', 'date')` → báo cáo
`invoice_and_order_list`, kỳ thu hẹp về đúng một ngày.

Giá trị ô `date` đã là `YYYY-MM-DD` (`toBusinessDate`), và `FilterBuilder.applyDateRange` hiểu ngày
trần là `[đầu ngày, đầu ngày kế)` — nên `{from: ô, to: ô}` chính xác là một ngày làm việc, không
cần chuyển đổi gì.

## Implementation notes
- Kế thừa **allow-list tường minh**, cấm spread:
  - kế thừa: `STORE`
  - ghi đè: `RANGE_DATE = { fromDate: ô, toDate: ô }`, `REPORT_PERIOD = 'custom'`
  - **bỏ**: `CHECKBOX_STATISTIC_BY_BRAND` — đích không hỗ trợ nhưng `invoiceFilterSummary` vẫn in
    ra file xuất khẩu ⇒ dòng phụ đề sai
  - **không set**: `STAT_DATE_TYPE`, `INVOICE_STATUS`. `daily-sales-summary` hard-code
    `invoice.issuedAt` và không expose hai filter này; để trống thì đích dùng đúng cột ngày ấy
    (A-04). Set vào là dialog liệt kê theo cột ngày khác dòng vừa click.
- `title: 'BẢNG KÊ HÓA ĐƠN'`; `subtitle: 'Ngày ' + định dạng dd/MM/yyyy` bằng `Intl` locale `vi-VN`.
- Ô rỗng → trả `null`.
