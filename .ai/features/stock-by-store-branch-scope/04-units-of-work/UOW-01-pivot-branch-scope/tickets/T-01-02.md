# T-01-02 — Chuyển báo cáo pivot sang org-wide

## Context
Đảo chiều bản sửa trước (ADR-01/ADR-02 đã bị ADR-04 thay thế). Cột động, dữ liệu và đường xuất
khẩu đều phải phủ toàn tổ chức; `organizationId` vẫn là ranh giới cứng.

## Implementation notes
- Gỡ `RbacService`, `CONSOLIDATED_PERMISSION`, `scopedActor` — sau ADR-04 mọi vai trò như nhau nên
  không còn gì để phân biệt. Constructor quay lại 2 tham số.
- `orgBranches(actor)`: bỏ `permittedBranchIds` và mệnh đề `id: In([...permitted])`, chỉ còn
  `where: { organizationId: actor.organizationId }`, giữ `order: { name: 'ASC' }`. Bỏ luôn nhánh
  `if (!permitted.size) return []`.
- `buildData` và `countRows`: thay `resolveInventoryBranchIds` bằng `resolveOrgWideBranchIds`,
  truyền `actor` nguyên vẹn.
- `assertKnownColumns` không đổi — nó nhận `branchIdSet` từ `orgBranches` nên tự nới theo.
- Không sửa file frontend nào.
