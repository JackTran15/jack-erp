# T-02-02 — Xoá controller + service legacy

## Context
`InventoryReportsController` phục vụ 8 endpoint `GET /reports/inventory/*` — bản v1 của đúng 8
báo cáo mà v2 đã phục vụ. `stockByBranch` truyền `dto.branchIds` thẳng từ query string vào
engine (`inventory-reports.service.ts:133`), và engine coi mảng rỗng là "không lọc chi nhánh"
(`stock-balance-pivot.service.ts:232`) ⇒ org-wide. Đây là lỗ hổng thứ hai của PQ-02.

## Implementation notes
- Xoá 5 file trong `touches` (trừ `inventory-reports.module.ts` — file đó chỉ sửa)
- Trong `inventory-reports.module.ts`: bỏ import và khai báo `InventoryReportsService`
  (providers) + `InventoryReportsController` (controllers)
- **Giữ nguyên** và không đụng tới: `StockPeriodService`, `StockBalancePivotService`,
  `TransferReportService`, `DocumentDetailService`, `TempWarehouseReportService`,
  `services/date-range-resolver.ts`, `dto/report-column-filter.dto.ts` — cả 7 thứ này v2 dùng
  chung (đã kiểm bằng grep, xem 03-logical-design.md)
- Sau khi xoá, chạy `grep -rn "InventoryReportsService\|InventoryReportsController" apps/`
