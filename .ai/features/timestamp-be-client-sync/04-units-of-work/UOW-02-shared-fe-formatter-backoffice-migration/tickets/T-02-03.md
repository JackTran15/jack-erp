# T-02-03 — Migrate treasury ledger date formatting (ledger-cash + deposit)

## Context

These two are structurally different from the other call sites: `LEDGER_CASH_VI_DATE` /
`LEDGER_CASH_VI_DATE_TIME` (`ledger-cash.constants.ts:1-13`) and `VI_DATE`
(`LedgerDepositPage.tsx:56-60`) are plain `Intl.DateTimeFormatOptions` objects, not
constructed `Intl.DateTimeFormat` instances — they're passed straight into
`Date.prototype.toLocaleDateString("vi-VN", OPTIONS)` at the actual call sites:

- `useLedgerCashTableColumns.tsx:25` —
  `r.documentDate.toLocaleDateString("vi-VN", LEDGER_CASH_VI_DATE)`
- `LedgerDepositPage.tsx:291` —
  `new Date(r.docDate).toLocaleDateString("vi-VN", VI_DATE)`

`LEDGER_CASH_VI_DATE_TIME` (`ledger-cash.constants.ts:7-13`) has no current caller anywhere
under `ledger-cash/` — confirmed by search. It is pre-existing dead code; this ticket does
not remove it (not asked for), only adds `timeZone` to keep it consistent with its sibling
if/when something does use it.

## Implementation notes

- Preferred: replace the two live call sites with the shared util directly —
  `formatViDate(r.documentDate)` in `useLedgerCashTableColumns.tsx`,
  `formatViDate(r.docDate)` in `LedgerDepositPage.tsx` — and delete `LEDGER_CASH_VI_DATE`
  and `VI_DATE` once nothing references them (search each file's own module for other
  uses first; do not delete blind).
- If a call site elsewhere in `ledger-cash/` or `deposit/` needs the raw
  `Intl.DateTimeFormatOptions` shape (e.g. passed into a third-party component prop
  instead of called directly) rather than a formatted string, keep the constant but add
  `timeZone: "Asia/Ho_Chi_Minh"` to its literal instead of deleting it — check before
  assuming the direct-call replacement above is safe everywhere.
- `LEDGER_CASH_VI_DATE_TIME`: add `timeZone: "Asia/Ho_Chi_Minh"` to the literal (do not
  delete unused dead code that wasn't asked to be removed).
- Do not touch `VOUCHER_FORM_LABEL_WIDTH`, `READONLY_INPUT_CLASS`, `TABLE_NUM_CLASS`,
  `DOCUMENT_SECTION_LABELS`, `DOCUMENT_SECTION_HEADING_CLASS` in `ledger-cash.constants.ts`
  — unrelated constants in the same file.
