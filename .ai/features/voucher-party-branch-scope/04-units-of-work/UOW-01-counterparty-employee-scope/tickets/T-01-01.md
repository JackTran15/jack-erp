# T-01-01 — EmployeeBranchScopeService + hai hàm dựng vị ngữ SQL

## Context

Đây là nơi duy nhất định nghĩa "nhân viên của chi nhánh đang làm việc". Ba nơi truy vấn
(UOW-01/02/03) gọi lại, mỗi nơi một cơ chế SQL khác nhau, nên thứ được chia sẻ là **văn bản
vị ngữ**, không phải kết quả truy vấn (ADR-02).

`RbacModule` đã là `@Global()` và export sẵn `RbacService`, `UsersService` — thêm service
mới vào `exports` là đủ, không module nào phải `imports` thêm.

Đọc `UsersService.visibleUserIds()` trước khi viết. Nó **không** phải thứ cần tái dùng
(ADR-01) nhưng là thứ dễ nhầm là tái dùng được, nên hai file phải trỏ chéo comment sang
nhau, nói rõ cái nào trả lời câu hỏi gì:
- `visibleUserIds()` → "tôi được quản những ai" (mọi chi nhánh actor thuộc về + cấp cao hơn)
- `resolve()` mới → "phiếu này thuộc chi nhánh nào" (đúng một chi nhánh đang làm việc)

## Implementation notes

- Kiểu trả về là union rời rạc, đừng dùng `string | undefined`:
  ```ts
  export type EmployeeScope =
    | { mode: 'all' }
    | { mode: 'branch'; branchId: string }
    | { mode: 'none' };
  ```
- `async resolve(actor: ActorContext): Promise<EmployeeScope>`
  1. `rbac.getUserPermissions(actor.userId, actor.organizationId)` — đã cache Redis, đừng
     tự thêm lớp cache nào
  2. chứa `iam.user.read.all` → `{ mode: 'all' }`
  3. không có `actor.branchId` → `{ mode: 'none' }`
  4. còn lại → `{ mode: 'branch', branchId: actor.branchId }`
- Hai hàm thuần, export ở module level (không phải method, để test không cần DI):
  ```ts
  export function employeeBranchScopeSqlNamed(userIdExpr: string, branchParam = 'scopeBranchId'): string
  export function employeeBranchScopeSqlPositional(userIdExpr: string, branchPlaceholder: string): string
  ```
  Cả hai trả về cùng một hình dạng:
  `EXISTS (SELECT 1 FROM user_branch_assignments uba WHERE uba.user_id = <userIdExpr> AND uba.branch_id = <param>)`
- **Không** thêm `uba.organization_id` vào vị ngữ: `branchId` đã do `ActorContext` xác thực
  là thuộc `branchIds` của token, và cột `branch_id` là uuid duy nhất toàn cục. Thêm vào chỉ
  làm câu truy vấn dài hơn mà không siết thêm gì — nếu người review muốn có, hãy nói rõ lý do
  chứ đừng thêm theo phản xạ.
- Dạng positional nhận **placeholder đã dựng sẵn** (`'$3::uuid'`), không nhận số thứ tự —
  người gọi mới biết mình đang ở tham số thứ mấy (ADR-03).
- Một `logger.debug` ghi `mode` + `branchId` (xem Observability trong `03-logical-design.md`).
- Tiếng Anh toàn bộ comment/log/message.
