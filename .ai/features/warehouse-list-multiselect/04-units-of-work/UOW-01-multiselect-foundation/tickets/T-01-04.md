# T-01-04 — Nhập kho — tách ô tick khỏi selectedId, thêm Chọn tất cả

## Context

`PurchaseOrdersPage.tsx:754-771` dựng ô tick từ `selectedId`:

```
onRowClick={(row) => setSelectedId(row.id)}
leadingColumn={{ cell: (row) => <input checked={selectedId === row.id}
                   onChange={() => setSelectedId(selectedId === row.id ? null : row.id)} /> }}
```

`selectedId` nuôi `useQuery(["goods-receipt", selectedId])` (dòng 362) và
`DetailPanel` → `useInfiniteQuery` trên `/:id/lines` (dòng 854). Nên mỗi cú tick là
hai request.

## Implementation notes

- Gọi `useRowMultiSelect({ rows: records?.data ?? [], getRowId: getOrderId })` ngay
  dưới `useDocumentListSelection` đang có. Hai hook, cùng `rows`, cùng `getRowId`
- `leadingColumn.header`: đổi `<span className="sr-only">Chọn</span>` thành
  `<SelectAllCheckbox ... disabled={(records?.data.length ?? 0) === 0} />`
- `leadingColumn.cell`: `<RowSelectCheckbox checked={isChecked(row.id)} onToggle={() => toggle(row.id)} />`
  — **không** còn nhắc tới `setSelectedId`
- `onRowClick={(row) => setSelectedId(row.id)}` giữ nguyên; nút số phiếu ở dòng 539
  giữ nguyên
- `rowClassName={(row) => (row.id === selectedId ? "bg-info-subtle" : undefined)}`
- Xóa tick khi đổi lọc:
  ```
  // Chỉ [columnFilters, period] — cố ý bỏ `pagination` ra ngoài: lật trang phải GIỮ
  // tick để gom phiếu qua nhiều trang rồi in một lượt (AC-09), còn đổi bộ lọc thì
  // tập phiếu cũ không còn nghĩa gì (AC-10).
  useEffect(() => { clearChecked(); }, [columnFilters, period, clearChecked]);
  ```
- Nút "Nạp" (dòng 468): thêm `clearChecked()` trước `void loadRecords()` (AC-11)
- Không đổi gì trong `DetailPanel`
