# T-04-01 — Nhập/Xuất kho truyền giá bán thật vào dữ liệu đổ sẵn

## Context

`toPrefillItems` (T-02-02, T-03-01) chép nguyên `sellingPrice: 0` từ code cũ. Trang
In tem mã coi giá 0 là "nguồn không biết giá" và chạy effect tra lại — **một request
`GET /inventory/items?search=<SKU>` cho mỗi dòng**, bắn cùng lúc bằng `Promise.all`.

Ở đường một phiếu (chục dòng) không ai để ý. Từ khi có Chọn tất cả rồi in hàng loạt,
cùng đoạn code đó bắn hơn 3.000 request và treo trình duyệt. Đây là bug do UOW-01/02
làm lộ ra, không phải bug mới sinh.

Giá vốn đã nằm trong payload: `line.item` là `@ManyToOne(() => ItemEntity, { eager: true })`
không kèm `select`, nên `GET /goods-receipts/:id` trả nguyên `ItemEntity` kể cả
`sellingPrice`. Chỉ có FE type là không khai nó.

## Implementation notes

- Thêm `sellingPrice?: number | string | null` vào quan hệ `item` của `GoodsReceiptLine`
  và `GoodsIssueLine`. Kiểu `number | string` vì cột là `decimal`, TypeORM trả chuỗi
- `sellingPrice: Number(line.item?.sellingPrice) || 0` ở cả hai `toPrefillItems`
- Không đổi gì khác trong mapping
